# 国家版本徽章制作与复核指南

本指南是九枚已注册国家版本徽章的唯一持久制作规范。它负责视觉身份、母版、颜色候选与制作验收；选择器行为、发布范围和本地化边界以 [`BP-I18N-CORE`](../blueprint/i18n/localization-contract.md) 为准，来源与授权边界以[国家版本徽章来源记录](../sources/realm-badge-provenance.md)为准。

## 制作边界

“再实现”指依据参考图重新建立干净的项目矢量轮廓，不是提交或嵌入原始像素，也不是重新发明或风格替换。临时轮廓提取只可辅助定位边界；未经人工并排复核、路径优化和负形清理的自动结果不能作为完成品。

每枚徽章必须保留：

- 外轮廓的主要方向与重心；
- 中轴、镜像或有意非对称关系；
- 主体与负形的咬合；
- 冠、兽、翼、角、叶、塔、锋刃、家纹格与放射束等语义附属物；
- 缩至 `28px` 后首先被识别的一级轮廓。

不得以统一品牌感为由增加共同圆框、盾框、描边、底板或三字母简称。项目统一性来自相同画布、前景通道、透明背景、槽位与对齐规则，不来自把不同纹章改成同一模板。

## 母版与导出规格

- 母版采用正方形 `viewBox="0 0 510 510"`；SVG 分辨率无关，不虚构 DPI。需要光栅验收衍生物时，统一导出为 `510 × 510`、sRGB、透明背景并使用相同密度元数据；
- 单色母版只使用纯白 `#fff` 不透明前景和透明背景。运行时通过 CSS mask 以 `currentColor` 着色，不依赖源文件白色；
- SVG 不得嵌入可见文字、位图、外部 URL、脚本、动画、滤镜、样式表或不可追踪随机值；
- 文件以稳定 `editionId` 命名，九枚使用相同画布、格式和导出流程，不分别发明组件接口；
- 清理抗锯齿产生的孤立像素、非设计性毛刺、破碎边缘和无意义空洞，但不得圆滑化尖角或补齐有意负形；
- 显示槽位固定为 `28 × 28px`。保留各自构图留白，不强制把所有非透明边界拉到相同宽度。

## 逐实体再实现协议

以下语义包含视觉观察和项目转译，不宣称是官方纹章学释义。制作时先满足几何身份，再用背景语义决定非运行时色层。

### `yan`｜炎

- 一级轮廓：严格中轴的冠形兽面；中央长尖与两组向外上挑长刃组成上部，外侧更长斜锋扩大威仪；下部横向交叉构件托住收尖面甲，并以短垂饰接入细密横向纹样基座；
- 内部关系：面部由层叠甲片般正负形构成，中央小菱形与额部纵轴清晰，左右近似镜像但保留手工切削差；
- 禁改：不得简化为龙头、面具、火焰或汉字；不得裁掉下方细横带；
- 设计语义：礼器、册封、镇守与古老秩序优先于具象生物身份。

### `victoria`｜维多利亚

- 一级轮廓：中央竖轴串联王冠、盾面和底部绶带；两只相向直立兽形成宽幅护持，盾后放射尖束形成王权背光；
- 内部关系：盾面上宽下尖，左右分区与中央分割明确；兽体头、前爪、后肢和尾形成可读剪影；
- 禁改：不得去除双兽、王冠或放射结构，不得换成现实英国纹章；
- 设计语义：王权合法性、议事制度与工业化伦蒂尼姆并存，精致与坚硬不能相互取代。

### `ursus`｜乌萨斯

- 一级轮廓：极宽双头翼徽，两只禽首背向外望，左右翼近水平展开，下部爪尾收为三角；
- 内部关系：胸口中央尖星与头间小树形负形是关键断点，翼面以大白块为主、少量深色切口划分羽层；
- 禁改：不得改成单头鹰、熊头像或现实帝国双头鹰细节复刻，不得填平中央负形；
- 设计语义：帝国规模、军政扩张、寒地重量与历史纪念感，而非轻盈飞翔。

### `siracusa`｜叙拉古

- 一级轮廓：正面长尖狼首占据中轴，耳或冠毛向上分叉；两侧植物枝叶从底部包围面颊，中央下方以长尖坠物收束；
- 内部关系：狼额、眼区、吻部和颊线由多层锐角负形咬合；叶枝可辨但不抢过狼首；
- 禁改：不得改成写实狼、黑手党图标、橄榄环或单纯鹿角；
- 设计语义：家族礼仪、城市秩序与荒野暴力共享同一正面形象，保留“文明花环包围捕食者”的张力。

### `minos`｜米诺斯

- 一级轮廓：双层圆章包住中央圆日，左右牛角向外展开；圆环下方由胸甲或叶片状构件接入中轴尖坠，横向铭牌穿过下半圆；
- 内部关系：圆日、环带、双角和下坠轴同心且中轴稳定；横牌碎形只提供装饰节奏，不生成可误读文字；
- 禁改：不得移除横牌、把圆日改成人眼，或直接套用现实希腊回纹与牛头硬币；
- 设计语义：英雄纪念、城邦公共章记、青铜器与石制纪念物。

### `leithanien`｜莱塔尼亚

- 一级轮廓：两个带大卷角的侧面头部向中央相对；外侧短直线与下方成组弧线向外放射，中央狭窄缝隙分隔双生结构；
- 内部关系：左右近似镜像但不合并为一张脸；卷角内斜向几何块、下方三组声波弧线和中央向下尖形必须存在；
- 禁改：不得改成双音符、耳机、现实双头鹰或单一山羊头；
- 设计语义：双塔、双重权威、乐律、回声与严密秩序。

### `kazimierz`｜卡西米尔

- 一级轮廓：唯一以右上—左下强斜线为主的窄高徽章；低头骑士或马首般甲片团块向右下冲出，背后三根长锋刺向右上，底部多根武器交叉；
- 内部关系：三锋长度阶差、中央盔甲大块负形和底部交叉冲势共同建立识别，不得校正成轴对称；
- 禁改：不得改成盾牌加长枪、现实翼骑兵、单独马头或比赛奖杯；
- 设计语义：骑士竞技、速度、武备与商业传播共同制造的攻击性剪影。

### `higashi`｜东

- 一级轮廓：上方粗圆环内嵌几乎贯通高度的“東”形家纹字章，下方独立排列两行、每行四枚菱形格；
- 内部关系：圆环、字章和八枚菱格均为实心大形；字章横竖负形在小尺寸仍须辨认，圆章与菱格之间保留明显断带；
- 禁改：不得换成日本国旗、鸟居、樱花或随意书法字，不得删减八枚菱格；
- 设计语义：家纹、旗印、编制与克制的书写秩序。

### `columbia`｜哥伦比亚

- 一级轮廓：中央是不规则深色空核，数十条不同长度、宽度和角度的矩形或锯齿射束向外爆发；整体近圆但不对称；
- 内部关系：射束以多组密度形成工业爆发，不得平均分度；中心负形保持足够大，最长束在上、右与下方形成偏置动势；
- 禁改：不得改成太阳、星条旗、烟花、罗盘或均匀齿轮，不得填满中心空核；
- 设计语义：技术扩张、能量释放、未知核心和面向未来的实验冲动。

## 制作与复核流程

1. 从来源记录确认实体与参考边界，按一级轮廓、轴线、关键负形和附属结构拆解，不按逐像素描摹；
2. 在统一母版内建立路径，清理非设计性噪点，但保留尖角、切削感、留白与有意不对称；
3. 检查 SVG 不含文字、位图、背景、外部依赖、脚本、动画或滤镜；
4. 与参考并排检查方向、重心、负形和语义附属结构；
5. 在 `28px`、`1x/2x`、浅色与深色背景复核，确保不糊成实心块、圆点或被裁切；
6. 若生成上色候选，只复用同一几何，不修改路径身份，并确认目录没有运行时消费者。

以下任一情况判定素材失败：改变核心结构；用统一边框覆盖实体差异；直接提交本地参考图；以图标替代语言文字；在运行时使用上色候选；或因细节清理使关键负形、方向和附属结构无法识别。
