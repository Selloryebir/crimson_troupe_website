# 开发指南

## 本地运行

项目没有构建依赖。在仓库根目录执行：

```bash
python3 -m http.server 4173 --directory src
```

访问 <http://localhost:4173>。不要直接双击 HTML 验证 ES modules；`file://` 环境不能代表静态服务器行为。

## 新增剧目

1. 在 `src/data/shows.js` 添加完整剧目数据与搜索字段；
2. 在 `src/index.html` 添加带唯一 `data-open-show`、月份和城市字段的节目卡；
3. 如需新的主视觉变体，在 `front.css` 与 `overlays.css` 中分别处理列表和详情表现；
4. 验证筛选数量、搜索结果、详情内容及预约选项一致；
5. 若预约下拉框仍为静态选项，同步更新它，避免可浏览但不可预约。

## 新增交互

- 将稳定内容放入 `data/`，DOM 行为放入最接近用户能力的 `scripts/` 模块；
- 新模块只导出其他模块真正需要的接口，并由 `main.js` 初始化；
- 不使用未声明的全局变量，不从一个功能模块直接修改另一个模块的私有状态；
- 新增浮层样式放入 `overlays.css`，页面业务样式按时间层归属；
- 同时处理键盘操作、焦点、减少动态效果和 JavaScript 失败路径。

## 最小验证

1. `git diff --check`；
2. 检查 HTML 标签、ID、锚点和本地资源；
3. 确认所有 CSS `@import` 与 JavaScript `import` 能返回 200；
4. 在桌面与不大于 500px 的视口检查页面；
5. 检查浏览器控制台无模块加载或运行错误；
6. 按改动范围验证筛选、搜索、详情、预约、档案和世界切换。
