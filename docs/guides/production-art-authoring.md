# 剧目视觉创作指南

本指南把 [`BP-CNT-PRODUCTION-VISUAL`](../blueprint/content/production-visual-language.md) 转化为一次可执行的创作流程。长期出版与污染结果由该蓝图负责，十三项已采纳题义位于 [`BP-CNT-PRODUCTION-VISUAL-CATALOG`](../blueprint/content/production-visual-catalog.md)；本指南只帮助人工或智能体为一个具体标题形成原创方案、生成或绘制资产并完成网页交付，不建立评分数据库或循环审批。

## 八步创作流程

1. **固定已知事实：** 记录 `productionId`、全部已知国家版本标题、已经确认的作品设定及不得虚构部分。只有标题时只分析词义、语气和文化联想，不补写官方剧情。
2. **建立标题语义矩阵：** 分别从每种标题找出人物、物件、地点、时间、数量、动作或抽象性质，标记跨语言共同意象、互补次义与相互冲突处；以共同意象决定主体，以次义丰富观看路径，不让英文标题或稳定 ID 反向垄断画面。
3. **写出三句戏剧构想：** 分别回答第一眼承诺什么、同一象征意味着什么代价、刻意不回答什么。若三句只有一个直接答案，概念尚未成立。
4. **选择间接指称：** 从主体、遗留物、容器、作用空间、仪式、后果和缺席位置中选择一种主要表达，默认不完整正面图解标题名词。
5. **选择一个构图动词：** 从蓝图的可迁移修辞中选择主导动作；核心象征只保留一个，辅助象征至多两个。
6. **选择中央画法：** 让题义决定纹章平涂、风景水彩、儿童剪纸、圣像结构、博物图谱、静物夜曲、木刻或编辑拼贴；统一性由出版层承担。
7. **建立剧目视觉身份：** 先以黑白剪影和三档明度验证主体，再确定材料中性色、剧目主色、一个受控强调色、结构墨、旧金及猩红版必须保留的记忆色。
8. **完成出版与网页交付：** 加入具有中轴和左右秩序的外围出版边界、题签、中央身份和固定底部归属区；由统一原创矢量源叠加归属标记，按实际页面需要分别制作表站或里站等级 `0` 资产、裁切及污染接口，不把某一语言烧录为唯一母版。

## 间接指称与构图动词

封面不是剧情摘要。创作前并列阅读全部已知国家版本标题，分别提取字面对象、动作、关系和文化联想，再确定共同主意象与只作次义的分歧；稳定 `productionId` 和最方便读取的语言都不得自动成为视觉主来源。优先描绘题名对象的痕迹、容器、作用空间、仪式、后果或缺席位置，而非对象全貌。

每项视觉同时具备第一眼可理解的公开承诺、同一象征在第二次阅读中显露的隐藏代价，以及一项刻意不回答的保留疑问。不安从剧目隐喻内部生长，不能在普通宣传画上追加眼睛、血迹、乱码或恐怖字体代替构思。

| 修辞         | 适用题义                     | 构图关系                   | 需要避免                         |
| ------------ | ---------------------------- | -------------------------- | -------------------------------- |
| 仪式压缩     | 荣誉、权力、戒律、启示       | 竖立、放射、授予或服从     | 直画军队、统治者或现成宗教符号   |
| 不可触及目标 | 秘宝、禁物、目的地           | 引入、抬升、封存或延宕     | 手持物陈列和说明性藏宝图         |
| 临界过程     | 日期、期限、季节、觉醒       | 分段、积累、断裂或显露     | 大量同质计数和直白时钟           |
| 物件代身     | 职业、身份、缺席人物         | 堆积、拟人、负重或留空     | 通用角色肖像                     |
| 关系剪影     | 双生、盟誓、祖源、庇护       | 缠绕、镜映、冻结或占据     | 并排头像和说明性亲缘场景         |
| 作用空间     | 声音、梦境、气候、记忆       | 照亮、飘移、远望或延宕     | 乐符、眼睛和粒子替代空间逻辑     |
| 系统增殖     | 欲望、制度、消费、群众性事件 | 增殖、吞并、聚集、上升燃烧 | 无因果拼贴、通用血腥和装饰性混乱 |

该表用于选择观看关系，不是七套固定模板。新标题先确定它如何作用于观者，再选择画法、媒介和颜色。

## 生成、绘制与网页分工

- 剧目主体、复杂背景、人物和场景使用原创无文字位图；导航、按钮、正文、标题、焦点、响应式布局和真实交互继续使用语义化 HTML/CSS。
- 本地化标题由 HTML 叠加，不写入生成图片。复杂中央图像不以大量 CSS 几何绘画、滤镜和图层合成实现。
- 同一剧目实际出现在两个时间层时，两项资产共享剧目身份并采用不同装帧制度，不被描述为升级、修复、损坏或前后迭代。
- 等级 `1—3` 优先复用少量透明印版、遮罩和轻量 CSS，不为每一级烘焙整页大图。
- 生成图片中的归属标记只用于构图预览；正式页面以同一项目自有 SVG 或 HTML/CSS 标记叠加，避免不同资产中的轮廓、比例和国家版本发生漂移。
- 正式素材进入 `src/assets/`，声明明确宽高、焦点和裁切，使用响应式尺寸与现代压缩格式；非首屏素材懒加载。未通过验收的候选留在不提交的本地参考区。

## 参考与权利边界

本地参考图只供人工分析和生成后对照，不得提交到运行时、作为网页背景或裁切后使用，也不得作为图生图输入。生成提示只使用正式蓝图和本指南的文字要求，不直接要求再现某张参考图。

交付前检查：

- 未复制官方徽记、图中文字、角色、独特边框、内部图形或可辨认构图；
- 不含伪文字、权利不明标识或容易被理解为官方签名的细节；
- 标题、替代文本和必要信息不依赖图片内小字；
- 生成物与参考材料只有抽象出版制度和艺术方法上的关系，不保留原图布局；
- 资产来源、生成方式、人工修正及允许使用范围可以在制作资料中定位。

## 退回条件

出现以下任一情况时回到戏剧构想，不靠增加装饰补救：

- 只把标题名词画在中央，没有公开承诺和隐藏代价；
- 只读取单一国家版本标题，或因为 `productionId` 来自英文就把英文名词画成唯一答案；
- 形成通用奇幻角色海报，缺少间接指称、舞台框景和剧团出版归属；
- 同时堆叠超过必要数量的眼睛、面具、帷幕、血迹、蜡封和神秘符号；
- 遮住标题后，各剧目只能靠换色区分；
- 去掉颗粒、滤镜和花边后，主体剪影与观看路径不成立；
- 近似复制参考徽记、角饰、题签轮廓、角色或独特构图；
- 表站与里站等级 `0` 被解释为升级、修复、损坏或前后迭代；
- 图片无法适配本地化标题，或正文、操作和替代文本依赖图中小字。
- 需要精确数量、镜像或中轴关系时，生成结果计数错误、外围无故失衡，却被氛围正确掩盖；

## 最小验收

- 用一个没有现成样本的新标题验证：创作者只凭文字规则能够产生属于同一出版制度、但不复刻十三项构图的新作；
- 对涉及计数、镜像或缺席的方案逐项核对对象数量、中轴和唯一破坏点，不以整体观感替代结构检查；
- 用一个跨时间层剧目验证：两项资产能被辨认为同一剧目身份，又能清楚属于不同装帧制度；
- 用列表、详情和 320px 窄屏裁切验证：焦点、记忆色、标题安全区和替代文本意图仍然成立；
- 用去纹理、灰度和缩略图检查验证：主体剪影、观看路径和剧目区分不依赖滤镜强度。

这里只保留一次方案确认和一次运行时验收。是否采用某个具体艺术方向属于人工判断；通过后，格式优化、压缩、响应式派生和无障碍接入属于实现工作，不重复发起同类审批。
