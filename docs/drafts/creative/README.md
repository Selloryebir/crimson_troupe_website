# 创意草稿

本目录保存尚未获得人工采纳的文案、叙事蓝本、表现概念和内容创意。每份实际创意草稿必须同时遵守 `docs/drafts/README.md` 的固定元数据、“正文、待解决问题、正式拆分与影响定位”三个顶层部分和人工门禁。本文件只维护创意草稿专属的 `CRE-*` 正文格式。

## 创意草稿正文模板

```markdown
### CRE-01｜创意名称

- 状态：候选，待人工判断
- 内容类型：
- 适用时间层：
- 内容目的：
- 预期入口：
- 设定边界：
- 正式迁入目标：

#### CRE-01 内容正文或叙事蓝本

#### CRE-01 素材与实现提示
```

这里不是正式内容仓库。创意获采纳后，内容规则和叙事蓝本进入 `docs/blueprint/content/`；实际逐字文案和结构化内容进入唯一运行时内容源，运行时素材进入 `src/assets/`，不得把正式蓝图变成部署内容副本。

创意候选只有在人工明确选择其进入可部署验证后，才迁为完整运行时预览单位；移动、增删或标记本目录文件本身不得改变构建。运行时预览仍不等于正式批准，具体成熟度、根集合、摘要和构建策略以 `BP-CNT-CORE` 为准。获选内容迁入运行时并核对完整后删除对应实际草稿，只保留本 README 的抽象模板。

完成迁移后删除实际创意草稿来源；即使本目录暂时没有创意草稿，也保留本 README 作为稳定职责和格式入口。
