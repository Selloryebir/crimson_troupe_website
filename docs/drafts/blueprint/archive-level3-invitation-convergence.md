# 里站等级 3 收束与邀请回应蓝图草稿

- 文档类型：蓝图草稿
- 状态：已批准，待正式迁移
- 规划效力：不直接约束正式蓝图或源码
- 分析基线：当前 `BP-FND-NARRATIVE`、`BP-MOD-ARCHIVE`、`BP-CNT-CORE`、`BP-I18N-CORE`、`BP-QLT-STAGES` 与现有里站污染实现
- 目的：把等级 3 从页面底部的解释性投影改为“既有档案先收束为同一异象，访客主动追索后才收到古堡邀请”的页面内体验，并补足等级 1—3 的视觉递进
- 非目标：确定最终剧目、邀请逐字文案或正式素材；修改污染概率和会话状态；创建克莱布拉松稳定场次、索引或新 URL；接入真实购票或站外行为

## 正文

### SET-01｜异常收束与邀请回应因果

- 状态：已批准，待正式迁移
- 规划结果：等级 3 先改变既有页面中的可见档案关系，再在访客点击异常内容时显示页面回应；不再无条件把完整解释框附加在正文末尾
- 适用范围：里站全部页面的等级 3 呈现、异常内容链接与邀请回应
- 不包含：等级 0 稳定内容修改、自动弹窗、真实系统弹窗、强制接受邀请或取消可靠退出
- 正式迁入目标：`BP-FND-NARRATIVE`、`BP-MOD-ARCHIVE` 与 `BP-QLT-STAGES`

#### SET-01 规划正文

等级 3 的体验顺序固定为：

```text
稳定档案已经产生明显异变
→ 多个原本不同的记录收束为同一剧目、同一时间与同一地点
→ 访客因好奇主动点击其中一个异常记录
→ 网站阻止本次立即导航，并以站内语义对话框发出正式邀请
→ 访客可以关闭邀请，也可以继续查看原本合法的目标页面
→ 目标页面在同一污染状态下继续以页面职责解释这份邀请
```

- 邀请不得在进入等级 3 时自动出现，也不得作为普通正文附加在页面底部。它是网站对访客主动追索异象的回应；没有点击就没有邀请。
- 所有异常记录保留原有实体数量、DOM 顺序和合法 `href`。等级 3 只改变可见投影，不创建克莱布拉松 `Performance`、重复索引或伪造详情路由。
- 邀请对话框打开时记录访客原本点击的合法目标。关闭后焦点返回触发元素；选择继续后才沿原链接导航。脚本失效时原链接仍按等级 0 页面正常工作。
- 对话框使用页面内语义实现，不调用浏览器 `alert`、新窗口、系统错误框、下载、全屏或站外链接。必须支持可见关闭操作、`Escape`、焦点进入与返回，并保持页脚返回表站入口可靠。
- 邀请的心理恐惧来自“古堡跨越快照时间主动回应访客”，而不是解释污染机制。不得继续使用“原记录仍然有效”“无需逐项撤销”“档案合并校对”等替访客消除矛盾的说明口吻。
- 每次点击受污染的主要内容都可以重新唤起邀请；普通主导航、语言切换、页脚声明和返回表站不被改写为邀请触发器。

### SET-02｜页面职责与可见内容收束

- 状态：已批准，待正式迁移
- 规划结果：各页面按照自身任务改变可见内容，但共同收束到同一未知演出、克莱布拉松林地城堡和同一份邀请
- 适用范围：首页、本季演出、历史演出、场次与剧目详情、搜索、剧团和里站静态席位页
- 不包含：所有页面机械显示同一段正文、改变搜索匹配结果、改变场次集合或让全部导航失去原任务
- 正式迁入目标：`BP-MOD-ARCHIVE`、`BP-MOD-PROGRAMS`、`BP-MOD-SEARCH`、`BP-CNT-CORE` 与 `BP-I18N-CORE`

#### SET-02 规划正文

等级 3 使用一份按国家版本本地化的投影内容记录，至少提供统一剧目标题、短句、请柬时间、克莱布拉松林地城堡、邀请标题与正文、继续和关闭标签。具体值仍属于可替换预览内容，不在本草稿中批准为正式文案。

| 页面职责       | 等级 3 可见投影                                                                                                                  | 邀请触发                                 | 必须保持的稳定责任                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- | ---------------------------------------------- |
| 首页           | 主视觉场次和本季演出卡的标题、短句、日期、地点、状态与海报收束为同一演出和同一请柬；各卡仍保留不同程度的遮蔽、编号错误或印版损坏 | 点击主视觉或任一演出卡                   | 页面 H1、演出卡数量与原合法链接                |
| 本季与历史演出 | 两个集合中的全部记录都显示同一演出、时间和克莱布拉松；重复本身成为异常，不能用额外说明框解释                                     | 点击任一列表记录                         | 当前／历史页面任务、集合数量、筛选语义和原链接 |
| 场次与剧目详情 | 原题、梗概、人员、时间和地点被同一请柬关系重释；页面可以保留局部原文残片或遮蔽痕迹，表现原记录仍在投影下方                       | 点击剧目、席位或主要关联入口             | H1 主次、详情 URL、返回路径和原实体归属        |
| 搜索           | 匹配数量与结果实体不变，但可见标题、摘要和地点收束为同一回应；查询仿佛只能得到同一个答案                                         | 点击任一结果                             | 原查询、结果数量、搜索范围和合法结果链接       |
| 静态席位页     | 所有同期场次、分区和价格被投影为同一场演出的不同席位记录；原本失联的结算不恢复                                                   | 点击场次、分区或最终失活入口的受污染表现 | 无真实购票、无表站票篮、无付款和兑换能力       |
| 剧团页         | 人员、职责和机构记录被重释为邀请中的角色或等待到场的席位，但不把新旧剧团写成同一主体                                             | 点击主要人员或职责记录                   | 页面仍可理解为剧团资料，退出和主导航不受影响   |

- 所有页面共同使用同一组投影事实，但投影句式和局部构图按页面职责变化；不得复制同一段长文覆盖全站。
- 卡片“全部变成同一演出”只指访客在等级 3 看到的内容。点击后仍可进入原详情 URL，详情页再以同一邀请重释其原实体，由此形成“不同入口最终都被古堡接管”的连续体验。
- 克莱布拉松继续只属于等级 3 投影。等级 0—2 的可见场次、稳定数据、搜索索引、页面源标题和合法 URL 不得提前泄露该地点。
- 最终剧目、请柬日期、邀请逐字文案与生成素材由后续内容审核替换；结构开发可以使用一套完整但明确不具正式资格的预览值，不得把现有解释性段落当作最终邀请继续沿用。

### SET-03｜污染递进与视觉编排

- 状态：已批准，待正式迁移
- 规划结果：补足文字遮蔽、关系矛盾、镜像、旋转、叠放和页面环境失序，使等级 3 具有足够视觉冲击，同时保持真实任务层安全
- 适用范围：里站页面内物料、列表、详情、搜索结果、静态席位记录、背景框景与邀请对话框
- 不包含：持续随机抖动、频闪、全局滤镜、真实文字容器乱飞、通用血字警告或多个无因果故障的堆叠
- 正式迁入目标：`BP-FND-NARRATIVE`、`BP-MOD-ARCHIVE`、`BP-CNT-PRODUCTION-VISUAL` 与 `BP-QLT-STAGES`

#### SET-03 规划正文

| 等级 | 内容关系                                           | 视觉表现                                                                                                                                                   |
| ---- | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `0`  | 所有稳定记录各自成立                               | 保持原始历史快照，不出现异常                                                                                                                               |
| `1`  | 一处编号、标题或登记痕迹出现跨记录重复             | 印版偏移、局部 `██` 遮蔽、轻微重影和相框内的重复编号；正文仍完整可读                                                                                       |
| `2`  | 不同记录开始互相借用字段，但不得出现克莱布拉松     | 部分文字镜像副本、档案框受控叠放、海报越出内框、日期或地点关系矛盾；页面归属仍清楚                                                                         |
| `3`  | 演出、时间、地点与请柬全部收束，访客点击后收到邀请 | 猩红物料接管、重复卡片形成错误节律、文本块大面积非常规遮蔽、视觉副本倒置或旋转、相框跨越页面网格；邀请对话框表现为页面主动组织出的正式物件，而不是普通弹窗 |

- `██` 是内容被档案力量遮蔽或抹除的结果，只用于非关键字段和投影副本；不得遮挡返回表站、关闭邀请、页脚声明或完成当前任务所需的全部文字。
- 旋转、倒置、错位和“乱飞”只作用于 `aria-hidden`、不可交互、`pointer-events: none` 的视觉副本或装饰层。真实链接、按钮、表单、标题和阅读顺序保持直立、可聚焦、可点击。
- 等级 3 可以在进入时播放一次短促的受控失序，随后稳定为当前会话变体决定的异常构图；不得持续随机运动。`prefers-reduced-motion` 直接显示同等强度的静态终态，不把减少动画降级成轻度污染。
- 三种稳定会话变体只改变遮蔽位置、侵入方向、镜像轴和副本构图，不改变统一演出、克莱布拉松、邀请语义或交互结果。
- 邀请对话框应延续旧剧团印版、古旧请柬和猩红侵入的物件逻辑，可出现不完全对齐的边框、跨接缝印章和文本层级冲突；不能使用现实操作系统标题栏、错误代码或通用恐怖网站视觉。
- 所有异常层必须在桌面和 320px 视口内受控裁切。不得依靠 `overflow-x: hidden` 掩盖真实交互元素已经漂出视口的问题。

### SET-04｜实现责任与最小验收

- 状态：已批准，待正式迁移
- 规划结果：用类型化本地化投影、显式污染插槽和独立邀请交互替代全局追加说明框与无约束 CSS 猜测
- 适用范围：污染内容数据、里站组件、污染与邀请脚本、样式、五国家版本和验证器
- 不包含：复制一套等级 3 页面树、运行时重写稳定数据、为每张卡片建立平行实体或引入前端框架／菜单库
- 正式迁入目标：`BP-MOD-ARCHIVE`、`BP-I18N-CORE`、`BP-QLT-STAGES` 与 `docs/blueprint/traceability.json`

#### SET-04 规划正文

- 将当前只服务大型说明框的 `ArchiveProjectionContent` 重构为页面内污染内容契约；五个国家版本分别提供完整投影字段，不从炎语运行时回退。
- 退役 `ArchiveLayout` 正文末尾无条件装配的可见 `ArchiveProjection`。保留一条简短状态公告，但完整邀请只存在于默认关闭的共享语义对话框中。
- 首页卡片、演出列表、详情字段、搜索结果和静态席位使用显式投影插槽输出稳定内容与等级 3 可见内容；不由脚本拼接 `innerHTML`，不以 DOM 序号猜测字段身份。
- 污染状态控制器继续只拥有等级、事件数、稳定变体和清除条件；邀请的打开、关闭、原链接暂存、继续导航与焦点恢复由独立小型交互能力负责，避免把页面内容编排写进状态机。
- 污染等级改变时不新增浏览历史、不持久化改写内容、不改变当前搜索结果、票务状态或场次数据。返回表站和关闭标签页后仍可从稳定等级 0 内容重新开始。

最小验收只覆盖以下可观察结果：

1. 等级 0—2 的可见页面不出现克莱布拉松；等级 3 的首页、本季、历史、搜索和静态席位记录按各自职责收束为同一演出与地点。
2. 等级 3 页面初次呈现不自动打开邀请；点击受污染主要内容才打开对话框。
3. 对话框关闭后焦点回到触发元素，继续后进入原合法链接；主导航、语言切换、页脚和返回表站不被拦截。
4. 原卡片、结果和场次数量不变，所有 `href`、搜索归属和稳定数据不变；不生成克莱布拉松普通场次或索引。
5. 五国家版本无遗留炎语字段；完整邀请不是 live region，只使用一条简短状态公告。
6. 桌面与 320px 下无真实交互元素外溢；键盘、减少动态效果和可靠退出成立。
7. 等级 1、2、3 可以从同一视觉因果辨认递进，等级 3 不再主要依赖页面底部说明框、轻微缩放或背景变色表达污染。

## 待解决问题

无。最终剧目、请柬时间、邀请逐字文案和正式素材被明确排除在本草稿的决定范围外；它们的后续替换不改变本草稿定义的触发因果、页面责任和交互结构。
