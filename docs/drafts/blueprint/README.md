# 蓝图草稿

本目录保存尚未获得人工正式迁移授权的新蓝图提案，以及针对既有 active 蓝图的候选修改。蓝图草稿可以包含已经讨论确认的单项结论，但在完成正式迁移前不构成产品或源码约束。

人工明确提出、准备按蓝图实现的事项，应在对应 `dev_feature_<slug>` 编写和审查蓝图草稿；只有人工已经认可实验方向并选择继续使用原型代码时，`dev_experiment_<slug>` 才能在晋级清理阶段编写所需蓝图草稿。蓝图迁入 active 前不得开始会固化某一产品答案的正式源码实现。

每份实际蓝图草稿必须同时遵守 `docs/drafts/README.md` 的固定元数据、“正文、待解决问题、正式拆分与影响定位”三个顶层部分和人工门禁。本文件只维护蓝图草稿专属的 `SET-*` 正文格式。

## 蓝图草稿正文模板

```markdown
### SET-01｜规划名称

- 状态：待正式采纳
- 规划结果：
- 适用范围：
- 不包含：
- 正式迁入目标：

#### SET-01 规划正文
```

修改既有正式蓝图时，在“正式迁入目标”填写原蓝图 ID，并优先只记录拟修改部分；只有大范围重写确实更清晰时才复制完整候选稿。草稿获采纳后原位修正正式蓝图并保持原 ID，不创建拥有相同职责的并行 active 蓝图。

完成迁移后删除实际草稿来源；即使本目录暂时没有蓝图草稿，也保留本 README 作为稳定职责和格式入口。
