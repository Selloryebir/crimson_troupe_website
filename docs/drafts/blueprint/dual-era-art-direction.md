# 双时期艺术与 UI 方向蓝图草稿

- 文档类型：蓝图草稿
- 状态：正文已获人工确认，待正式迁移
- 规划效力：无；仅供人工审核，不约束正式蓝图、源码或运行时素材
- 分析基线：人工指定的新、旧剧团时期参考图；当前 `BP-FND-EXPERIENCE`、`BP-FND-NARRATIVE` 与 `BP-MOD-ARCHIVE`
- 目的：把两组参考图反复出现的色彩、构图、材质、边框、勾线和情绪规律转译为表站与里站可分别执行的艺术设计思想
- 非目标：复制官方图片、Logo、活动 UI、字体或构图；把参考图加入运行时；立即替换现有样式；锁定最终色值、组件规格或逐页视觉稿；用污染代替里站等级 `0` 的设计

## 正文

### SET-01｜参考图转译原则与双站共同基因

- 状态：已获人工确认，待正式迁移
- 规划结果：两组参考图只作为视觉证据，提取共同基因和时期差异，不把单张插图或活动包装误写成整站规则
- 适用范围：表站与里站的品牌识别、色彩角色、图像策划、排版层级、装饰语言和跨世界连续性
- 不包含：官方素材使用许可、逐张图像的剧情解释、最终设计令牌或页面实现
- 正式迁入目标：`BP-FND-EXPERIENCE`；参考来源及排除项候选记录到 `docs/references/design-reference.md`

#### SET-01 证据边界

- “新时期”和“旧时期”的归属由人工指定；场景插图用于观察光线、构图、材质和情绪，活动主视觉与奖章用于观察标题、徽章、边框及图形系统；
- 只有多张参考图反复出现的规律才上升为方向，单一角色、道具、颜色或特殊构图不成为全站规范；
- 参考图不是已获运行时使用授权的项目资产；正式迁移只保留设计结论和必要来源说明，不复制图片到 `src/assets/`。

#### SET-01 共同视觉基因

两站应共享“剧场、帷幕、面具、聚光、猩红、被框住的舞台”这些品牌母题，但使用方式必须不同：

| 共同母题 | 表站转译                             | 里站转译                                     |
| -------- | ------------------------------------ | -------------------------------------------- |
| 猩红     | 品牌动作、舞台能量和内容焦点         | 帷幕、封印、邀请和逐渐侵入的痕迹             |
| 黑色     | 现代摄影与舞台暗部，用于建立清晰对比 | 墨、煤烟、深廊与不可见空间，构成主要环境     |
| 框景     | 电影画幅、屏幕、编辑网格和利落裁切   | 画框、票证、档案卡、门廊和层层嵌套的观看关系 |
| 光       | 白色或冷色舞台光，强调行动与新秩序   | 烛光、旧聚光和门缝光，强调诱导与窥视         |
| 线条     | 精确细线、切角和运动轨迹             | 双线、刻线、旧金框饰和不均匀印刷边缘         |

双站的连续性来自母题，不来自复用相同布局后更换颜色。表站应先像一家正在运营的当代剧团，里站等级 `0` 应先像一份当年完整成立的旧网站。

### SET-02｜表站：现代剧场编辑系统

- 状态：已获人工确认，待正式迁移
- 规划结果：表站形成“克制的当代剧场机构 + 电影化舞台瞬间”的艺术方向，明亮可信但保留猩红剧团的危险余韵
- 适用范围：表站首页、演出列表与详情、剧团、搜索、票务以及表站共用导航和页脚
- 不包含：把表站整体改成暗色恐怖页面；逐张复刻《红丝绒》插图；用高饱和红覆盖所有服务界面
- 正式迁入目标：`BP-FND-EXPERIENCE`

#### SET-02 视觉内核与情绪

新时期参考图以宽画幅裁切、锐利斜线、局部动作、冷暖舞台光和受控暗部集中人物与动作，表达经历危险后重建秩序的专业感。表站的情绪顺序是可信、清晰、从容，再在剧目图像和过场中显露锋利与危险；服务页面不要求访客先理解暗线。

#### SET-02 调色板角色

以下色值是结合参考图与当前 `main.css` 提出的原型起点，不是最终令牌：

| 语义角色 | 候选起点  | 使用方式                                             |
| -------- | --------- | ---------------------------------------------------- |
| 画廊纸色 | `#F1EDE5` | 页面主要底色，提供现代展册和剧院节目单的清洁空间     |
| 抬升纸色 | `#FAF8F3` | 卡片、票务和需与背景分离的功能表面                   |
| 墨黑     | `#171310` | 正文、导航、精确边框和局部深色舞台区                 |
| 酒红     | `#811B28` | 品牌主色、当前状态和主行动，不铺满长篇阅读区域       |
| 舞台红   | `#C43A4A` | 剧目视觉、动态轨迹和短时强调，面积小于酒红           |
| 冷青     | `#3E7F86` | 边缘光、媒体状态和少量冷暖平衡，不作为第二套主品牌色 |
| 灰粉     | `#D4A9AA` | 柔化强烈红黑关系，用于图像氛围而非低对比正文         |
| 暖铜     | `#AD7542` | 节目编号、票面细节和小面积工艺感，不模拟里站旧金装饰 |

页面大面积仍以纸色和墨黑保证机构可信度；深色电影画面应作为首页主视觉、剧目视觉或章节断点出现。猩红负责指向，冷青负责反光，二者不得在所有组件中同时争夺注意力。

#### SET-02 图像与构图

- 优先使用宽画幅、近景裁切、明确焦点和单向舞台光；允许主体越出规则网格，但正文与操作仍保持稳定列线；
- 使用帷幕、衣摆、丝带、光束或抽象笔触形成方向，不用无意义粒子覆盖页面；
- 图像可包含轻度颗粒、笔触和色差，但主体与文字安全区保持清楚；首页使用强叙事主视觉，内页回到任务优先的编辑网格；
- 缺少已授权图像时，使用项目自有 CSS 图形、色块、线条和排版占位。

#### SET-02 排版、边框与组件

- 展示标题采用具有舞台海报张力的衬线体，导航、筛选、搜索和票务状态采用清晰无衬线体；不复刻活动标题字形；
- 使用大标题、明确编号、宽松留白和不对称编辑网格建立现代感，信息层级不依赖卡片阴影；
- 常规边框使用细实线、短下划线、切角或局部双线；六边形、场记板和屏幕框只用于编号、票面或专题徽记；
- 动效表现为幕布揭示、焦点移动、轻微视差或快速但克制的切换；减少动态效果时直接呈现最终状态。

### SET-03｜里站：被保存的仪式剧场

- 状态：已获人工确认，待正式迁移
- 规划结果：里站形成“完整的旧剧场网站 + 缓慢显露的仪式性不安”的艺术方向，在污染之前已经具有年代、诱惑和权威感
- 适用范围：1091 里站等级 `0` 的全部页面、旧剧团图像系统、档案与票证式组件，以及四级污染的视觉递进
- 不包含：把里站做成低清表站、通用哥特模板、持续故障屏、现实 VHS/拨号界面复刻或不可读的黑红噪声
- 正式迁入目标：`BP-FND-EXPERIENCE`、`BP-MOD-ARCHIVE`；污染递进候选同步检查 `BP-FND-NARRATIVE`

#### SET-03 视觉内核与情绪

旧时期参考图以正面轴线、门廊、画框、聚光、深色帷幕、旧金纹样和纸张颗粒组织被刻意留下的观看对象，使舞蹈与宴会更像排练好的邀请。里站等级 `0` 的情绪顺序是古老而完整、礼仪化、诱人，再显露不安与恶意；污染只能破坏完成度，不能替代完成度。

#### SET-03 调色板角色

以下色值同样只是原型起点，并优先复用当前里站基础令牌：

| 语义角色 | 候选起点  | 使用方式                                           |
| -------- | --------- | -------------------------------------------------- |
| 煤烟黑   | `#17100E` | 页面主底色和深廊空间，不使用绝对纯黑吞没层级       |
| 漆木黑   | `#211714` | 抬升表面、档案面板和旧木构件                       |
| 旧纸     | `#D8C9AD` | 正文与主要图文信息，保持长文可读                   |
| 褪色墨   | `#9D8D77` | 次级说明、编号和年代信息，不承担关键状态           |
| 帷幕红   | `#7D1722` | 等级 `0` 的帷幕、封印和重要标题                    |
| 鲜血红   | `#BB2835` | 污染升级、危险动作和少量视觉穿刺，不作为正文底色   |
| 旧金     | `#9A6A32` | 画框、徽记、规则线和仪式等级，不制作大面积金属渐变 |
| 烛光琥珀 | `#D09A55` | 局部光源和互动焦点，不能替代可访问焦点样式         |
| 烟紫灰   | `#66555F` | 帷幕暗部、阴影和褪色图像的冷暖过渡                 |

旧纸与煤烟黑负责阅读，旧金与帷幕红负责仪式等级，鲜血红只在异常或关键诱导中出现。纹理不得降低正文、导航、搜索反馈和返回入口的对比度。

#### SET-03 图像与构图

- 优先使用正面轴线、中心舞台、拱门、长廊、画中画和被框住的对象，制造“访客正在被安排观看”的关系；
- 使用较克制的 4:3、肖像画、登记卡或旧节目单比例，与表站的宽银幕和自由裁切形成区别；
- 图像可以有暗角、纸纹、炭笔、褪色、漏印和轻微失焦，但主体与替代文本不依赖缺陷；烛光、门缝光和单束聚光用于牵引视线；
- 面具、玫瑰、帷幕、票证、画像和旧徽记可以形成素材母题。

#### SET-03 排版、边框与组件

- 展示标题采用古典、紧凑、具有刻印感的衬线体；正文仍使用高可读衬线体，功能标签和编号可使用窄体无衬线或等宽体；不使用难辨认的黑体花字承载任务；
- 页面采用较窄正文列、居中仪式标题、登记簿式列表和稳定对称骨架，局部不对称只用于叙事焦点；
- 边框以双线、细刻线、内外框、切角和少量纹样建立层级；装饰集中在入口、画像、票证和章节标题；
- “磨损”表现为装饰层上的断线、套印偏差和墨色不匀，不移动语义 DOM，不改变点击区域，不让组件实际错位；
- 等级 `0` 不使用随机抖动、扫描线、持续闪烁或系统故障图标。年代感来自排版、媒介和礼仪结构，不来自廉价故障滤镜。

#### SET-03 污染视觉递进

| 等级 | 视觉变化                                           | 不得改变                                         |
| ---- | -------------------------------------------------- | ------------------------------------------------ |
| `0`  | 完整旧纸、框饰、帷幕和仪式化排版                   | 无异常；网站本身可独立成立                       |
| `1`  | 少量漏印、手写划线、图像乳剂痕迹和不一致的红色批注 | 信息顺序、焦点和正文可读性                       |
| `2`  | 局部涂黑、套印偏移、画像缺损、边框被覆盖和内容矛盾 | 主导航、搜索结果归属和可理解反馈                 |
| `3`  | 大块黑红侵入、框景撕裂、受控视觉越界和明显叙事失真 | DOM 语义、键盘路径、视口安全、返回入口和页脚声明 |

污染应像旧媒介和剧场秩序被某种意志逐步改写，而不是统一叠加噪点或更换一套随机 CSS。

### SET-04｜从艺术方向到 UI 系统的最小落地边界

- 状态：已获人工确认，待正式迁移
- 规划结果：两套方向可以通过语义令牌、排版、框景、图像规格和污染修饰器落地，同时保持现有组件职责和可访问性
- 适用范围：未来正式蓝图迁移后的 UI 切片设计、设计令牌调整、原创素材委托和视觉验收
- 不包含：创建独立设计系统仓库、一次性重做全部页面或为每种装饰建立组件
- 正式迁入目标：`BP-FND-EXPERIENCE`、`BP-MOD-ARCHIVE`、`BP-FND-NARRATIVE`

#### SET-04 UI 与素材约束

- 两站分别拥有语义化视觉令牌，不让共享变量迫使两站得到相同表面；真正共享的只包括可访问性、尺寸尺度和必要品牌母题；
- 原创图像应记录焦点位置、允许裁切范围、文字安全区、明暗版本和替代文本意图；同一图像不得依赖桌面固定比例才能理解；
- 纹理、暗角、红色侵入和边框均属于装饰层，不成为状态、错误、选择或链接的唯一表达；
- 焦点样式、当前导航、错误反馈和成功反馈先满足清晰识别，再接受艺术风格修饰；
- 设计验收比较“任务是否同样可完成”和“两个世界是否被立即区分”，不以装饰数量、滤镜强度或与参考图的表面相似度作为完成度。

### TEST-01｜候选色值、纹理密度与图文叠加验证

- 状态：待可部署样张验证
- 所属规划或关联正文：`SET-02`、`SET-03`、`SET-04`
- 问题：候选色值、纹理强度、边框密度和图像文字安全区在真实表站与里站页面中是否同时满足风格辨识、长文阅读、交互反馈和 320px 裁切？
- 影响：决定哪些候选色值进入正式语义令牌，以及装饰应停留在页面、组件还是图像层；不影响两套艺术方向本身
- 建议答案：正式采纳方向后，先以四个代表性页面制作最小视觉切片；只调整未通过可读性、任务层级或双站辨识的参数，不借测试重新讨论已确认的信息架构
- 合并动作：人工确认样张结论后，把最终语义角色和约束融入对应正式蓝图；具体 CSS 数值保留在源码，不在蓝图复制实现
