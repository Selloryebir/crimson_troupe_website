# 《傀影与猩红孤钻》材料的双站体验宏观指导建议稿

- 文档类型：建议草稿
- 状态：待人工审核
- 规划效力：无；人工明确授权正式迁移前，不约束正式蓝图、源码、运行时内容或待批准美术草稿
- 分析基线：`local-reference-materials/phantom_and_crimson_solitaire/` 下 5 份 Markdown 与 1 份 CSV 本地材料；当前 active 双站体验、叙事状态、里站、内容、节目、搜索与票务蓝图；当前双站实现；`docs/drafts/blueprint/folio-production-visual-language.md` 仅用于划分职责
- 目的：从游戏设计者、玩家和泰拉访客三个互相独立的视角，提取能够指导表站与里站内容、结构、口吻、交互、UI、排版和异常表现的宏观原则，并给出不扩大当前运行时状态的最小落地方向
- 非目标：复制原作文本、图像、专有 UI、机制名称或数值；把局部材料视为完整官方时间线；新增 20 种网站状态或第二套随机系统；改写待批准美术草稿；迁移正式蓝图；修改源码或运行时内容

## 正文

### REC-01｜以三种视角共同确定材料的可用内核

- 状态：候选，待人工判断
- 优先级：P0
- 价值：避免把叙事文本误作网站文案库，也避免把游戏数值误作网页机制；为后续内容、体验和视觉判断提供同一上游目的
- 成本：低；主要是创作与评审时使用统一判断口径
- 推荐结论：采纳“可信邀请、多声部证据、观看者被重新编入演出、诱惑与代价并存”四项宏观母题；所有具体实现仍须通过现有双站任务和安全边界

#### REC-01 原因

本地材料均为 UTF-8。五份 Markdown 是局部剧情、提示和文书摘录；CSV 含 13 项基础幻觉及 7 项组合幻觉。材料没有完整展示顺序、解锁条件、机制生命周期、来源网址或版本信息，因此只足以支持设计方法分析，不能独立证明完整玩法流程、官方时间线或网站应采用的具体内容。

| 材料证据               | 可见结构                                                               | 高置信设计作用                                                   | 不应越过的推论边界                                                |
| ---------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------- |
| `背景故事.md:5-15`     | 贵族请柬以节庆、宴席、烟火与演出构成体面邀请，署名和日期建立物件身份   | 先让邀请作为正常社会行为成立，危险在事后重读时出现               | `102X` 残缺日期不能直接成为 1091 现行公告，原文不能复制为站内文案 |
| `故事的引言.md:5-17`   | 进入古堡从即时第二人称转为事后任务概览，搜救者随后被称为戏剧参与者     | 访客的身份关系可从调查或观看转为“已被编排”                       | 叙事处境中的别无选择不能转成真实强制、身份识别或无法退出          |
| `主题专属贴士.md:5-17` | 剧团、团长、地区与古堡各有短小认知锚点，并保留传闻与异常               | 在碎片叙事外提供低负担索引；演出与现实悲剧的对应是核心主题机制   | 危险因果与长寿团长不是普通访客必知事实，不应写成表站公开简介      |

| `探索之外.md:5-63`     | 剧团笔记、地方月报、管家残片、舞台通知、重建规划与外部报告互相校正     | “艺术振兴”逐渐显露为对灾难、场地、资源和人才的占用               | 不据此把新剧团默认写成旧剧团阴谋的延续，也不默认访客是罗德岛成员  |
| `幻觉报告册.csv:2-21`  | 基础效果改写视野、路线、节奏、资源、约束与替换；组合项生成新的行为规则 | 异常通过规则、收益、代价、作用域和组合关系改变体验，不只是加滤镜 | 缺少取得方式与完整生命周期；不能逐项转成网站状态或显示游戏数值    |

三个视角对同一材料的判断应同时成立：

| 视角       | 材料的主要目的                                                           | 形成的体验                                                               | 对网站的有效转译                                                                             |
| ---------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| 游戏设计者 | 让文书揭示剧团如何把灾难改写为艺术，再让规则使参与者感到自身行动也被编排 | 熟悉规则仍可学习，但原有策略和因果判断被暂时重写                         | 每个异常有明确触发、反馈、作用域、收益或揭示、代价及恢复；组合形成一个新因果，不机械叠加效果 |
| 玩家       | 先接受可信邀请，再通过重复探索和交叉阅读重建真相                         | 礼貌诱惑、好奇、有限不确定、掌控与失控并存，最后对早期内容产生第二次理解 | 关键内容稳定可达，支路确有信息奖励，故事可以不可信但操作和事实数据必须可信                   |
| 泰拉访客   | 在正常国家、地方、巡演、节目与机构事务中遇到不合常理的历史关系           | 先看到真实剧团网站，再发现档案似乎把访客从宾客改写成演出参与者           | 所有信息先作为泰拉内网站、告示或文书成立，不出现游戏节点、数值和玩家身份术语                 |

三者的交集不是“红黑恐怖网站”，而是：可信的机构外壳提供正常任务，多种有出处的声音逐步改变历史解释，访客因主动观看而接近演出关系，同时始终保有可理解的选择与退出。

#### REC-01 最小落地

- 把上述交集作为后续草稿、内容样张和代表页面评审的上游口径，不据此立即增加页面、字段或客户端状态；
- 每项候选创意至少能够说明它对游戏设计因果、玩家体验和泰拉内合理性分别有什么作用；若只能说明“更吓人”或“更像游戏”，则不进入后续规划；
- 本地材料继续只作为被忽略的研究输入。若本稿获准正式迁移，只在 `docs/references/` 记录材料范围、抽象借鉴、转译和排除项，不提交原文件或大段原文。

#### REC-01 可观察验收

- 不查看材料原文时，人员仍能解释四项宏观母题及其适用边界；
- 任一后续设计都能区分材料事实、项目推论和候选实现，不把局部摘录宣称为完整官方事实；
- 删除颜色、纹理和动效描述后，建议仍能说明访客认知为何变化。

#### REC-01 非目标

- 重建活动完整剧情、机制算法、时间线或解锁顺序；
- 将幻觉名称用于诊断、称呼或标记访客；
- 为证明可追溯而新增状态数据库、审查表或重复摘要。

### REC-02｜表站先兑现服务，里站等级 0 先兑现邀请

- 状态：候选，待人工判断
- 优先级：P0
- 价值：保持“泰拉人打开真实剧团官网”的根本体验，使后续异常有可以被重新解释的稳定基线
- 成本：中；主要是内容编排和代表页面文案校准，不要求重做现有路由或功能
- 推荐结论：两站都先作为各自年代的剧团官网成立；表站以清晰服务建立信任，里站等级 `0` 以礼仪、邀请和可执行事务建立诱惑，危险不抢占第一阅读层

#### REC-02 原因

请柬和剧团传单先提供举办者、场所、庆典、演出与观演规则等正常信息，其不安来自玩家后来知道“邀请可能也是选材、观看可能也是参演”。若页面一开始便使用血字、乱码、献祭警告或全知反派口吻，访客无需重新理解任何内容，项目也会退化为表面化 creepypasta。

表站与里站应分别保持以下边界：

- **表站：** 日期、地点、剧目、剧团、搜索、票务和观演提示直接、准确、面向观众；共享的面具、帷幕、角色和历史线索可以保留艺术余韵，但不能暗示新剧团仍在执行旧剧团的掠夺逻辑；
- **里站等级 `0`：** 以 1091 当时仍在运营的网站口吻提供当季节目、历史节目、剧团、搜索和不可购买的席位页面；礼貌可以更正式、规则可以更仪式化，仍须让宾客理解要看什么、去哪里和如何返回；
- **共同原则：** 每个页面先完成一个网站任务，再承载最多必要数量的叙事线索。异常失效或被移除后，页面不能变成没有内容的布景。

#### REC-02 最小落地

- 优先选择现有首页、一个场次详情、剧团页、搜索页和票务页作为内容样张，不新增一级路由；
- 对表站样张只检查机构可信度、信息优先级和艺术余韵，不主动补旧剧团恶意；
- 对里站等级 `0` 样张先完成邀请、节目登记和观演礼仪，再讨论污染后的第二读法；
- 使用“移除全部异常后是否仍像真实网站”作为最小判断，不建立额外评分体系。

#### REC-02 可观察验收

- 首次访客无需理解暗线即可在表站完成查演出、了解剧团、搜索和进入票务；
- 里站等级 `0` 在脚本或污染不可用时仍有完整内容、事务反馈和返回路径；
- 同一段表站服务文案不会因强行埋伏笔而同时显得含糊、虚假或不专业；
- 用户可以先相信邀请，后因其他证据重新理解邀请，而不是第一眼就被告知它是陷阱。

#### REC-02 非目标

- 把表站设计成旧剧团的伪装层；
- 用常驻恐怖元素证明里站身份；
- 把页脚同人声明扩张到正文或用沉浸感掩盖必要任务反馈。

### REC-03｜以有出处的多声部内容形成证据关系

- 状态：候选，待人工判断
- 优先级：P0
- 价值：让世界观、地方历史和剧团危险通过可推理关系出现，减少百科说明、反派独白与无来源怪谈
- 成本：中；需要为少量内容明确作者、受众、时间和用途，但不要求为每份文书建立独立页面
- 推荐结论：将公开事务、外部制度、私人见证和异常改写分成不同声音；真相由声音之间的缺口、重复和利益关系产生

#### REC-03 原因

`探索途中.md` 与 `探索之外.md` 的有效性不来自单篇文字，而来自会议、命令、遗嘱、新闻、内部通知、重建计划和外部报告对同一地点作出不同解释。公开文书越平静，制度性伤害越突出；真正怪异的梦呓只占少量，因此不会把全部作者写成同一种破碎口吻。

建议使用四类内容声音，而不是四套平行事实：

| 内容声音       | 表面职责                                   | 适合出现的位置                           | 叙事价值                                     | 保护边界                                                    |
| -------------- | ------------------------------------------ | ---------------------------------------- | -------------------------------------------- | ----------------------------------------------------------- |
| 剧团公开事务   | 邀请、节目、观演须知、场次、席位、剧团说明 | 两站现有首页、节目、剧团与票务页面       | 建立机构可信度，并提供可被后来重读的正常承诺 | 任务事实准确，不用双关替代日期、地点、价格或状态            |
| 外部制度声音   | 地方新闻、场地许可、行政或行业记录         | 相关场次、地点或档案的次级区块与搜索入口 | 显示剧团以外的社会如何理解或合理化事件       | 不把官网变成全面历史数据库，不冒充剧团的唯一事实            |
| 私人或内部见证 | 署名信件、制作便笺、排演批注、残片         | 少量详情补充或可选档案支路               | 提供具体人的局限认知、遗漏和风险             | 说明文种和来源，不截断必要任务信息，不默认属于官方事实      |
| 异常编辑声音   | 批注、替代摘要、关系提示或角色重命名       | 只在既有污染等级允许的叙事呈现中         | 让档案从被动对象逐步表现出编排意志           | 不改稳定 ID、路由、搜索范围、票务数据、原始内容或翻译完整度 |

进入生产内容时，作者侧至少要能定位来源或说话者、预期受众、泰拉时间可信度、表面用途、与其他记录的关系及官方来源或项目原创状态。它们用于防止无意矛盾和错误宣称，不要求全部显示给访客，也不要求新增审批台账或在蓝图中保存逐篇注释。

建议的信息节奏是“公开承诺 → 制度背景 → 私人代价 → 异常关系 → 事后重读”，但不是固定页面顺序。具体材料只在与当前场次、剧目、地点或剧团任务有关时出现，避免把浏览网站变成强制阅读卷宗。

#### REC-03 最小落地

- 先围绕一个已有 1091 场次或剧目制作一条短证据链：一份公开节目说明、一份有出处的次级材料和一处污染后关系提示；
- 使用现有稳定实体 ID、详情页和搜索范围建立联系，不为每份邀请、月报或便笺新增一级路由；
- 搜索可以索引获准公开的文种与摘要，但结果归属、URL 和类型始终稳定；
- 表站只采用符合新剧团身份的公开内容；旧剧团内部恶意不通过共享品牌反向污染表站。

#### REC-03 可观察验收

- 访客能够从署名、文种、时间或上下文分辨不同声音，不把矛盾误认为内容错误；
- 至少一条短证据链能在没有全知解释页的情况下形成可复述的因果；
- 每项次级材料都与现有页面任务或实体有关，删除后不会留下死链接和空路由；
- 页面核心内容不以解谜、随机触发或长文阅读为前置条件。

#### REC-03 非目标

- 建立百科、调查数据库、证据图谱工具或新的全文内容系统；
- 复制原作的邀请函、会议记录、笔记或专有角色身份；
- 用随机日期冲突、省略号、重复字和涂黑制造没有来源关系的伪档案。

### REC-04｜让“演出改写现实”成为语义引擎

- 状态：候选，待人工判断
- 优先级：P0
- 价值：把剧团、节目、地点、访客与污染连接成同一叙事因果，使视觉异常不再是独立装饰
- 成本：中；需要对少量跨页面内容进行编排，不要求修改污染概率、状态机或核心数据
- 推荐结论：不安应主要来自正常剧场词汇和网站关系的第二次解释；污染等级只逐步显露这种关系，不凭空创造另一套事实

#### REC-04 原因

材料反复把现实关系改写成剧场关系：灾后地区成为艺术土壤，人才成为可挑选的苗木，古堡成为新舞台，行动者成为群演，公开采风与重建掩盖资源占用。核心不是“剧团旁边发生恐怖事件”，而是剧团用艺术和机构语言重新命名现实，并可能让现实服从演出。

网站可使用以下语义动作，具体色彩、边框、封面和动效仍由待批准美术草稿负责：

1. **邀请转为筛选：** 首次阅读是正常观演邀请，后续记录显示被邀请者可能也是剧团所需的人、角色或资源；
2. **观看转为参演：** 访客先被称为宾客或观众，较高污染只在虚构叙事中让“到场、登记、落座、谢幕”等词获得角色关系，不声称掌握真实身份；
3. **地点转为舞台：** 城市、剧场和历史场所先有真实功能，再由剧团记录显露其被取材、占用或重新编排；
4. **节目转为现实先兆：** 剧目与地方事件通过日期、角色、意象或措辞产生对应，但稳定场次事实不被伪造；
5. **机构转为持久角色：** 称号、岗位、节目编号或出版制度可以跨时期回响，但不能未经人工决策把新旧剧团写成同一恶意主体。

在现有污染 `0—3` 上可以叠加语义节奏，而不改变状态定义：

| 等级 | 宏观认知作用                           | 适合的内容变化                                             | 不允许的结果                                         |
| ---- | -------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------- |
| `0`  | 档案是完整、礼仪化且可查阅的旧剧团网站 | 正常邀请、节目、登记与组织说明；只保留可二次理解的词义余韵 | 提前出现明确故障、威胁或全知真相                     |
| `1`  | 档案开始显露重复或不合时宜的对应       | 一处署名、短语、编号或图像关系在另一材料中重现             | 改变核心事实、批量划线或让每个区块同时异常           |
| `2`  | 多份记录之间出现可解释的角色或因果冲突 | 次级批注、交叉引用或叙事摘要让访客发现“艺术在消费现实”     | 破坏搜索归属、时间集合、链接、键盘顺序或可读性       |
| `3`  | 档案显露自身可能在编排访客的关系       | 少量虚构称呼或环境回应把观看解释为参演，仍保留可靠返回     | 识别真实身份、伪造系统警告、困住用户或让任务无法完成 |

该表只说明认知递进，不规定每页必须出现的文本数量，不替代 active 蓝图已有的视觉与安全契约。

#### REC-04 最小落地

- 选择一条 REC-03 的短证据链，先用静态四帧说明等级 `0—3` 分别新增了什么理解，再决定是否需要视觉或客户端实现；
- 每次升级只强化同一关系，不在同一页混用互不相关的眼睛、献祭、故障、跟踪和倒计时套路；
- 异常文案属于国家版本内容，必须遵守现有本地化发布门禁，不在客户端写死炎语变体。

#### REC-04 可观察验收

- 评审者能不用“更红、更乱、更抖”描述四级差异，而能说明每一级新增的认知关系；
- 等级上升后，稳定实体、任务状态和来源内容仍与等级 `0` 一致；
- 表站离开旧档案后保持正常，不因访客已经理解暗线而开始随机故障；
- 异常称呼只针对虚构会话角色，不接触设备、位置、账号或浏览数据。

#### REC-04 非目标

- 定义具体文案、图像、色值、边框、纹理或污染接口；
- 让每个页面、每个等级都出现同样数量的异常；
- 以该建议替代 `BP-FND-NARRATIVE` 或 `BP-MOD-ARCHIVE` 的正式状态与安全边界。

### REC-05｜把幻觉机制降维为作者侧异常语法

- 状态：候选，待人工判断
- 优先级：P1
- 价值：从 CSV 获得比“增加噪点”更有因果的创作方法，同时避免新状态机、玩法膨胀和可访问性损伤
- 成本：低至中；先用于一条代表性证据链的构思，只有真实价值成立后才评估实现
- 推荐结论：保留现有四级污染、固定概率和稳定变体；只把幻觉的视域、节奏、交换、约束、替换与绕行关系用作内部创作维度

#### REC-05 原因

CSV 的重点不是名称或数值，而是四条系统规律：强效果具有有限作用域，未知被限制在特定部分，多数代价有可理解的补偿，两个基础主题组合后生成一个新的第三规则。游戏允许损失、失败和重开，网站的公共任务不允许承受同类惩罚，因此只能转译其因果，不能移植其后果。

| 作者侧维度 | 来源示例                       | 可用的网页创作方向                                               | 明确禁止                                             |
| ---------- | ------------------------------ | ---------------------------------------------------------------- | ---------------------------------------------------- |
| 方向与视域 | `H-01`、`H-02`                 | 只隐藏非关键预告，或增加可选档案岔路；主要链接目的与正文始终可见 | 隐藏主导航、合法结果、焦点位置或深层 URL             |
| 压力与节奏 | `H-03`、`H-08`、`H-11`、`H-13` | 一次触发、一次离散变化、随后回到稳定阅读；文案节奏可收紧         | 倒计时惩罚、假加载、持续抖动、自动滚动或冻结输入     |
| 资源与交换 | `H-04—H-06`、`H-15—H-19`       | 可选支路提供额外语境，同时带来可预期的叙事不安或视觉代价         | 收费、丢失内容、改变票价与票篮、威胁真实文件或收藏   |
| 约束与准备 | `H-09`、`H-13`、`H-16`、`H-20` | 让异常会话变体保持稳定，减少无意义跳换                           | 限制滚动、阅读、搜索、返回、键盘或减少动态效果       |
| 替换与失真 | `H-07`、`H-12`                 | 在同一稳定实体下提供可逆、署名清楚的非关键摘要或图像变体         | 改写 ID、日期、范围、URL、翻译完整度或唯一剧情来源   |
| 绕行与回返 | `H-10`                         | 未来可选支路进入有限内容，结束后回到原页面并提供一份原创语境奖励 | 强制迷路、无限分支、可疑下载或无法回到来源           |
| 组合关系   | `H-14—H-20`                    | 两个已明确的压力共同产生一个能用一句因果说明的新结果             | 同时叠加两套 CSS、显示病症名称或增加 20 个运行时状态 |

污染应形成“认知收益 + 表面稳定性代价”，而不是“用户能力损失”。例如，访客可以因一次可选支路理解一条新的档案关系，同时看到该关系开始侵入原有编排；不能以隐藏日期、替换搜索结果或丢失票篮作为代价。

组合效果只在两个前置关系已经能被理解时才有意义。它应形成一个新的因果句，而不是把红滤镜、删除线、乱码和位移同时打开。具体组合内容属于未来创意或蓝图讨论，本稿不批准任何组合玩法。

#### REC-05 最小落地

- 不建立幻觉注册表、访客标签或新随机数；继续由现有 `0—3` 状态和稳定变体承担运行时归属；
- 在一个代表页面的静态分镜中，只选一个作者侧维度测试“触发—收益—代价—恢复—保护区”是否清楚；
- 若一个方向必须破坏核心操作才能成立，直接放弃，不为忠于游戏机制寻找技术绕路。

#### REC-05 可观察验收

- 任一异常能够用一句话说明触发、获得的新理解、承担的叙事代价和结束条件；
- 同一级变体在当前标签页保持稳定，升级沿已有因果强化，不因重渲染随机换主题；
- 关键内容不由概率、彩蛋或组合状态独占；
- 减少动态效果、无 JavaScript、键盘和窄屏路径仍能完成相同核心任务。

#### REC-05 非目标

- 复刻幻觉系统、战斗数值、节点、资源、藏品或组合名称；
- 改变当前污染概率、触发集合、上限、清除策略和会话归属；
- 提前启用 `docs/drafts/creative/archive-anomalous-ticketing.md` 的异常购票构想。

### REC-06｜以稳定任务线承载可选发现与解释环路

- 状态：候选，待人工判断
- 优先级：P0
- 价值：让服务、探索与恐惧各有节奏，避免核心任务被彩蛋绑架，也避免档案只剩无目的装饰
- 成本：低至中；优先复用现有路由、稳定 ID、相关内容链接和浏览器历史
- 推荐结论：保持一条独立成立的表站服务线、一条自愿进入的里站发现线和一条可重复的证据解释环路；所有支路有可靠回返

#### REC-06 原因

玩家材料的有效节奏是“稳定基线 → 主动动作 → 一次异常 → 稳定结果 → 新信息”，而不是持续失控。`H-10` 的额外区域尤其提供了低风险彩蛋模型：进入有限支路、回到原层、获得明确内容。网站可以借鉴边界和回返关系，不能照搬游戏术语或把支路设为核心任务门槛。

| 旅程         | 建议路径                                                                      | 体验结果                                                 | 必须保护                                               |
| ------------ | ----------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------ |
| 表站服务线   | 搜索或首页 → 本季演出 → 场次/剧目 → 票务或返回                                | 访客完成真实剧团网站的主要任务，不进入彩蛋也得到完整结果 | 服务文案、价格、状态、键盘与无 JavaScript 路径直接可靠 |
| 里站发现线   | 低干扰快照入口 → 1091 首页邀请 → 本季或历史登记 → 剧目、剧团或搜索 → 返回表站 | 访客主动跨越阈限，发现旧站是完整网站而非单页惊吓         | 合法 URL、浏览器历史、同语言返回和污染保护区           |
| 证据解释环路 | 一个稳定实体 → 有出处的次级材料 → 相关记录或搜索 → 回看原内容                 | 新线索改变对既有邀请、地点或节目关系的理解               | 关键线索不依赖随机概率；关联使用稳定 ID，不靠标题猜测  |
| 未来可选支路 | 明确的档案入口 → 一段有限内容 → 返回来源并恢复合理焦点                        | 以额外语境奖励好奇，而非奖励访问权限或下载               | 不强制进入、不无限嵌套、不伪造文件或阻断退出           |

污染判定继续只发生在 active 蓝图定义的合格动作上。异常出现后应尽快进入静止、可阅读的结果；进入支路、切换页面和提交搜索各自仍遵守一次动作至多一次判定，不能因建议中的叙事环路重复收费。

#### REC-06 最小落地

- 用现有路由选择一条最短代表链：里站首页邀请、一个 1091 场次或剧目、一次里站搜索和返回表站；
- 先补内容关系与来源，再判断是否需要新视觉或交互。普通相关链接足以完成时，不新增关系图、解谜面板或状态；
- 只有一条有限支路在内容价值、退出和多语言成本上通过验证后，才讨论是否扩展同类模式。

#### REC-06 可观察验收

- 用户始终知道自己是在完成网站任务、查看次级材料还是进入可选支路；
- 每条支路都能回到来源或现有主任务，浏览器前进、后退与直接 URL 正常；
- 离开里站后表站恢复完全稳定，认知变化由用户记忆承担，不把污染带回正常服务；
- 不阅读暗线的访客不会失去场次、剧目、搜索或票务信息。

#### REC-06 非目标

- 新建路线图、成就、收藏、解锁树或长期进度；
- 自动把所有本地文书转换成独立页面；
- 用隐藏热区、假错误、强制等待或不可逆导航制造探索感。

### REC-07｜以宏观意义约束具体美术与实现

- 状态：候选，待人工判断
- 优先级：P0
- 价值：让文本、图像、UI、排版与动效服务同一叙事目的，同时保持本稿和待批准美术草稿各司其职
- 成本：低；主要是建立上下游关系，并以一条代表性内容链验证，而非全站重做
- 推荐结论：本稿只回答“为何这样体验、异常表达什么、什么不能受损”；具体封面、色彩、材料、框景、边线、污染接口与资产管线继续由独立美术蓝图负责

#### REC-07 原因

宏观体验和具体美术必须结合，但不能成为两个重复事实源。若两份草稿未来均获采纳，宏观指导位于产品、叙事和世界内编辑语义的上游；美术蓝图以该目标选择表现方法。封面的一种印版工艺不能反向成为所有页面唯一的故事解释，视觉效果也不能新增未经批准的访客目标、污染状态或内容事实。

| 对象       | 本稿规定的宏观意义                                       | 待批准美术草稿或未来实现负责的具体形式         | 始终保护的结果                                            |
| ---------- | -------------------------------------------------------- | ---------------------------------------------- | --------------------------------------------------------- |
| 文本与口吻 | 谁在说、为何说、首次与二次阅读如何变化                   | 具体文案、排版层级和国家版本表达               | 任务状态直接；说话者、文种和不可靠性可理解                |
| 剧目与图像 | 图像应支持节目、角色、地点或档案关系，不只是填充恐怖气氛 | 封面题义、构图、色系、边框、记忆色和裁切安全区 | 不复制原作素材；HTML 标题、替代文本与本地化不依赖图中小字 |
| UI 与排版  | 文书类型和信息层级应由语义结构体现                       | 具体框景、纸面、题签、网格和组件状态           | 导航、搜索、票务、焦点、对比度和 320px 视口稳定           |
| 污染       | 档案从被观看对象逐步显露为主动编排者                     | 具体印版、侵入方向、纹理、变体和静态分镜       | 只改呈现与叙事变体，不改 DOM 语义、布局计算和稳定事实     |
| 动效       | 用户动作后只发生一次有因果的阈限、揭示、遮蔽、越界或回返 | 具体时长、曲线、遮罩、帷幕、焦点或印版动作     | 结束后静止；减少动态效果直接得到同一最终信息              |
| 本地化     | 所有可见异常文本和替代内容都是国家版本内容               | 翻译包、字体回退、排版和发布门禁               | 不在客户端写死炎语，不用缺译作为叙事污染                  |

本稿不为自动音频、设备感知、个人化、远端请求或新依赖提供依据。游戏 UI 中的层、节点、战斗、部署、希望、生命、藏品、源石锭和机制数值只可作为内部研究语境，不能出现在泰拉剧团官网的访客界面；幻觉名称也不应用作访客心理标签。

#### REC-07 最小落地

若本稿与美术草稿未来均获正式迁移，先使用 REC-06 的一条代表链完成以下顺序：

1. 在无污染状态确认两站任务和内容声音成立；
2. 用静态分镜确认一条语义关系在 `0—3` 中逐级显露；
3. 由美术蓝图选择最小视觉实现，不用额外效果补救内容空缺；
4. 在当前国家版本、本地化预览、窄屏、键盘、无 JavaScript 和减少动态效果条件下检查同一结果；
5. 只有代表链成立后再覆盖同类页面，不逐页添加特例。

#### REC-07 可观察验收

- 评审者能分别指出宏观目标和具体美术方案，不在两个文件找到相反或重复的产品事实；
- 代表链在没有视觉异常时可信，在加入视觉方案后更清楚表达同一意义，而不是依靠效果制造新剧情；
- 关闭动画、使用键盘或窄屏不会失去任何叙事必要信息、任务反馈和退出；
- 所有新增显示内容都有当前国家版本来源，不通过缺译、乱码或字体故障制造污染。

#### REC-07 非目标

- 修改、批准或合并 `docs/drafts/blueprint/folio-production-visual-language.md`；
- 在本稿中复制调色板、13 项封面解剖、猩红印版层次、边框密度或资产字段；
- 因为宏观方向已经清楚而跳过后续人工正式迁移和一次性开发计划。

## 待解决问题
