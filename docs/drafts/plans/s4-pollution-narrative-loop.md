# S4 里站污染叙事闭环一次性开发计划

- 文档类型：一次性开发计划
- 状态：已批准执行
- 规划效力：只约束 S4 的实施顺序、范围收口与验收，不覆盖 active 正式蓝图
- 分析基线：已验证的 S3 炎国双站等级 `0` 页面与搜索；`BP-FND-CORE`、`BP-FND-EXPERIENCE`、`BP-FND-NARRATIVE`、`BP-MOD-ARCHIVE`、`BP-MOD-SEARCH`、`BP-I18N-CORE`、`BP-QLT-STAGES`
- 目的：在不破坏 S3 等级 `0` 网站的前提下，实现当前标签页内四级污染状态、五类白名单触发的单次判定、稳定声明式变体、历史恢复和可靠清除，使表站发现到里站浏览再到退出形成完整叙事主线
- 非目标：修改里站源内容或搜索归属、实现异常购票或表站票务、加入第二国家版本、遥测、Cookie、服务端状态、持续闪烁、强制全屏或随机 DOM 破坏

## 正文

### PLAN-04｜S4 里站污染叙事闭环

- 状态：已批准执行
- 正式依据：`BP-FND-CORE`、`BP-FND-EXPERIENCE`、`BP-FND-NARRATIVE`、`BP-MOD-ARCHIVE`、`BP-MOD-SEARCH`、`BP-I18N-CORE`、`BP-QLT-STAGES`
- 范围：污染纯状态与标签页存储适配、表里与里站导航触发、里站搜索触发、等级应用、稳定变体、受控污染槽位、四级视觉与叙事呈现、自动化状态模拟及追踪映射
- 完成条件：从表站进入、直接进入、里站导航、未来语言切换适配点和搜索提交各自至多判定一次；等级以固定 `42%` 单调升至 `3` 并在标签页内稳定，刷新与历史恢复不追加判定，返回表站清除；任意等级不改变语义、焦点、搜索范围、视口安全、减少动态效果、页脚声明与退出

#### PLAN-04 执行前提

1. S4 只在 `dev_code` 修改功能源码；用户已授权本阶段自动开发与两个职责分支之间的提交、推送和合并。功能修改前按实际路径运行 `npm run blueprint:where -- <路径...>`。
2. S3 等级 `0` 是脚本失败、状态存储不可用和新标签页初始状态的稳定基线；污染模块不得成为页面内容、导航、搜索或退出的前置条件。
3. 污染状态只存在于 `sessionStorage`，不进入 URL、HTML 构建内容、Cookie、服务端或跨标签通信；存储读写异常立即退化为等级 `0`。
4. 本轮只有 `yan / zh-CN` 可发布，因此语言切换没有可见选项；仍以显式触发类型和未来链接标记保留一次判定接口，不创建未发布语言页面或占位选择器。
5. 不建立生产调试 UI。纯状态函数允许在本地自动化模拟时注入随机值；正式构建只调用浏览器随机源，不输出等级增减控制。

#### PLAN-04 状态与导航边界

- 污染等级类型固定为 `0 | 1 | 2 | 3`；固定概率 `0.42` 由状态模块单一常量拥有。等级 `3` 不再调用随机源。
- 标签页状态至少保存版本、等级和稳定变体种子；读入未知、损坏或越界值时返回新等级 `0` 状态，不信任任意 JSON。
- 从表站点击历史快照入口时先请求 `front-entry` 判定并记录目标；目标里站页面只消费该导航标记，不重复执行 `direct-entry`。
- 直接 URL、书签或外部链接在正常 `navigate` 导航中请求一次 `direct-entry`；`reload` 与 `back_forward` 不请求判定。
- 普通主按钮、Ctrl/Command/Shift/Alt 点击、新窗口、新标签页、下载、站外链接和同页锚点不修改当前标签页状态；新标签页按自己的直接进入规则开始。
- 里站普通内部链接在当前页离开前请求一次 `archive-navigation` 并记录目标；目标页消费标记，避免二次判定。标记只对短时且目标匹配的正常导航有效。
- 里站搜索提交在当前搜索页请求一次 `archive-search` 并立即更新呈现；随后点击结果属于新的里站导航。未来国家版本链接使用 `archive-locale`，并由同一点击适配器保证不再执行普通导航判定。
- 任意表站页面加载与里站返回表站入口都清除污染状态；浏览器历史再次进入里站时恢复等级 `0` 且不追加判定。

#### PLAN-04 呈现边界

| 等级 | 最小呈现结果                       | 允许手段                                 | 禁止影响                     |
| ---- | ---------------------------------- | ---------------------------------------- | ---------------------------- |
| `0`  | 保持 S3 原始快照                   | 无污染规则命中                           | 无                           |
| `1`  | 少量可疑痕迹，仍可被理解为页面瑕疵 | 细划线、局部重复墨迹、海报轻微痕迹       | 文本可读性、点击目标、布局   |
| `2`  | 多处明确异常和内容矛盾感           | 受控涂黑、红叉、局部替代提示、色彩侵入   | DOM 语义、替代文本、搜索事实 |
| `3`  | 明显叙事侵入和局部失真             | 强化已有痕迹、轻微受控错位、稳定异常文案 | 导航、退出、页脚、焦点、视口 |

- 页面只为海报、节目登记、首页邀请、内容标题和搜索结果等少量真实区域声明 `data-pollution-slot`；不为每个元素添加形式化标记。
- 状态只写入根元素的等级和稳定变体属性。CSS 或现有 DOM 中的装饰性异常节点据此呈现，不删除内容、不改变元素角色、不重排键盘顺序。
- 里站返回入口、表里切换入口和整个页脚置于稳定层；主导航可以出现视觉痕迹，但链接文本、位置与可点击区域保持稳定。
- 异常文案只作为补充叙事，不替代任务信息；装饰性文案从辅助技术隐藏。减少动态效果关闭所有非必要位移和转场，但保留静态等级差异。
- 小于等于 620px 时取消污染造成的几何位移，只保留不导致溢出的颜色、划线和叠印；任意等级不得新增页面级水平滚动。

#### PLAN-04 自动化与失败收口

- 纯状态模拟直接调用正式状态函数，不在测试中重写一套概率逻辑。至少验证固定失败序列保持等级、固定成功序列逐级到 `3`、封顶后随机源不再执行、非法存储回退为 `0`。
- 理论概率沿用正式门禁：十次独立 `42%` 判定中至少三次成功的概率约为 `86.2839%`。实现检查只证明配置值与纯函数行为一致，不重复建立统计事实源。
- 浏览器原生存储、Navigation Timing 或随机源不可用时不得阻断页面；控制器捕获边界错误并保持或恢复等级 `0`。
- 若无法可靠区分一次导航的来源，优先不追加判定并保持浏览，而不是冒险重复升级。短时目标标记只解决已知的表站入口和里站内部导航。

#### PLAN-04 最终验收矩阵

1. `npm run verify` 通过；新增功能源码具有追踪映射；运行时不读取 `docs/`。
2. 纯状态模拟覆盖四级、42%、封顶、单调性、损坏回退和稳定变体；十次达到等级 `3` 的门禁结论保持成立。
3. 表站进入、直接进入、里站导航、语言适配和里站搜索五类触发均连接同一判定接口；一次动作不会被两个监听器重复处理。
4. 刷新、前进、后退、同页锚点、输入搜索字符与页面重渲染不增加等级；返回表站后状态清除。
5. 等级 `0`～`3` 不改变 URL、canonical、robots、搜索索引条目、目标链接或底层内容。
6. 里站导航、搜索、详情、不可购票页和返回在无 JavaScript 时仍可用或有明确降级；脚本故障不留下遮罩。
7. 320px 起无新增横向丢失；键盘焦点、可访问名称、页脚声明、返回入口和减少动态效果保持稳定。
8. 静态产物不包含污染调试按钮、等级增减接口或只靠 CSS 隐藏的开发控制；不包含 S5 票篮与交易流程。

#### PLAN-04 停止与回退条件

- 若实现要求修改 URL、服务器、Cookie、跨标签通信、搜索索引事实或里站等级 `0` 内容才能维持状态，停止扩大并返回 `dev_blueprint`。
- 若某个污染效果无法在 320px、键盘或减少动态效果下保持稳定，删除该效果而不是为其增加补丁链。
- 若同一动作无法可靠防止两次判定，先取消次要触发适配并保持一次明确判定，不用去重日志或延时锁掩盖设计问题。
- 单个呈现变体失败时保留状态机和已验证的较低等级效果，不随机修改 DOM 补足“恐怖感”。
