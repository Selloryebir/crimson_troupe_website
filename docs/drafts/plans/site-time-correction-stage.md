#### PLAN-01 切片原则

时钟、快照、场次 ID、九语言记录键与 Astro 静态路径相互构成构建闭包。单独提交其中一层会产生错误分类、缺失本地化键或无效详情 URL；因此 `TIME-01` 是本计划唯一的源码切片。它不是把多个独立功能压进一个提交，而是避免为制造切片而引入新旧 ID 双写、兼容适配器或临时错误产物。
