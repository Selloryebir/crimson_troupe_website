## 正文

### PLAN-06｜S6 简体中文双站候选加固

- 状态：已批准执行
- 正式依据：全部 active 正式蓝图，重点为 `BP-FND-CORE`、`BP-FND-EXPERIENCE`、`BP-FND-NARRATIVE`、`BP-MOD-SEARCH`、`BP-MOD-PROGRAMS`、`BP-MOD-ARCHIVE`、`BP-MOD-TICKETING`、`BP-I18N-CORE`、`BP-QLT-STAGES`
- 范围：现有表站、1091 里站、搜索、污染、票务、跨页面导航、响应式与减少动态效果、构建产物、源码追踪及当前阶段说明
- 完成条件：五条旅程在现有发布范围内没有断路；状态机和构建产物检查可重复；只修复审查确认的问题；正式产物仅含 `yan / zh-CN`；阶段与仓库说明反映真实实现；浏览器能力不足时明确保留未验证项

#### PLAN-06 执行约束

1. S6 只在 `dev_code` 产生功能源码改动；修改前对实际路径运行 `npm run blueprint:where -- <路径...>`，新增、删除或重命名功能源码时同步追踪表。
2. 审查结论必须定位到 active 蓝图、调用关系或可观察产物。没有证据的问题不制造改动；纯审美偏好、跨阶段优化和未来扩展不进入本轮。
3. 允许删除已经确认无调用且不承担契约的遗留源码与样式；不以 S6 为由拆分大型文件、改用新框架或建立平行内容源。
4. `docs/drafts/creative/archive-anomalous-ticketing.md` 继续保持未采纳，不进入实现、测试数据或预留分支。第二语言和未发布国家版本不得进入页面树或语言选择器。
5. 日常诊断只运行相关检查；跨层修正完成后运行一次完整 `npm run verify`，不得在同一轮重复执行其已包含的质量或构建门禁。

#### PLAN-06 五条核心旅程

1. 表站首页 → 本季或历史演出 → 场次/剧目详情 → 票务入口；
2. 表站首页或内页 → 剧团/搜索 → 内容详情或明确无结果反馈；
3. 表站彩蛋入口 → 1091 首页 → 里站浏览 → 返回同国家版本表站首页；
4. 直接访问 1091 深层页面 → 里站搜索与污染升级 → 浏览器历史恢复或主动退出；
5. 表站票篮 → 失败/波动重试或成功 → 存单与逐场纪念票 → 下载、打印或退出。

#### PLAN-06 候选验收矩阵

1. `npm run verify` 一次通过，构建产物只包含炎国简体中文双站及根路径跳转；所有功能源码存在有效追踪映射。
2. 五条核心旅程的目标 URL、链接、返回路径、页面标题和失败反馈在静态产物中成立；搜索结果不会跨语言或跨世界。
3. 只有 `/yan/` 可索引；其余页面均为 `noindex,follow`。每页 `lang`、canonical、尾斜杠、本地资源与 ID 唯一性正确。
4. 表站与等级 `0` 里站在无 JavaScript 时核心内容可读；票务脚本未启用或初始化失败时显示“暂未开票”；污染失败时退化为等级 `0`。
5. 污染固定 `42%`，等级只增不减并封顶；五类触发各至多判定一次；主动返回清除状态；正式产物没有调试控制。
6. 票务五种结局可确定性到达；失败、波动、线路返回与重试保持票篮；成功结果冻结；存单、逐场票面、SVG 和打印读取同一结果且不包含身份或真实交易能力。
7. DOM 与 CSS 结构支持最低 320px、键盘焦点、触控操作和 `prefers-reduced-motion`；若当前环境存在可用浏览器，则补充代表性视口与交互遍历，否则明确记录为人工验收前的未验证项。
8. 页面不加载第三方脚本、遥测或运行时远端资源；CRE-01、未发布语言及其入口不进入产物。
9. 只删除能够证明无调用、无运行时作用且无蓝图职责的遗留文件或规则；不为候选标签进行无关重构。

#### PLAN-06 停止与回退条件

- 若发现问题必须改变用户目标、正式状态边界或已确认内容才能修复，停止该项源码扩张并返回 `dev_blueprint`；不在代码分支擅自改写契约。
- 若某项验证需要新增后端、真实交易、身份数据、远端服务或大型端到端框架，保留现有静态能力并将该项标记为未验证，不扩大依赖面。
- 若无法取得浏览器引擎，不把 HTML/CSS 静态检查描述为视觉或完整键盘验收；候选可部署结论与人工浏览验收结论分开报告。
- 若清理候选与动态引用存在疑义，保留该实现并记录判断，不以减少文件数量为目标。
