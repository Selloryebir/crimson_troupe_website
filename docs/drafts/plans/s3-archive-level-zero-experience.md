## 正文

### PLAN-03｜S3 炎国里站等级 0 体验

- 状态：已批准执行
- 正式依据：`BP-FND-CORE`、`BP-FND-DOMAIN`、`BP-FND-EXPERIENCE`、`BP-FND-NARRATIVE`、`BP-MOD-ARCHIVE`、`BP-MOD-PROGRAMS`、`BP-MOD-SEARCH`、`BP-MOD-TICKETING`、`BP-CNT-CORE`、`BP-I18N-CORE`、`BP-QLT-STAGES`
- 范围：炎国 1091 里站首页、本季与历史场次、场次与剧目详情、剧团、独立搜索、不可购票页；所需类型化内容、里站组件、等级 `0` 样式、渐进增强与追踪映射
- 完成条件：关闭或缺失污染脚本时，浏览者仍能从任一合法 1091 URL 浏览内容、区分场次与剧目、完成站内搜索、理解票务不可用状态，并可靠返回同国家版本表站首页；里站在内容、编排、媒介语言和浏览节奏上不是表站换色版本

#### PLAN-03 执行前提

1. S3 只在 `dev_code` 修改功能源码；本计划在 `dev_blueprint` 建立并同步后执行。用户已明确授权 S2～S6 自动开发、验证、提交、推送及两个职责分支之间的合并。
2. 开始功能修改前对实际候选源码运行 `npm run blueprint:where -- <路径...>`；新增、删除或重命名功能源码时同步维护 `docs/blueprint/traceability.json`。
3. 现有 1091 URL、`archive` 世界语义、`Production` / `Performance` 边界、canonical、robots、页脚返回入口与页脚非官方声明保持稳定；不得为年代感另建平行路由或复制表站实体事实。
4. 里站内容是概念站原创的 1091 公开网站内容，不暗示游戏官方事实。新增事实只服务于当前页面和搜索闭环，不扩写人物传记、剧情真相或尚未采纳的异常购票创意。
5. S3 所有可见异常均属于年代媒介表达，不得提前表现污染等级；删除、涂黑、错位、替换、红叉或随机失真留给 S4 的声明式变体。

#### PLAN-03 实施边界

- **等级 `0` 独立成立：** 以旧剧团当时面向观众的网站口吻写作，页面不自称“数字化校录中的不完整原型”。历史快照语境可以由存档外壳说明，但 1091 页面正文应像当时可用的网站，而不是现代管理员注释。
- **双集合有真实内容：** 至少建立一个 1091 本季 `Performance` 和一个 1091 历史 `Performance`，由独立 `Production` 组成；集合归属显式保存，不由浏览器时间推导。列表、详情和搜索读取同一来源。
- **年代视觉泰拉化：** 使用项目自有 CSS/HTML 图形、编号、栏线、纸张或印刷媒介暗示和较慢的信息节奏建立年代感，不直接套用现实早期互联网、具体印刷流派或故障录像语言。
- **搜索严格隔离：** 单独生成 `yan:archive:1091` 构建期索引，浏览器只接收该索引；不加载表站索引后过滤。S3 搜索提交不执行污染判定，该协作接口在 S4 接入。
- **票务始终不可用：** 所有 1091 场次只链接到同国家版本里站票务页；页面以历史快照语境说明席位登记已经结束，不建立票篮、价格或纪念票。
- **共享改动最小化：** 只有两个世界确实共享的无障碍、路由或基础令牌才修改共享源码。表站 S2 页面、搜索索引和视觉结果只接受回归修正，不借 S3 重排。
- **无脚本与安全：** 普通浏览和详情依赖普通链接；筛选或搜索脚本失败时保留完整内容、范围说明和返回路径。不得加入远端请求、第三方脚本或个人信息输入。

#### PLAN-03 内容与实现收口

- 1091 内容可使用少量项目原创名称和事实形成完整页面，但不得复用表站“现在”的场次、主创或机构文本来假装年代差异；同一旧剧目在多个旧场次复用时继续通过稳定 ID 关联。
- 页面可以说明它属于 1091 快照，但不应反复出现“尚未校录”“当前阶段”“数字化”等破坏当时网站身份的开发说明；真正缺失的功能使用当时语境下的明确状态。
- 搜索索引只派生稳定 ID、类型、标题、摘要、必要别名和目标 URL，不复制完整正文；表站与里站索引生成函数和客户端查询只有在不混合数据作用域时才共享。
- 里站可使用更密集编号、框线、对称构图、较小的运营信息块和项目自有图形建立媒介年代感；不得牺牲正文对比度、触控目标、焦点指示或视口安全。
- 不在 S3 创建污染插槽的空壳、随机配置、调试 UI 或异常文案占位；S4 根据已成立的页面语义选择少量真实槽位。

#### PLAN-03 最终验收矩阵

1. `npm run verify` 通过，新增功能源码均有追踪映射，运行时不读取 `docs/`。
2. 1091 首页 → 本季/历史 → 场次详情 → 剧目详情或不可购票页通过真实链接完成；任一里站页面可返回 `/yan/`。
3. 本季与历史集合相对 1091 明确且均有已发布内容；列表、详情、搜索使用同一实体和稳定 ID。
4. 里站索引只含 `/yan/archive/site/1091/` 目标；表站既有索引仍不含里站目标。
5. 全部里站页面为 `noindex,follow`，`lang`、canonical、路径和刷新直达正确；只有 `/yan/` 保持索引。
6. 无 JavaScript 时主导航、正文、列表、详情、不可购票反馈与退出可用；搜索显示直接的不可用反馈。
7. 代表视口无页面级横向内容丢失；键盘焦点、文本反馈和减少动态效果不依赖装饰。
8. 页面源码和产物不含污染等级、42% 判定、异常购票、第二语言或远端服务。

#### PLAN-03 停止与回退条件

- 若必须改变稳定路由、世界语义、领域边界、搜索范围或票务不可用契约才能继续，停止对应切片并返回 `dev_blueprint`，不在源码中另建规则。
- 若某项内容需要引用游戏既有剧情事实、特定角色原话或来源不明资产，保留当前页面结构并改用不冒充官方事实的原创内容或自有图形；不伪造来源。
- 若搜索需要跨世界索引、远端服务或大型依赖，保留范围明确的无脚本状态并停止扩大实现。
- 单个切片失败时只修复当前切片，不堆叠 S4 污染功能或保留并行入口掩盖问题。
