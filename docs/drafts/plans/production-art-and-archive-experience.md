#### PLAN-01 执行前门禁

- 本计划在人工明确授权前保持“候选”，不得据此修改正式蓝图、源码、Git 分支或远端状态；
- 获得本阶段自动执行授权后，先在 `dev_blueprint` 完成 `BP-00`。只有新视觉蓝图已注册为 `active`、既有蓝图已消除冲突、`blueprint:check` 通过且影响定位完成，才可把下一源码切片标记为“已批准待同步”；
- `ART-00` 是本阶段唯一主观人工方向门。它只审查代表性生成封面、双时间层关系、`0—3` 分镜和克莱布拉松三语请柬，不拆成逐图或逐页审批；方向通过后，后续扩展与客观缺陷修复由智能体连续完成；
- `CODE-01—CODE-06` 均是独立源码切片，分别形成至少一个仅属于本切片的 `dev_code` Conventional Commit，并逐项完成“同步到 `dev_code` → 实现、验证、提交及推送 → 回到 `dev_blueprint` 复核并收口”；具体 Git 操作遵守长期指南，不在本计划复制另一套流程；
- `BP-00`、`ART-00` 与 `CLOSE-00` 不是源码切片，不制造 `dev_code` 空提交。若最终验证发现实质缺陷，先在 `dev_blueprint` 将其归入受影响的既有切片或新增一个边界明确的修正切片，再进入 `dev_code`，不得塞入无定义的“收尾提交”。

##### ART-00｜唯一人工艺术方向门

- 生成输入只使用正式剧目视觉蓝图和作者指南的文字结论，不把本地参考图送入生成流程；复杂中央艺术使用无文字位图，标题、导航、按钮和正文继续由 HTML/CSS 承担。
- 代表集固定包含：`der-ring` 的表站对照与里站等级 `0` 候选、一个不进入产品事实源的陌生标题、同一代表浏览链的 `0—3` 四帧、等级 `3` 克莱布拉松请柬的炎语/东国语/哥伦比亚语候选。
- 人工只需一次判断：是否近似复制参考素材；是否能识别同一剧目不同时间层；污染是否从出版物有因果地进入页面；请柬是否建立心理惊悚且不退化为通用恐怖网站。未通过时只调整对应候选，不修改稳定蓝图和无关源码。
- 通过后仅把实际采用的里站 `der-ring` 资产移入运行时；表站对照、陌生标题和过程稿继续作为本地临时验证材料，并在 `CLOSE-00` 精确删除。不得删除人工原有的其他本地参考资料。

##### CODE-02｜视觉资料和代表资产管线

- 用一个最小、类型化资料替代继续扩张 `moon / flame / snow / banquet / lantern / masks` 的做法。运行时只保存实际需要的资产引用、时间层、焦点、裁切安全区、记忆色、污染接口、替代文本意图和权利来源；作者分析字段不发送到浏览器。
- 图片声明明确尺寸和响应式候选，采用仓库支持的现代压缩格式；非首屏懒加载。本地化标题不烧录进图像，三语共用无文字母版。
- 先让 `der-ring` 的里站列表和详情消费新管线，证明组件接口、窄屏裁切、替代文本和等级 `0` 装帧成立；旧通用视觉只有在失去全部消费者后才删除。

##### CODE-03｜表站整体艺术覆盖

- 为 `uncrowned`、`caged-fire` 与 `second-snow` 生成题义不同、记忆色不同且属于同一出版制度的表站正式资产；不为当前未被场次引用的三个原创剧目生成无消费者素材，也不删除其数据。
- 通过环境、内容表面、舞台焦点、裁切、留白、框景和原创方形品牌标更新表站；现有首页、本季、历史、场次详情、剧目详情、剧团、搜索与票务任务全部覆盖。
- 优先修改令牌、页面模式和可复用组件，不逐路由复制装饰；不新增人物实体或肖像来满足人物框示例，不改票务小游戏流程和纪念票契约。

##### CODE-04｜里站等级零整体艺术覆盖

- 为 `der-ring`、`one-hundred-and-one-days`、`the-carnival` 与 `ode-au-triomphe` 完成其里站等级 `0` 正式资产；四者保留独立隐喻和记忆色，猩红装帧不成为统一黑红滤镜。
- 通过深廊、旧纸阅读岛、仪式轴线、嵌套框景、旧金内线和闭合猩红印版更新里站八类页面；等级 `0` 静止、完整、可查阅，不显示运行时故障或克莱布拉松。
- 表站与里站可以共享品牌谱系、语义基础和必要组件接口，但不能收敛为同一布局换色；不改变页面数量、导航任务或不可购票结论。

##### CODE-05｜污染编排与视觉呈现

- 保留 `pollution-state.ts` 已有 `0—3`、固定 `42%`、三种稳定变体、五类触发和标签页生命周期；只有发现与 active 蓝图不符的客观缺陷时才做等价修复。
- 按“页面类型 × 等级 × 稳定会话变体”建立最小确定性编排资料，页面显式提供可污染槽位、保护区和侵入边界；不创建按幻觉编号拆分的状态、组件或 CSS 套件。
- 等级 `1` 使用局部错版与登记痕迹，等级 `2` 使用档案层叠和空间关系失序，等级 `3` 先建立可供请柬投影接管的环境骨架；视觉副本不接收焦点或指针，真实交互层不旋转、镜像或位移。
- 删除通用删除线、红叉、三条全屏线、统一饱和度滤镜、真实文字容器位移和“请不要回头”孤立警告，并同步删除失去消费者的组件属性和三语消息。无 JavaScript 时完整显示里站等级 `0`。

##### CODE-06｜等级三叙事投影

- 建立独立、类型化且本地化的投影内容，以稳定页面职责和实体 ID 关联，不写死在 CSS 或客户端脚本，也不改源 `Performance`、`Production`、URL、搜索索引和翻译完整度。
- 首页、演出列表、场次详情、剧目详情、剧团、搜索和不可购票页分别呈现同一请柬主轴的不同侧面；本季与历史演出共用列表职责，但保留各自集合、条目数量和合法链接。
- 等级 `0—2` 不出现克莱布拉松演出信息；等级 `3` 才显示林地城堡、统一演出和请柬关系。视觉投影可以改变访客所见摘要和说明，链接始终指向原有合法实体。
- 炎语、东国语和哥伦比亚语具有等价投影、可访问名称和排版；不得以缺译、乱码、伪系统错误或字体故障制造污染。

##### CLOSE-00｜完整验证、追踪收口与清理

- 在同一最终验证轮只运行一次 `npm run verify`；三语言预览另运行预览构建及其产物门禁，因为它与默认正式构建的国家版本范围不同，不在前后重复完整质量或默认构建。
- 浏览器矩阵覆盖炎语、东国语和哥伦比亚语的表里站代表页，320/390、768、1280 视口，键盘、触控、减少动态效果、无 JavaScript、直接 URL、搜索、票务、语言切换、浏览器前进后退、污染等级和返回表站。
- 核对七个可见剧目和八类页面没有旧通用几何或廉价污染残留；核对所有生成资产来源、尺寸、替代文本、懒加载和非首屏加载策略；确认没有参考原图、过程图、截图或候选进入 Git。
- 若检查无问题，更新必要的实现状态和追踪关系，删除本计划及智能体在 `ART-00` 新建的未采用候选目录，提交并推送最终 `dev_blueprint` 收口；停止在 `dev_code -> dev` 之前等待人工验收与授权。
