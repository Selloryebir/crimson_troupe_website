本文件只保存国家版本徽章的来源身份、可核验范围和权利边界，不定义选择器行为、项目配色或制作步骤。项目采用的几何和制作规范位于 `docs/guides/realm-badge-authoring.md`，非运行时上色候选位于 `docs/project/realm-badge-color-previews/`，运行时资产位于 `src/assets/realm-badges/`。

## 本地视觉来源与许可边界

人工在本地忽略目录 `local-reference-materials/realm_badge/` 提供了炎、维多利亚、乌萨斯、叙拉古、米诺斯、莱塔尼亚、卡西米尔、东与哥伦比亚九枚官方徽章参考图，并明确声明这些图片属于获官方授权使用的开放素材，可以用于本项目的再实现。原始文件均为 `510 × 510`、sRGB、带透明通道的单色 WebP。

本项目只提交依据参考重新实现的项目素材，不提交本地原图。人工声明解决了本次使用授权，但当前没有额外的公开许可链接、署名条款或原图再分发授权记录；因此原图继续只存在于本地忽略目录，也不能因本记录存在而进入仓库。

## 维护顺序

1. 本文件只更新来源、许可和可核验事实边界；来源冲突保留并交由人工判断，不静默选择。
2. `docs/guides/realm-badge-authoring.md` 负责把已确认来源转为项目几何、配色候选和制作规则，不得把项目推导回写成官方事实。
3. `docs/project/realm-badge-color-previews/` 只保存非运行时项目候选；`src/assets/realm-badges/` 只保存已批准的运行时单色母版。
4. 若获得官方矢量源、正式色彩规范或更明确许可，应先更新本文件，再判断是否需要修改指南、项目候选、蓝图或运行时资产。
