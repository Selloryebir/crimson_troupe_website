# 泰拉术语来源与已见形式

本目录保存2026-09-15术语研究实际使用的来源登记及逐语言已见形式。它不参与运行时，不构成正式译文采纳，也不把社区百科变成官方资料。研究释义、关联与非官方候选位于[研究目录](../../research/terra-terminology/README.md)。

## 唯一责任文件

| 文件                                           | 责任                                                                       |
| ---------------------------------------------- | -------------------------------------------------------------------------- |
| [sources.json](sources.json)                   | 来源ID、标题、链接、发布主体、语言、材料类型、实际读取方式、访问日期和限制 |
| [attestations.json](attestations.json)         | 已见词形、概念ID、locale、来源等级、具体栏目定位及异写说明；不含AI翻译候选 |
| [原活页来源](../official-folio-productions.md) | 13项活页标题与中文原文的既有唯一来源；本目录不复制、不改写                 |

`GEO-*`、`ORG-*`、`WORLD-*`等前缀只是研究分工来源编号，不是可信度排序。多个编号可以指向同一URL并记录不同读取范围；这不算多条独立佐证。实际唯一URL数由研究检查器统计。`form_id`是一次词形证据记录；同一词形可有不同强度的多条记录，不能因文本重复删除较强证据。

## 读取字段

- `official_site`：发行方或正式改编作品的页面。媒介范围见notes；动画页面只能支持实际出现的形式，不能自动覆盖游戏剧情。
- `game_text_mirror`：非官方站点明确转载的游戏正文或出版目录；只采纳定位到的词形，不将攻略说明或目录外未读正文标为官方。
- `community_wiki`：社区整理、语言栏、考据和说明。即使内容可信，也不默认表示已与官方客户端核对。
- `local_approved`：项目既有作者资料，仅证明项目曾保存该形式，不证明游戏官方采用；URL字段在此使用仓库根相对路径。

读取方式另列为`full`、`search_excerpt`、`blocked`、`local`。`search_excerpt`也可能包含较长的索引正文，但仍不是本轮成功打开全文。只读到页面标题不支持其全部故事；完全不可见的来源只能留作追索，不可成为某词形的唯一证据。

`official_direct`只表示词形直接出自发行方页面，不替代access。`official_reproduced`表示明确转载的原文形式；`community_reference`保留社区所见；`project_approved`仅对应已有项目选择。缺失语言没有伪造记录；冲突形式也没有静默改成所谓标准形。

## 代表性锚点

- 中文基础名词：[鹰角功能介绍](https://ak.hypergryph.com/protocol/application)，支持矿石病、源石、罗德岛、阿米娅、整合运动等实际形式。
- 英日机构及角色名称：[国际服制作人问答](https://www.arknights.global/news/443?list=true)、[日服制作人问答](https://www.arknights.jp/news/147)。名称证据不扩大成全部机构沿革证明。
- 新任酒神与Miss.Christine：[国际服活动公告](https://www.arknights.global/news/1955)、[日服活动公告](https://arknights.jp/news/1953)。现实公告日期不是泰拉事件日期。
- 通用概念原文转载：[PRTS加载贴士](https://prts.wiki/w/Tip)。仅明确加载文本部分按转载登记。
- 广域跨语言索引：[PRTS泰拉词库](https://prts.wiki/w/泰拉词库)与各Arknights Terra Wiki词条。词库标注出版方并不能代替每条原文定位；跨站搬迁镜像不构成独立证据。

完整链接以sources.json为准，词形具体支持段落以attestations.json的locator为准。更名、人员更替、地区归属和剧透可知性仍由研究上下文约束，不从词形表推导。
