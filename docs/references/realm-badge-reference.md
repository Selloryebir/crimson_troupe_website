# 国家版本徽章参考与转译边界

记录日期：2026-08-21

本文件只记录国家版本徽章设计所依据的参考关系、使用边界与来源层级，不定义选择器当前行为，也不代替正式蓝图、创作指南或运行时素材。

## 本地视觉参考

人工在本地忽略目录 `local-reference-materials/realm_badge/` 提供了炎、维多利亚、乌萨斯、叙拉古、米诺斯、莱塔尼亚、卡西米尔、东与哥伦比亚九枚官方徽章参考图，并明确声明这些图片属于获官方授权使用的开放素材，可以用于本项目的再实现。原始文件均为 `510 × 510`、sRGB、带透明通道的单色 WebP。

本项目只提交依据参考重新实现的项目素材，不提交本地原图。再实现必须保留主体轮廓、构图关系、负形与缩小识别点，不擅自把徽章改造成统一盾徽或以现实国家标志替代。人工声明解决了本次使用授权；当前没有额外的许可链接、署名条款或再分发原图授权记录，因此原图继续只存在于本地忽略目录。

## 证据层级

1. 本地参考图决定徽章的主体轮廓、构图、负形和焦点，不由上色方案改写；
2. 官方公开材料限制国家语义和颜色联想，但不被解释为官方色标；
3. 项目草稿和作者指南负责把前两层转译为可制作规则；
4. 正式蓝图只保存选择器结果、素材边界和验收条件，运行时实现只消费已批准素材。

若后续获得官方矢量源、正式色彩规范或更明确的许可条款，应优先更新本文件，再判断是否影响作者指南、正式蓝图或运行时资产，不静默覆盖已有来源说明。
