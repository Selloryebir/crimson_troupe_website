# 参考资料

本目录记录外部网站、设定资料、视觉研究和素材许可。参考资料只支持设计与内容决策，不直接作为网站运行时输入。

## 当前记录

- [`design-reference.md`](design-reference.md)：维也纳爱乐、Royal Ballet and Opera 的能力分析、泰拉化转译与明确排除项。
- [`production-title-reference.md`](production-title-reference.md)：人工确认的 13 项活页剧目三语标题、稳定 `productionId` 映射及使用边界。
- [`performance-location-reference.md`](performance-location-reference.md)：演出地点候选池、跨语言名称、地点性质与内部创作备注。
- [`realm-badge-reference.md`](realm-badge-reference.md)：九个国家版本徽章的本地参考边界、官方设定依据及项目转译限制。
- [`realm-badge-color-previews/`](realm-badge-color-previews/)：与单色母版共用几何的九枚上色视觉候选，仅供非运行时比较。
- [`ticketing-gameplay-reference.md`](ticketing-gameplay-reference.md)：票务小游戏拓展使用的游戏设计、现实票务、可访问性与设定来源，以及抽象转译和排除项。
- [`victorian-visual-reference.md`](victorian-visual-reference.md)：维多利亚设计改革、剧场印刷、现实机构与《红丝绒》活动语境在正式双站视觉系统中的转译和排除项。

## 新增要求

- 记录可访问的公开来源链接、访问日期和使用目的；
- 区分事实摘录、设计观察、推断与原创转译；
- 只记录参考关系，不把未获蓝图采纳或未在源码成立的设想写成当前功能；当前实现变化时删除过期实现宣称，不把本目录维护成第二份产品说明；
- 不保存无使用权的第三方原图、字体、音频、视频或源代码；
- 若引入可用资产，记录许可、署名要求、原始来源和项目内路径；
- 来源冲突写入备注，不静默选择对当前方案更方便的版本。
