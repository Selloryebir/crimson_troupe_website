# 参考资料

本目录记录外部网站、设定资料、视觉研究和素材许可。参考资料只支持设计与内容决策，不直接作为网站运行时输入。

## 当前记录

- [`design-reference.md`](design-reference.md)：维也纳爱乐、Royal Ballet and Opera 的能力分析、泰拉化转译与明确排除项。

## 新增要求

- 记录可访问的公开来源链接、访问日期和使用目的；
- 区分事实摘录、设计观察、推断与原创转译；
- 不保存无使用权的第三方原图、字体、音频、视频或源代码；
- 若引入可用资产，记录许可、署名要求、原始来源和项目内路径；
- 来源冲突写入备注，不静默选择对当前方案更方便的版本。
