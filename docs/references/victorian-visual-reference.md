## 设计合理性

1. Aesthetic Movement 以线条、几何、协调色彩和审美自主回应工业时代的庸俗与物质主义；Arts and Crafts 则更直接批评机器主导生产造成的品质与劳动问题，以及忽视材料的过度装饰。二者立场不同，但都能支持“有时代依据而不等于繁复堆饰”的设计目标。
2. Owen Jones 的现代设计语言同样从比例、用途和统一关系出发，因此本实验选择构件语法而非历史图案拼贴；这不代表采纳他的具体跨文化图形。
3. 剧场海报史说明宣传图像与节目事务信息逐渐分工；这与本站既有 `Production` 视觉和 `Performance` 日期、地点、票务事实的领域分离相容。
4. Royal Opera House 的历史建筑持续承担当代工作剧院职责，支持表站把历史材料当作机构连续性，而不是让现代服务页面表演古老。
5. 「傀影与猩红孤钻」主题官网可支持克莱布拉松古堡、登记处、告示栏、活页剧目与区域性幻觉等抽象语汇；《红丝绒》官方页面可支持电影片场与演出语汇并置。二者都不能证明本站双时间层、网站污染、新旧剧团组织、色彩、登记制度或网页存在；这些仍是二次创作。
