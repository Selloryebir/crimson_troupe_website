# 设计参考与转译记录

记录日期：2026-08-18

本文件用于说明猩红剧团概念站参考了哪些公开网站能力、它们被如何转译，以及哪些内容被明确排除。目的不是证明视觉相似，而是让设计决策可追踪。

## 参考对象

- [Vienna Philharmonic / 维也纳爱乐乐团](https://www.wienerphilharmoniker.at/)
- [Royal Ballet and Opera / 英国皇家芭蕾舞团与歌剧院](https://www.rbo.org.uk/)

## 借鉴并转译的内容

### 1. 从品牌吸引到演出决策的连续路径

维也纳爱乐首页在机构介绍之外突出当前新闻、乐季亮点，并将观众引向完整音乐会日历。本站据此重新整理表站路径：

1. 用主视觉和剧团宣言建立品牌印象；
2. 紧接本季演出与实际日期；
3. 提供月份、巡演城市筛选；
4. 从剧目详情进入席位预约。

转译后的界面、演出名称、城市、日期和文案均为本站原创，并未复刻参考站的卡片样式或日历布局。

### 2. 可检索、可筛选的演出档案

维也纳爱乐的音乐会日历可按指挥、作曲家、地点等字段筛选，并把长期演出档案作为机构历史的一部分。本站采用了这种“结构化节目数据”的思路，但只保留符合当前原型规模的月份与城市筛选。

表站页脚原有的 CT–091 隐藏入口也因此获得了双重意义：对新剧团，它像严谨的馆藏编号；对旧剧团，它是档案系统被污染的裂缝。

### 3. 不同的观看方式

RBO 首页将内容区分为现场演出、影院放映、线上串流和其他活动。本站没有照搬这些频道，而是将其改写为泰拉世界内的三种抵达方式：

- 巡演剧场：完整舞台与现场乐团；
- 城市放映厅：跨移动城市同步转播；
- 源石讯道：演出后的限时延时观看。

这种区分让“泰拉人如何接触一家巡演剧团”更可信，也给旧剧团的“不明来源讯号”留下叙事接口。

### 4. 剧目详情的信息完整度

RBO 的剧目详情集中呈现观看方式、日期、地点、时长、语言、内容提示、剧情、主创和无障碍资源。本站借鉴的是这套信息责任，而非页面外观：

- 每部剧拥有独立的详情视觉；
- 明确列出日期、地点、时长和语言；
- 提供原创简介及主创名单；
- 标注强光、烟雾、频闪、低频等观演提示；
- 说明无阶梯席位、辅助听觉与字幕支持；
- 从详情直接进入预约流程。

### 5. 搜索作为服务，也作为叙事

维也纳爱乐提供全站搜索和多语言入口。当前原型没有制作不完整的语言切换，而是优先实现真正可用的站内搜索：支持演出、日期、城市、服务和剧团内容，并提供 `/` 快捷键。

搜索同时承担双时间层叙事：普通词汇返回表站信息；“091”“旧剧团”“失踪”等词汇会暴露一条不应存在的馆藏记录。

### 6. 视觉层面的抽象原则

两个参考站都把演出内容置于视觉中心，使用明确的标题层级、克制的机构导航、充足留白，以及编辑内容与事务信息之间的节奏变化。本站吸收了这些抽象原则，并继续使用自身既有的猩红、纸色、黑色系统和 CSS 舞台装置语言。

## 明确没有借鉴的内容

- 没有下载或使用参考站的图片、视频、图标、字体、Logo 或其他品牌资产；
- 没有复制参考站的 HTML、CSS、JavaScript、组件代码或接口；
- 没有逐字使用其标题、宣传语、剧目介绍或事务说明；
- 没有复刻其网格尺寸、页面顺序、动画参数或购票流程；
- 没有伪装成参考机构，也没有建立任何附属或合作关系；
- 当前站内表单仍是概念交互，不处理付款或真实个人信息。

## 后续使用规则

若继续参考其他文化机构网站，应追加记录：参考对象、抽象能力、泰拉化方式和排除项。任何官方图片、音频、字体或商标资产都不得因“参考”而直接进入仓库。
