## 责任与来源边界

本文件是当前 13 项活页剧目标题形式、官方简体中文描述及项目稳定 `productionId` 映射的唯一长期人员参考。标题和描述由项目负责人提供并人工确认，来源定位为《傀影与猩红孤钻》相关活页剧目；描述于 2026-08-29 固定，本次迁移不重新核验外部页面。运行时保存同范围的可机械验证来源记录，并由质量门禁核对已采用剧目的炎语标题及简介；后续若发现来源差异，先保留现有稳定 ID 与原记录，并交由人工确认修正，不静默覆盖。

本目录不参与网站运行。某条记录只有经过内容选择、补齐当前阶段所需字段并进入唯一运行时剧目注册表后，才成为可被 `Performance` 引用的 `Production`；保存标题与官方描述不表示已经排演、发布或限定所属时间层。

## 使用规则

- `productionId` 由 `English` 来源形式一次性转换为小写 kebab-case：保留词序与冠词、空格转连字符、移除撇号和不适合 ID 的标点。表中 ID 已冻结，不在运行时从显示标题生成，也不因显示标题勘误自动改写；
- 中文形式对应 `zh-CN` 来源，日文形式对应 `ja-JP` 来源，`English` 先作为未区分地域的 `en` 来源。`en-US`、`en-GB` 或其他国家版本仍需分别纳入其开发范围和审核门禁；
- 官方描述只固定本节的简体中文来源正文及原有段落、标点，不自动产生英文、日文或其他国家版本译文；任何翻译均须另行记录来源与审核状态，不得称为官方译文；
- 标题与描述记录不自动生成体裁、主创、场次、搜索结果或详情页。剧目一旦以 `folio` 进入运行时，炎语 `title` 和 `synopsis` 必须逐字采用本文件对应来源，其他国家版本 `synopsis` 必须忠实翻译该来源，并按本地化契约同步全部构建范围；
- `folio` 表示采用人工确认的活页标题及官方简体中文描述。没有直接来源依据的体裁、宣传短句、主创、观演提示、场馆和演出记录仍是概念站创作，不得描述为活动已经确认的事实；
- 页面和组件不自动为标题增加书名号。某段正文确有语法需要时，由该段文案自行加入标点，不回写标题数据。
