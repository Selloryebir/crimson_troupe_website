# 演出地点候选参考

## 责任与使用边界

本文件保存后续演出内容开发优先参考的地点候选池，不参与构建，也不是运行时白名单、发布清单或自动替换指令。候选池已经由人工确认完整；其他地点仍可在遵守相同来源、命名和内容审核边界后增加。

`LOC-SRC-*` 只用于本参考内定位，不是运行时 `locationId`。“是”表示表站与里站均可选，“等级 3 投影”表示只用于里站等级 `3` 叙事投影。候选被实际采用时仍须建立稳定运行时身份、完整国家版本内容和适用的内容成熟度，内部备注不得直接拼接进公开页面或搜索索引。

## 维护规则

- 中文名、英文名和本国语名是独立显示形式，不互相推导；来源差异或名称冲突保留在备注中，不静默覆盖；
- 地点类型可以在进入运行时后规范为多值枚举，但候选备注不能替代正式场馆、地址或国家版本文案；
- 扩展候选池只修改本参考；只有地点被实际内容采用或长期地点规则改变时，才影响运行时数据或正式内容蓝图。
