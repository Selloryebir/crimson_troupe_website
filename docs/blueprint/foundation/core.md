# BP-FND-CORE｜静态站点内核

## 用户结果

无论附加模组是否可用，用户都能打开一个内容可读、导航可信、可静态部署的表站。

## 边界

- 负责页面外壳、静态路由、全局资源入口和无 JavaScript 的核心可读性；
- 为组件、内容、脚本和样式提供明确依赖方向；
- 不负责具体剧目、搜索结果、档案情节或小游戏规则；
- 不因假设性的正式需求预建账号、后端、遥测或第三方运行时。

## 行为契约

- Astro 在构建期生成页面，浏览器交互使用原生 TypeScript 渐进增强；
- 页面装配可以依赖布局、组件和数据，客户端功能由唯一入口装配；
- JavaScript 失败时不得留下无法关闭的全页覆盖层；
- 新增多页面、API 或后端只在内容规模或真实服务需求成立后设计。

## Demo 基线

- 单一公开路由可以构建、部署和浏览；
- 表站核心内容无需客户端脚本即可阅读；
- 现有功能通过显式模块初始化。

## Formal 增量

- 根据真实内容规模决定路由和内容集合，不同时维护两个事实源；
- 只有接入真实预约或发布服务时才增加网络、隐私和故障契约。

## 验收

- 移除一个非核心客户端增强不会破坏表站阅读；
- 构建产物不依赖 `docs/` 作为运行时输入；
- 全局装配和依赖方向与架构文档一致。
