# BP-FND-NARRATIVE｜双时间层与污染状态

## 用户结果

用户能够通过正常页面导航在表站与 1091 里站之间切换，并在里站经历逐级污染；无论状态如何，都能理解当前位置、使用浏览器历史并可靠返回表站。

## 边界

- 拥有 `front` / `archive` 世界语义、跨世界导航规则、浏览器历史行为，以及当前标签页的污染等级与稳定变体选择；
- 为里站、搜索等模组提供一次性污染判定接口，不拥有各模组的具体视觉、内容或入口文案；
- 不收集身份信息，不使用账号、Cookie、服务端状态、跨标签页同步或生产遥测维持污染；
- 不通过不可逆状态、受损语义或被遮挡的出口困住用户。

## 世界与导航契约

- 当前世界由合法 URL 决定。表站彩蛋入口导航至同一国家版本的 1091 里站首页；任意里站页面的返回入口导航至同一国家版本的表站首页；
- 合法深层 URL 直接显示对应页面。表里切换可以有过场和叙事反馈，但必须完成正常路由导航；
- 国家版本切换保持当前世界并优先进入等价页面；没有等价页面时回到同一世界的目标版本首页并提供反馈；
- 普通页面导航、表里切换和国家版本切换形成正常浏览器历史；前进或后退只恢复对应 URL，不被视为新的站内导航，也不强制返回首页；
- 切换过程遵守减少动态效果，完成后焦点进入目标页面的合理位置。表里切换入口、页脚同人声明与里站返回路径不受污染。

## 污染状态契约

- 污染值为 `0 | 1 | 2 | 3`，依次表示原始快照、轻度污染、中度污染和重度污染；
- 状态归属于当前浏览器标签页，在同一标签页和不同国家版本的里站页面之间连续存在，不按语言拆分；新标签页初始值为 `0`；
- 每次有效判定成功时增加 `1`，只增不减并在 `3` 封顶；到达 `3` 后停止随机判定，但触发动作本身继续正常工作；
- 污染值未封顶时，每次有效判定以固定 `42%` 概率增加一级，各次实际判定相互独立；概率由单一配置拥有，不随失败次数或等级变化；
- 主动返回表站时先清除污染状态；关闭标签页后状态结束。清除后通过浏览器历史重新进入里站时恢复为等级 `0`，不还原旧痕迹，也不追加判定；
- JavaScript 或标签页会话状态不可用时退化为等级 `0`；污染等级与变体不进入 URL、canonical、底层内容或翻译数据；
- 同一等级的随机变体选择在当前标签页内保持稳定；升级时保留、强化或明确替代已有痕迹，不因重渲染发生严重度倒退或无意义跳换。

## Demo 基线

- 当前原型支持两种世界，并同步 URL 锚点、标题、主题色和可访问隐藏状态；
- 页内入口、退出按钮和快捷键共享同一切换行为；
- 当前世界仍通过单页显隐切换，尚未实现路由驱动的双站与四级污染状态。

## Formal 增量

- 以独立页面路由替换单页世界面板，并实现上述跨世界、跨国家版本和浏览器历史行为；
- 实现标签页范围的四级状态、单一概率配置、稳定变体选择、受控测试入口和清除策略；
- 测试构建可以增加、减少或指定污染值；正式产物必须通过构建条件排除调试 UI 与控制代码，不能仅用 CSS 隐藏。

## 验收

- URL、世界、浏览器历史、可访问性和焦点不会互相矛盾；
- 每个合格动作至多产生一次污染判定，非合格动作不会意外升级；
- 状态不可用或污染模组故障时，里站等级 `0` 和返回路径仍然成立；
- 减少动态效果不会阻止进入、浏览、污染状态理解或退出。
