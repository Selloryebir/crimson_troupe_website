# BP-FND-NARRATIVE｜叙事状态

## 用户结果

用户对表站与旧档案之间的切换、异常反馈和退出拥有可理解且一致的体验。

## 边界

- 拥有全站当前时间层及其可访问性、URL、标题和切换反馈；
- 定义未来渐变污染的阶段语义，但不拥有各模组的具体视觉或文案；
- 不收集身份信息，不通过不可逆状态困住用户。

## 行为契约

- 当前世界为 `front` 或 `archive`，只有叙事状态能力可以改变它；
- 模组读取状态后决定自身表现，不直接修改其他模组的私有状态；
- 切换过程遵守减少动态效果，结束后焦点进入目标世界的合理位置；
- 进入异常状态后始终存在明确、键盘可达的返回路径。

## Demo 基线

- 支持表站和里站两种世界；
- URL 锚点、页面标题、主题色和可访问隐藏状态同步变化；
- 页内入口、退出按钮和快捷键共享同一切换行为。

## Formal 增量

- 仅在至少两个真实模组需要时，引入 `dormant`、`leaking`、`unstable`、`invitation` 等污染阶段；
- 明确每个阶段的触发、持续范围、刷新恢复、模组权限和一键复原；
- 不把污染阶段退化为单一暗色滤镜。

## 验收

- 状态、URL、可访问性和焦点不会互相矛盾；
- 减少动态效果不会阻止进入或退出；
- 单个叙事模组故障不会消除返回路径。
