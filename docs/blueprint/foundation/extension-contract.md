# BP-FND-EXTENSION｜功能扩展契约

## 用户结果

新增、停用或移除污染、票务等独立能力时，既有页面、核心任务和可靠退出保持稳定。

## 边界

- 定义功能单元如何按页面装配、依赖基础状态、启停和安全降级；
- 污染与票务是独立模组，不得成为基础页面可读性的前置条件；
- 不要求每个辅助函数成为模组，不引入运行时远程插件，也不用全局事件总线替代清晰的一对一接口。

## 行为契约

- Astro 结构在构建期按页面装配，客户端能力由明确入口按页面需要初始化；页面不存在某个模组根节点时应安全跳过；
- 模组不得读取或修改其他模组的私有状态；一对一协作使用显式、类型化接口，只有真实的一对多状态广播才使用事件；
- 污染模组只增强里站异常呈现，停用、初始化失败或客户端状态不可用时退化为完整的等级 `0` 网站；
- 票务模组只增强表站稳定票务地址，未实现、停用、无 JavaScript 或加载失败时显示可理解的“暂未开票”状态和返回路径；
- 启停模组不得改变稳定 URL、内容源、其他页面职责或无关模组实现；高交互能力可以按需加载，但其失败不能阻断页面基础内容。

## Demo 基线

- 客户端功能按能力拆分，并只由需要该能力的页面装配；缺少对应根节点时安全跳过；
- 污染与票务拥有彼此独立的标签页状态和静态降级，不修改其他模组私有数据；
- 追踪表能够从现有功能源码定位主要及相关蓝图。

## Formal 增量

- 按独立页面能力初始化客户端模组，并为污染与票务提供显式启停及降级契约；
- 只有至少两个模组出现重复装配需求时，才引入类型化注册表；
- 高交互模组分别声明键盘、减少动态效果、标签页状态和退出策略，不共享隐式全局状态。

## 验收

- 页面缺少无关模组 DOM 时不会中断其他客户端能力；
- 关闭污染后里站等级 `0` 完整可浏览，关闭票务后稳定票务页及返回路径仍存在；
- 新能力不需要修改无关模组内部实现，抽象由已经出现的重复需求驱动。
