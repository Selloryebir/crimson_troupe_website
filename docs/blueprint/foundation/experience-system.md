# BP-FND-EXPERIENCE｜双网站体验系统

## 核心问题

如果一位泰拉人搜索“猩红剧团”，会打开怎样的网站，并在什么时刻意识到它还保留着另一个年代的网站？

## 产品身份与语气

- 用户第一眼应将页面理解为可信的泰拉剧团官网，而不是作品介绍页或开发演示页；
- 表站位于《红丝绒》事件之后，表现傀影继承酒神相关权能并重新组建的剧团；其全站时间只称为“现在”，具体内容可以通过历史、未来场次和新闻稿中的泰拉日期呈现时间区间；
- 本站整体属于二次创作，但访客侧不逐项标注游戏已有事实、原创或推演内容；非官方同人声明只出现在所有表站、里站和国家版本的页脚；
- 页脚声明必须正常可读、具有足够对比度并可被辅助技术访问，不得通过极小字号、低透明度或叙事伪装使其事实上不可见；
- 表站的节目、剧团、观演服务和公告使用克制、准确、面向观众的机构口吻；搜索、筛选、错误与表单状态直接说明结果，不进行角色表演；
- 信件、访谈和角色发言等署名内容必须标示说话者及内容性质；里站可以使用不可靠、诱惑或侵入的语气，但不得污染表站常规服务文案。

## 体验契约

| 维度     | 表站：`front`                                                | 里站：`archive` 1091                                                      |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------------------- |
| 首要目标 | 建立可信、专业、真实运营中的新剧团官网                       | 呈现当年实际存在、其后被保存并逐渐污染的旧剧团网站                        |
| 信息结构 | 首页；本季演出；历史演出；剧团；搜索；次级票务入口           | 独立首页及同名主任务；1091 内容、年代浏览节奏、不可购票入口与可靠返回路径 |
| 视觉语法 | 现代、明亮、权威；以排版、图像、留白、色彩和克制动效建立层级 | 古老、阴暗、怪异、扭曲；以泰拉媒介语言建立年代感，再叠加受控污染          |
| 用户关系 | 被清晰服务的观众                                             | 被历史快照辨认并诱惑的访客                                                |
| 安全边界 | 信息明确、操作可预期                                         | 可以不安和不可靠，不得真实欺骗、困住或伤害用户                            |

两站共享品牌线索、Astro 工程、无障碍基础和必要基础令牌，但使用独立路由树、页面布局、导航、内容模型、设计令牌子集和客户端状态；它们不是同一页面的明暗换肤，也不要求逐页对应。

## 信息与视觉层级

- 默认进入当前国家版本的表站首页。首页以文字、图片和克制动效承担品牌与重点内容的编辑叙事；
- 表站主导航固定为本季演出、历史演出、剧团和搜索，四项均有独立 URL。内容页以任务完成为主，搜索可使用不同信息密度；
- 品牌标识返回当前国家版本的表站首页；
- 观看与预约通过未来场次和票务工具页提供，属于次级入口，不扩张四项主导航；
- “扁平化”只指减少无意义拟物、缩短核心内容的到达层级，不表示视觉均质或把全部内容放入单页；页面仍须通过比例、裁切、明暗、材质、留白和框景建立剧场空间，列表、筛选、分页和详情层级按任务使用；
- 图片必须承担剧目、人物、场景或品牌叙事功能，不作为无意义填充；参考现实机构时只借鉴抽象的信息分工和交互原则，并完成泰拉化转译。

## 双时期艺术方向

艺术参考只用于提取多张材料反复出现的光线、构图、材质、边框和情绪规律，不授权复制官方图片、Logo、活动 UI、字体、单一角色或独特构图。正式运行时只使用权利清晰的项目素材；缺少已授权图像时，以自有 CSS 图形、色块、线条和排版占位。

两站都必须至少区分页面环境、内容表面和舞台或档案焦点三个视觉层次。层次优先通过色值、比例、裁切、留白和边界建立，阴影、纹理和动效只作辅助；不得把相同宽度、相同底色和相同边线的连续区块误认为高端克制，也不得通过给所有区块增加卡片和阴影纠正扁平感。

两站共享“剧场、帷幕、面具、聚光、猩红和被框住的舞台”这些品牌母题，但不得通过同一布局换色实现：

| 共同母题 | 表站转译                             | 里站转译                                 |
| -------- | ------------------------------------ | ---------------------------------------- |
| 猩红     | 品牌动作、舞台能量和内容焦点         | 帷幕、封印、邀请和逐渐侵入的痕迹         |
| 黑色     | 现代摄影与舞台暗部，用于建立清晰对比 | 墨、煤烟、深廊与不可见空间，构成主要环境 |
| 框景     | 电影画幅、屏幕、编辑网格和利落裁切   | 画框、票证、档案卡、门廊和嵌套观看关系   |
| 光       | 白色或冷色舞台光，强调行动与新秩序   | 烛光、旧聚光和门缝光，强调诱导与窥视     |
| 线条     | 精确细线、切角和运动轨迹             | 双线、刻线、旧金框饰和不均匀印刷边缘     |

### 表站视觉语言

- 表站采用“克制的当代剧场机构 + 受控电影舞台”：情绪先可信、清晰、从容，再在主视觉、剧目图像和过场中显露速度、锋利与危险；服务页面不要求访客先理解暗线；
- “明亮”表示信息开放、状态清楚和阅读可辨，不等于全页浅色。清洁纸色、抬升纸色和墨黑维持机构可信度，舞台暗面用于主视觉、媒体框和章节转场，酒红承担品牌与主行动；舞台红、冷青边缘光、灰粉和暖铜只作受控辅助，不能在同一视口争夺主导；
- 首页使用不对称编辑网格，首屏之后以浅色阅读段、暗色舞台段和开放留白形成节奏；文字与操作保持稳定列线，重点视觉可以跨列、贴边、被前景裁切或局部越出网格，不连续堆叠等宽白色卡片；
- 演出列表以节目条目或海报序列组织图像、标题、日期和地点；详情页以主视觉建立作品身份，再让事实、编排、主创和提示回到稳定阅读网格；搜索与票务可以使用编号、场记线、切角和局部深色状态面板，但任务反馈不依赖风格装饰；
- 图像优先宽画幅、近景裁切、近远景遮挡、斜向运动、明确焦点与冷暖舞台光。缺少权利清晰图像时使用自有舞台块、光束、帷幕、抽象轨迹和裁切平面，不绘制可识别的官方人物、标志或场景；
- 展示标题使用有舞台海报张力的系统衬线字体，导航、筛选、搜索和票务状态使用系统无衬线字体，小型编号可以使用等宽回退；层级依靠字号、行长、字重和留白，不以强制单行、过宽字距或全大写伤害长文本与哥伦比亚语；
- 常规边界使用精确细线、短下划线、局部双线和少量切角；圆角、胶囊按钮、通用阴影和连续卡片框不作为默认语法。空间感来自裁切、重叠、方向和明暗，不依赖玻璃拟态或三维按钮；
- 动效可以采用幕布揭示、焦点移动或快速克制的场景切换，不使用无意义粒子覆盖页面，不长时间隐藏初始内容；减少动态效果时直接呈现最终状态。

### 里站视觉语言

- 里站采用“完整的旧剧场网站 + 缓慢显露的仪式性不安”：等级 `0` 先古老而完整、礼仪化、诱人，再由污染显露恶意；年代感不依赖故障效果；
- 以深廊黑、煤烟黑和漆木暗面建立环境，以旧纸和褪色墨承担阅读，以帷幕红、旧金、烛光琥珀和烟紫灰组织礼仪层级；鲜血红只用于异常与关键诱导，不成为等级 `0` 的默认主行动色；
- 暗环境不等于压低全部亮度。正文和任务区可以使用旧纸亮面或高对比旧纸文字；烛光与旧金负责引导，帷幕红负责仪式，暗角、烟尘和纸纹集中于边缘、媒体与框饰；
- 首页以稳定中心轴、门廊或舞台口建立首屏，并通过外框、内框、节目单或画像形成嵌套观看关系；先呈现邀请或剧团权威，再进入告示与本季登记，暗色前厅、旧纸档案和烛光焦点形成纵深，不用规则网格背景模拟年代；
- 演出列表采用登记簿、节目单或档案目录节奏；详情图像优先正面轴线、中心舞台、拱门、长廊、画中画和被框住的对象，并使用 4:3、肖像、登记卡或旧节目单比例区别于表站宽银幕；
- 页面使用较窄正文列、仪式标题和稳定对称骨架，但长文、搜索结果和事务信息仍左对齐阅读；搜索与不可购票页属于同一旧站事务系统，不通过装饰损害输入、状态和返回路径；
- 边框区分结构线、框景线和装饰线。双线、刻线、内外框、切角、旧金和少量纹样集中于入口、重点海报、票证与章节标题，普通列表不重复套多层框；
- 展示标题使用紧凑的系统衬线字体，正文使用高可读衬线字体，功能标签与编号使用无衬线或等宽回退；不使用难辨识花体或伪古字形承载任务；
- 暗角、纸纹、炭笔、褪色、漏印和轻微失焦只能位于有密度上限的装饰层，不降低正文、导航、搜索反馈和返回入口的对比度，也不移动语义 DOM 或点击区域；
- 等级 `0` 不使用随机抖动、扫描线、持续闪烁、现实系统故障图标或不可读黑红噪声。更具体的等级 `0` 与污染递进由里站蓝图负责。

### 页面模式与视觉分工

| 页面模式       | 表站责任                             | 里站责任                                 |
| -------------- | ------------------------------------ | ---------------------------------------- |
| 首页           | 编辑网格、舞台暗面与清楚主任务共存   | 仪式轴线、嵌套框景与等级 `0` 完整性成立  |
| 演出列表或详情 | 海报节奏与事实阅读层互不争夺         | 登记簿节奏、旧式比例与可查阅性成立       |
| 搜索或票务     | 高密度事务任务仍属于现代剧团品牌     | 功能反馈仍属于旧档案系统且保持清晰       |
| 全局外壳       | 导航、国家版本选择器、页脚与窄屏稳定 | 年代外壳、返回入口、选择器与污染边界稳定 |

代表页面先建立可复用的视觉模式，验证后再覆盖同类页面；不得以逐页特例维持一致性，也不得为了共享组件让两站重新收敛为相同表面。

### UI 与素材不变量

- 两站分别拥有语义化视觉令牌；真正共享的只有可访问性、尺寸尺度和必要品牌母题，共享变量不得迫使两站得到相同表面；
- 双站令牌至少表达环境、内容表面、焦点、主文字、次文字、结构线、品牌行动和状态反馈；具体值由源码拥有，同一全局语义不能由页面或单个组件维护平行颜色事实，剧目自身的受控视觉配色不受此限制；
- 原创图像应记录焦点位置、允许裁切范围、文字安全区、明暗版本和替代文本意图，同一图像不得依赖桌面固定比例才能理解；
- 纹理、暗角、红色侵入和边框均为装饰层，不能成为状态、错误、选择或链接的唯一表达；
- 焦点、当前导航、错误与成功反馈先满足清晰识别，再接受艺术修饰；完成度以任务是否同样可完成、三层空间是否成立及两个世界是否被立即区分判断，不以装饰数量、滤镜强度或与参考图的表面相似度判断；
- 具体色值、纹理密度、边框密度和图文叠加参数由可部署样张验证后留在源码，不在蓝图固化未经验证的数值。

## 跨视口与交互不变量

- 手机端与电脑端承载相同任务、内容和结果，导航形式、信息密度、图像裁切和动效幅度可以不同；
- 最低检查宽度为 320 CSS 像素，并覆盖 375/390、768、1024、1280/1440 等代表性宽度及更宽桌面；
- 目标宽度下不得出现页面级横向内容丢失、主要操作被遮挡、文本脱离容器或只能依赖 hover 完成的任务；
- 东国语预览使用系统日文字体与正常禁则换行；假名、汉字和全角标点不得通过固定高度、强制单行、关键文字省略或单页译文特例适配。先修正共享内容驱动布局，只有确属日语文字系统的问题才使用 `:lang(ja-JP)`；
- 移动导航必须处理触控目标、安全区、展开后的页面滚动和焦点管理；
- 所有动效遵守 `prefers-reduced-motion`，且不得依赖动画才能理解信息或完成任务。

## 非目标

- 复刻游戏界面或现实剧院网站的构图、素材、文案、代码与品牌表达；
- 进行真实购票、支付、账号或个人信息处理；
- 把里站做成表站换肤、不可退出的惊吓页面，或用污染替代等级 `0` 的网站建设；
- 为表站设置决定界面、路由或构建的固定泰拉年份。

## Demo 基线

- 表站可以作为具有四项主任务和次级票务入口的专业剧团官网被理解；
- 里站拥有独立页面树、内容节奏、年代视觉和可靠退出，不依赖污染才成立；
- 桌面、最低 320px 窄屏、键盘和减少动态效果路径均能完成两个网站的核心任务。

## Formal 增量

- 完成表站四项主任务与次级票务入口，并让 1091 等级 `0` 里站在没有污染时独立成立；
- 建立一致的语义设计令牌和组件状态，不依赖页面级补丁维持视觉；
- 按上述双时期方向验证表站现代编辑系统、里站仪式剧场和共享品牌母题，不把两站收敛为同一布局换色；
- 保持跨视口任务等价、焦点顺序稳定，并为多语言长文本保留布局弹性。
- 以表站首页、演出列表与详情、票务，以及里站首页、演出列表与详情、搜索和国家版本选择器验证东国语排版；只把实测仍有长期价值的最小规则留入共享视觉系统。

## 验收

- 用户不进入彩蛋也能发现演出、理解剧团、使用搜索并到达票务入口；
- 用户进入里站后可以浏览完整等级 `0` 网站，并始终识别和执行返回；
- 两站差异同时体现在信息、文案、交互和视觉上，不被理解为同一组件的明暗换肤；
- 表站先呈现可信当代机构与受控电影舞台，里站等级 `0` 先呈现完整仪式档案剧场；首屏、演出内容页和事务页在不依赖明暗换色时仍能辨别世界；
- 页面环境、内容表面与舞台或档案焦点形成明确层次；候选色彩与装饰在桌面、320px、键盘和长文页面中不会削弱任务层级与可读性；
- 炎语、东国语与哥伦比亚语在 320、390、768 和 1280 CSS 像素代表视口中不出现缺字、标题或控件截断、假名行高异常及页面级横向外溢；
- 页脚声明在两个网站和所有已发布国家版本中保持可读、可访问且不侵入正文。
