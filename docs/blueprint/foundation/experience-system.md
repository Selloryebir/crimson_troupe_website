# BP-FND-EXPERIENCE｜双网站体验系统

## 核心问题

如果一位泰拉人搜索“猩红剧团”，会打开怎样的网站，并在什么时刻意识到它还保留着另一个年代的网站？

## 产品身份与语气

- 用户第一眼应将页面理解为可信的泰拉剧团官网，而不是作品介绍页或开发演示页；
- 表站位于《红丝绒》事件之后，表现傀影继承酒神相关权能并重新组建的剧团；其全站时间只称为“现在”，具体内容可以通过历史、未来场次和新闻稿中的泰拉日期呈现时间区间；
- 本站整体属于二次创作，但访客侧不逐项标注游戏已有事实、原创或推演内容；非官方同人声明只出现在所有表站、里站和国家版本的页脚；
- 页脚声明必须正常可读、具有足够对比度并可被辅助技术访问，不得通过极小字号、低透明度或叙事伪装使其事实上不可见；
- 表站的节目、剧团、观演服务和公告使用克制、准确、面向观众的机构口吻；搜索、筛选、错误与表单状态直接说明结果，不进行角色表演；
- 信件、访谈和角色发言等署名内容必须标示说话者及内容性质；里站可以使用不可靠、诱惑或侵入的语气，但不得污染表站常规服务文案。

## 体验契约

| 维度     | 表站：`front`                                                | 里站：`archive` 1091                                                      |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------------------- |
| 首要目标 | 建立可信、专业、真实运营中的新剧团官网                       | 呈现当年实际存在、其后被保存并逐渐污染的旧剧团网站                        |
| 信息结构 | 首页；本季演出；历史演出；剧团；搜索；次级票务入口           | 独立首页及同名主任务；1091 内容、年代浏览节奏、不可购票入口与可靠返回路径 |
| 视觉语法 | 现代、明亮、权威；以排版、图像、留白、色彩和克制动效建立层级 | 古老、阴暗、怪异、扭曲；以泰拉媒介语言建立年代感，再叠加受控污染          |
| 用户关系 | 被清晰服务的观众                                             | 被历史快照辨认并诱惑的访客                                                |
| 安全边界 | 信息明确、操作可预期                                         | 可以不安和不可靠，不得真实欺骗、困住或伤害用户                            |

两站共享品牌线索、Astro 工程、无障碍基础和必要基础令牌，但使用独立路由树、页面布局、导航、内容模型、设计令牌子集和客户端状态；它们不是同一页面的明暗换肤，也不要求逐页对应。

## 信息与视觉层级

- 默认进入当前国家版本的表站首页。首页以文字、图片和克制动效承担品牌与重点内容的编辑叙事；
- 表站主导航固定为本季演出、历史演出、剧团和搜索，四项均有独立 URL。内容页以任务完成为主，搜索可使用不同信息密度；
- 品牌标识返回当前国家版本的表站首页；
- 观看与预约通过未来场次和票务工具页提供，属于次级入口，不扩张四项主导航；
- “扁平化”指减少无意义拟物和层叠、缩短核心内容的到达层级，不表示把全部内容放入单页；列表、筛选、分页和详情层级可以按任务使用；
- 图片必须承担剧目、人物、场景或品牌叙事功能，不作为无意义填充；参考现实机构时只借鉴抽象的信息分工和交互原则，并完成泰拉化转译。

## 跨视口与交互不变量

- 手机端与电脑端承载相同任务、内容和结果，导航形式、信息密度、图像裁切和动效幅度可以不同；
- 最低检查宽度为 320 CSS 像素，并覆盖 375/390、768、1024、1280/1440 等代表性宽度及更宽桌面；
- 目标宽度下不得出现页面级横向内容丢失、主要操作被遮挡、文本脱离容器或只能依赖 hover 完成的任务；
- 移动导航必须处理触控目标、安全区、展开后的页面滚动和焦点管理；
- 所有动效遵守 `prefers-reduced-motion`，且不得依赖动画才能理解信息或完成任务。

## 非目标

- 复刻游戏界面或现实剧院网站的构图、素材、文案、代码与品牌表达；
- 进行真实购票、支付、账号或个人信息处理；
- 把里站做成表站换肤、不可退出的惊吓页面，或用污染替代等级 `0` 的网站建设；
- 为表站设置决定界面、路由或构建的固定泰拉年份。

## Demo 基线

- 表站可以作为具有四项主任务和次级票务入口的专业剧团官网被理解；
- 里站拥有独立页面树、内容节奏、年代视觉和可靠退出，不依赖污染才成立；
- 桌面、最低 320px 窄屏、键盘和减少动态效果路径均能完成两个网站的核心任务。

## Formal 增量

- 完成表站四项主任务与次级票务入口，并让 1091 等级 `0` 里站在没有污染时独立成立；
- 建立一致的语义设计令牌和组件状态，不依赖页面级补丁维持视觉；
- 保持跨视口任务等价、焦点顺序稳定，并为多语言长文本保留布局弹性。

## 验收

- 用户不进入彩蛋也能发现演出、理解剧团、使用搜索并到达票务入口；
- 用户进入里站后可以浏览完整等级 `0` 网站，并始终识别和执行返回；
- 两站差异同时体现在信息、文案、交互和视觉上，不被理解为同一组件的明暗换肤；
- 页脚声明在两个网站和所有已发布国家版本中保持可读、可访问且不侵入正文。
