# BP-I18N-TERMS｜多语言术语契约

## 用户结果

剧团、人物、地点、种族、机构、场次和剧目名称在不同国家版本及两个时间层中保持可辨认、可追踪的一致性。

## 边界

- 本蓝图只规定多语言标准形式、显示别名、搜索别名、时间层变体和来源状态的结构与使用方式；
- 产品术语、`Performance` / `Production` 关系、字段归属和时间语义只由 `BP-FND-DOMAIN` 定义；国家版本及 locale 只由 `BP-I18N-CORE` 定义；
- 实际术语数据不存放在蓝图正文，不使用显示文本作为稳定标识；
- `docs/references/production-title-reference.md` 是当前 13 项活页剧目来源标题与稳定 `productionId` 映射的唯一参考；蓝图不复制该表，运行时只接入被当前内容采用的记录；
- 地点候选资料及其创作备注由 `BP-CNT-CORE` 保存，本蓝图只负责正式采用地点的多语言形式、别名、冲突和审核状态；
- 不静默解决来源冲突，不为尚未进入开发的国家版本创建空白翻译表。

## 行为契约

- 术语记录至少支持稳定 `concept_id`、分类、国家版本或 locale、标准形式、显示别名、搜索别名、应避免译法、表站名称、里站变体、来源、冲突备注和审核状态；
- 缺失值必须显式表示，不能用猜测、机器翻译或中文原文静默补齐；
- 表站机构口吻、系统反馈、署名内容和里站叙事的翻译应保持各自语用边界，不能因角色化翻译污染表站服务文案；
- 搜索索引消费已批准的标准形式和别名，不复制术语矩阵；跨国家版本内容通过稳定概念 ID 对应，不依赖翻译标题；
- 活页剧目中文标题作为 `zh-CN` 来源形式，日文标题作为 `ja-JP` 来源形式，`English` 先作为未区分地域的 `en` 来源。`en-US` 与 `en-GB` 必须分别进入对应国家版本的开发和审核范围，不能因存在 `en` 形式自动获得发布资格；
- 活页标题的 `productionId` 已由来源形式一次性映射并冻结，不在运行时从标题生成。标题数据不保存 `《》`、`『』` 等包围书名号，组件也不自动添加；正文语法需要的标点由正文拥有；
- 地点中文名、英文名与本国语名不互相推导；正式采用时通过稳定 `locationId` 与国家版本内容关联，场馆和地址说明不并入地点术语记录；
- 署名、引语、翻译和改写内容保留来源定位；冲突形式在备注中保留，等待人工决定，不覆盖现有批准形式。

## Demo 基线

- 当前类型化内容使用稳定 ID，显示名称与身份分离；
- 当前单语言专有名词写法保持一致，但尚无独立术语数据源。

## Formal 增量

- 简体中文基线先保持批准术语一致；在首个其他国家版本开发前建立单一术语数据源；
- 本阶段五国家版本预览只覆盖当前运行时引用的地点、场次、六项原创剧目和四项已采用活页剧目，不把地点候选目录或其余九项活页标题批量转为运行时术语；
- 当前采用的四项活页剧目直接使用参考中已经提供的 `zh-CN`、`en` 与 `ja-JP` 标题形式；哥伦比亚预览采用 `en` 形式仍只属于技术预览，米诺斯与乌萨斯的 `el`、`ru` 形式允许使用 AI 预览译文，三者均不表示完成人工译审；
- 术语范围与审核遵守本地化蓝图的一次一个国家版本流程，不单独制造第二套翻译门禁；
- 需要连续阅读时可以生成面向人员的可读视图，但原子数据源保持唯一。

## 验收

- 同一概念的标准形式、别名和时间层变体可以通过稳定 ID 相互定位；
- 来源冲突和缺失值不会被静默覆盖，未批准形式不会进入正式搜索索引；
- 13 项标题参考、四项运行时活页剧目与各国家版本完整详情保持单向引用，不形成相互覆盖的第二事实源；
- 术语更新可以列出受到影响的内容与搜索入口，而不改写领域定义或国家版本矩阵。
