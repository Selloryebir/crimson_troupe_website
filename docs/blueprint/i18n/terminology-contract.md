# BP-I18N-TERMS｜专有名词契约

## 用户结果

剧团、人物、地点、种族、机构和剧目名称在不同语言及两个时间层中保持可辨认、可追踪的一致性。

## 边界

- 本蓝图只规定术语矩阵的结构和使用方式，实际术语数据不存放在蓝图正文；
- 不静默解决来源冲突，不使用显示文本作为稳定标识；
- 不为尚未决定支持的语言创建空白翻译表。

## 行为契约

术语记录至少支持稳定 `concept_id`、分类、各语言标准形式、别名、应避免译法、表站名称、里站变体、来源、冲突备注和审核状态。缺失值必须显式表示，不能用猜测补齐。

## Demo 基线

- 类型化内容使用稳定 ID，显示名称与身份分离；
- 当前单语言专有名词写法保持一致。

## Formal 增量

- 在第二种真实发布语言开始前建立术语数据源；
- 搜索索引消费已批准的标准形式和别名，而不是复制词表；
- 需要连续阅读时提供面向人员的可读视图，但保持一个原子数据源。

## 验收

- 同一概念的翻译、别名和时间层变体可以相互定位；
- 来源冲突和缺失值不会被静默覆盖；
- 术语更新可以列出受到影响的内容和搜索入口。
