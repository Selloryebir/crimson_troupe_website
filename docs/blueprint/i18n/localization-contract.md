# BP-I18N-CORE｜国家版本与本地化契约

## 用户结果

用户能够在已经完整发布或明确标为开发预览的国家版本中理解导航、内容、状态与错误；开发中的翻译缺失不会造成空白页面，也不会混入正式产物。

## 边界

- 负责国家版本注册、构建范围、locale 解析、发布集合、类型化内容解析、开发期回退、格式化、国家版本选择器、布局适配和翻译完整度门禁；
- 国家版本 ID `editionId`、公开路径段 `routePrefix` 与技术 locale 是不同字段，当前一一对应；
- 不把中文原文作为程序键，不从显示名推导 URL，不把机器翻译自动视为批准内容；
- 不要求简体中文基线完成前制作其他语言内容。

## 注册与路由协作

- `editionId` 与 `routePrefix` 必须显式存储，不能根据英文名、显示名或彼此拼接推导；显示名称也不得反向参与 URL 生成；
- 所有公开 URL、切换链接、canonical、搜索结果链接和静态生成路径使用对应 `routePrefix`；页面 `html lang`、日期、数字、分词和搜索归一化使用技术 locale；
- 技术 locale 只描述现实语言处理规则，不表示泰拉实体属于对应现实国家；
- 国家版本共享网站能力、稳定内容 ID 和主要结构；必要地区差异使用显式内容字段，不复制整套页面；
- 本矩阵已由人工确认完整、正确且不存在已知问题。除非人工明确要求修改具体值，否则不恢复并行 CSV，也不重复审计实体内容；实现仍需机械检查 ID 唯一性、路径格式和必填字段。

## 注册、构建与发布范围

- 国家版本注册、当前构建范围和正式发布范围是三个独立概念。注册表只说明可规划的国家版本，不自动生成页面、选择器选项或翻译文件；
- `releaseEditionIds` 是正式构建和正式国家版本选择器的唯一发布集合，当前固定为 `['yan']`；不得另行维护语义相同的 locale 发布数组；
- 开发预览使用独立构建范围，本阶段固定为 `['yan', 'higashi', 'columbia']`，只用于开发服务器和可部署预览，不授予东国语或哥伦比亚语翻译审核及正式发布资格；
- 未显式选择构建模式时必须采用正式发布范围；未知构建模式在生成页面前失败，不能静默扩大为预览范围；
- 路由、组件、搜索索引和产物验证只消费当前构建范围派生出的同一国家版本集合，不自行筛选注册表；
- 只构建一个国家版本时，页眉显示不可展开的当前版本标识；构建两个及以上版本时才提供可导航选择器。未进入当前构建范围的版本不产生空翻译、空页面、失效链接或占位选项；
- 哥伦比亚 AI 英译与东国语 AI 日译可以用于结构、字体、布局和功能预览，但在各自人工整体译审前始终属于草稿内容。本阶段最终可部署三语言预览必须机械覆盖完整且不含回退，正式构建仍只包含炎国。

## 类型化内容与解析边界

- 语言无关事实只保存一次；所有访客或辅助技术可感知文字按 `editionId` 组织为类型化内容，并通过显式国家版本参数解析。页面和客户端不得从全局可变“当前语言”读取内容；
- 本地化内容至少按页面、消息组、地点、场次和剧目五类稳定记录组织。页面记录按世界和稳定页面 ID 区分；消息组按共享、筛选、搜索、票务与污染等真实消费者划分；其他三类记录分别通过 `locationId`、`performanceId` 和 `productionId` 关联；
- 每个进入构建范围的国家版本通过一个显式完整包入口提供网站、节目与消息内容；解析器只注册该入口，不逐文件拼装国家版本，也不使用 glob、运行时路径或目录扫描发现内容；
- 国家版本的运行时剧目详情可以按 `folio` 与 `original` 分区维护，但必须在完整包入口合并为同一个 `ProgramContent.productions`。消费者、回退和完整度验证只读取合并后的统一接口；
- 已存在的本地化记录必须满足该记录的完整类型。开发中允许目标国家版本缺少整条记录，但不得使用空字符串表示缺失，也不得在任意深层字段逐字符串拼接中文；
- 统一解析器只在完整记录边界执行“目标国家版本 → 炎国”回退，并返回实际来源 locale。页面、组件、搜索和票务只消费解析后的记录，回退内容在最小合理容器标注 `lang="zh-CN"`；
- 稳定 ID、ASCII 路由段、枚举、明确标识码、`LMD`、票号数值和纯装饰字符可以不翻译；页面元数据、导航、按钮、表单、状态、错误、无脚本反馈、ARIA 文本、搜索、污染叙事、结算与票面文字均属于本地化范围；
- 里站叙事投影使用稳定实体 ID 与页面职责定位，但可见异常文案、摘要、请柬信息和异常可访问名称仍属于国家版本内容；不得在脚本、CSS、图片或视觉资料中写死炎语，也不得用缺译、乱码或字体故障冒充污染；
- 搜索索引、列表、详情和票务输入从同一解析后内容视图派生，不为单个模组维护平行翻译事实。

## 国家版本选择器

- 选择器切换国家版本而非局部界面语言。可见标签只使用注册表中的 `languageName.native`，每个选项使用自身技术 locale 的 `lang`，图形标识不能替代可访问文字；
- 两个及以上版本使用原生 `<details>` / `<summary>` 和普通链接列表作为基础结构；不使用无法可靠承载标识与语言文本的原生 `<select><option>`，也不为普通导航引入通用菜单库或自制 ARIA 菜单；
- 无 JavaScript 时全部选项仍可导航；增强只负责 `Escape`、焦点返回及确有需要的外部点击关闭。当前项具有 `aria-current` 或等价语义，最低 320px 下仍可到达；
- 切换优先进入目标版本同一世界和同一稳定页面；没有等价内容时进入目标版本同一世界首页并给出可理解反馈。搜索词不跨版本携带；
- 里站切换复用既有 `archive-locale` 污染判定接口，每次切换至多请求一次判定，不复制污染状态机；
- 选项使用国家版本注册中的稳定产品顺序，当前版本不移动位置，不对不同文字系统执行混合字母排序；
- 正式国家标识素材提供前，炎国、东国与哥伦比亚分别使用显式 `YAN`、`HIG`、`COL` 字段生成项目内正方形临时 SVG；标识码不从路径、locale 或显示名截取。三项按注册表既定产品顺序显示，后续正式素材复用同一正方形槽位，不改变内容或导航接口。

## 编码、语言标注与字体

- 仓库文本、结构化数据、HTML、客户端数据和 SVG 统一使用 UTF-8；字符编码与语言是不同维度；
- 页面根元素使用当前国家版本 locale；选项、专名或开发回退与页面主语言不同时，在最小包围元素上声明对应 `lang`；
- 本阶段使用系统字体和 `:lang()` 分别适配 `zh-CN`、`ja-JP` 与 `en-US`，只依据可部署页面中观察到的缺字、断行、行高、全角标点、控件截字或窄屏外溢调整字体顺序、尺寸与间距；
- `ja-JP` 使用常见平台系统日文 serif / sans 字体回退及正常日语禁则换行，不使用固定高度、强制单行或省略号隐藏关键信息；只有标识码、日期和明确不可拆分的短字段可以保持单行；
- 本阶段不引入 Web Font，也不提前为其他国家版本增加字体兼容分支。编码、`lang`、选择器和内容接口必须保持可扩展，尚未进入预览的文字系统留待对应版本开发时单独验证。

## 简体中文基线与开发顺序

- `zh-CN` 是唯一首发基线。必须先完成简体中文表站、里站、内容、功能及既有质量门禁，并经一次人工整体审核确认可发布，之后才能开始其他语言的正式内容开发；
- 简体中文阶段同时建立 locale 感知的路由和内容读取边界，但只发布炎国 `yan / zh-CN`；语言区域可以显示当前语言，不提供空下拉、未开发选项或“即将推出”入口；
- 开始其他语言的正式内容开发前，基于已批准简体中文版本建立轻量翻译范围清单。开发预览可以先由类型化基线机械生成同一范围，但不因此获得发布资格；每项至少定位来源文件或稳定内容 ID、需翻译字段或内容类别，以及所依据的简体中文基线版本；
- 翻译范围覆盖正文、结构化内容、导航、系统反馈、元数据、替代文本、搜索文本、素材内可见文字及其他访客或辅助技术可感知字符串；未发布草稿、纯装饰和无需翻译的专名不计缺失；
- 每轮只声明一个目标 `editionId` 与 locale 并依据同一清单开发。清单只界定范围，不复制译文，也不保存长期进度、人员或审核流水账。

## 回退、完整度与发布门禁

- 开发环境按完整记录执行“目标国家版本 → 炎国”回退；回退不改变 URL、国家版本或搜索范围。页面根元素保留目标 locale，实际回退为中文的最小内容容器标记 `lang="zh-CN"`；
- 开发期缺失生成面向开发者的清单或构建报告，不在沉浸式页面中显示警告；
- 一个目标语言达到 `100%`，表示范围清单内全部必需项都已有目标语言内容，并经一次人工整体审核确认；进度可以使用百分比，正式发布门禁只使用“通过”或“不通过”；
- 正式构建只发布显式列入 `releaseEditionIds` 的国家版本；集合内任一版本不完整时发布失败。未完成版本可以存在于仓库和本地开发回退，但不得进入正式入口或形成多语言混排页面；本阶段三语言可部署预览同样要求炎国、东国与哥伦比亚零缺失、零回退；
- 简体中文基线变化后，只将受影响的范围项重新标记未完成；补译并人工确认后恢复发布资格，不因无关变化要求整种语言重审；
- 某国家版本有意不提供地区内容时使用显式内容状态，不用空字符串或从范围清单静默删除表示；
- 结算画面、纪念票、下载与打印版本均属于发布范围，必须使用当前国家版本的完整翻译和格式化规则。

## 模组与状态边界

- 搜索按 `{editionId}:front` 与 `{editionId}:archive:1091` 生成独立索引，查询归一化使用当前 locale，不在浏览器加载其他国家版本索引后过滤；
- 客户端筛选、搜索、票务和污染脚本只接收当前页面需要的 locale 与消息子集，不加载全部国家版本内容，也不保留中文默认文案；
- 票篮、票务流程和冻结结果只保存稳定 ID、枚举和数值，显示标签由当前国家版本重新解析。切换国家版本时这些同标签页业务状态保持不变；未来若改为按国家版本隔离，必须先修改正式票务契约；
- 分区示意拓扑、图形锚点、报价百分比、互斥结果、路线、报价变体、旅程标签和印章语义保持语言无关；舞台方向、分区名称、场馆说明、合作通道、费用说明、失败记录、印章解释及可访问名称属于当前国家版本内容；
- 里站污染状态按叙事契约跨国家版本保持；搜索词、披露开合和滚动位置等瞬时输入不因此新增持久化要求；
- 纪念票的屏幕、SVG、下载和打印内容读取同一国家版本内容与字体规则，票号、二维码、价格和结局事实不因语言改变；
- 同一冻结结果在国家版本切换后必须以目标版本重新生成票面文字，但保持票号、二维码、稳定票纹、旅程标签与印章语义；不得把印章文字或分区标签烘焙到语言无关图形资料中；
- 构建验证从当前构建范围派生路由、`lang`、canonical、robots、链接、搜索范围和选择器期望，不把炎国路径或中文句子作为其他版本的通用断言。
- 三个预览国家版本在表站与里站必须拥有同一组页面、搜索、筛选、票务或不可购票、污染、选择器、状态恢复、下载、打印、键盘、无脚本和响应式路径；机械字符串完整度不能代替功能等价验证。

## Demo 基线

- 国家版本注册显式区分 `editionId`、`routePrefix` 与 locale，当前发布集合只包含 `yan / zh-CN`；
- 页面、内容读取、搜索范围和语言显示保留 locale 边界，正式构建不会生成未发布国家版本；
- 炎国、东国与哥伦比亚双时间层开发预览已建立完整包、零回退、国家版本选择器与状态隔离；东国与哥伦比亚译文均为未经过人工译审的技术预览内容。

## Formal 增量

- 先完成只生成 `yan / zh-CN` 的国家版本注册、静态路由、内容读取和语言显示边界；
- 在正式构建继续只发布炎国的前提下，把现有炎国与哥伦比亚开发预览扩展为炎国、东国与哥伦比亚三语言双时间层预览，保持记录级内容解析、覆盖报告和构建范围驱动的静态生成；
- 让搜索、筛选、污染、票务、结算与票面消费当前国家版本内容，并让票务与污染状态在切换国家版本后保持；
- 为里站等级 `2—3` 的可见叙事投影提供类型化三国家版本内容，保持稳定实体、路由和等级 `0` 源内容不变；
- 以原生结构、正方形临时标识和系统字体验证炎语、东国语与哥伦比亚语的长文本、日文禁则换行、搜索归一化、等价页面、焦点、无脚本和最低 320px 路径；
- 后续版本继续按“一次一个国家版本”的流程建立范围清单、开发、回退报告和发布门禁，不把本阶段三语言视觉结果外推为其他文字系统已适配。

## 验收

- 增加国家版本不要求逐个改写组件业务逻辑，显示名、路径前缀和技术 locale 不互相推导；
- 简体中文网站不依赖其他语言即可构建、审核和发布，正式产物不含未开发版本入口；
- 开发期缺失不会破坏导航或退出，正式发布集合与最终三语言预览均不含回退内容；
- 选择器在表站与里站保持世界和等价页面，纯链接路径、键盘、焦点、320px 和无 JavaScript 行为成立；
- 同一内容在不同国家版本中保持稳定身份；票篮、冻结结果与污染状态在切换后保持，搜索和发布范围仍严格隔离；
- 接入下一国家版本只需新增内容、术语、必要字体适配和明确构建集合项，不复制页面、领域事实或模组状态机。
