# BP-I18N-CORE｜国家版本与本地化契约

## 用户结果

用户能够在已经完整发布或明确标为开发预览的国家版本中理解导航、内容、状态与错误；开发中的翻译缺失不会造成空白页面，也不会混入正式产物。

## 边界

- 负责国家版本注册、构建范围、locale 解析、发布集合、类型化内容解析、作者诊断回退、格式化、国家版本选择器、布局适配和翻译完整度门禁；
- 国家版本 ID `editionId`、公开路径段 `routePrefix` 与技术 locale 是不同字段，当前一一对应；
- 不把中文原文作为程序键，不从显示名推导 URL，不把机器翻译自动视为批准内容；
- 不要求简体中文基线完成前制作其他语言内容。

## 注册与路由协作

- `editionId` 与 `routePrefix` 必须显式存储，不能根据英文名、显示名或彼此拼接推导；显示名称也不得反向参与 URL 生成；
- 所有公开 URL、切换链接、canonical、搜索结果链接和静态生成路径使用对应 `routePrefix`；页面 `html lang`、日期、数字、分词和搜索归一化使用技术 locale；
- 技术 locale 只描述现实语言处理规则，不表示泰拉实体属于对应现实国家；
- 国家版本共享网站能力、稳定内容 ID 和主要结构；必要地区差异使用显式内容字段，不复制整套页面；
- 本矩阵已由人工确认完整、正确且不存在已知问题。除非人工明确要求修改具体值，否则不恢复并行 CSV，也不重复审计实体内容；实现仍需机械检查 ID 唯一性、路径格式和必填字段。

## 注册、构建与发布范围

- 国家版本注册、构建预设、当前构建范围和正式发布范围是不同概念。注册表只说明可规划的国家版本，不自动生成页面、选择器选项或翻译文件；
- `releaseEditionIds` 是正式国家版本集合的唯一来源，当前固定为 `['yan']`；不得另行维护语义相同的 locale 发布数组；
- 构建只接受三个有限命名预设，并由同一个 `SITE_BUILD_PROFILE` 入口选择：
  - `showcase`：默认，构建炎国，使用当前展示根集合与 `preview-ok`，保持未批准内容阶段仍可部署；
  - `preview`：按国家版本矩阵顺序构建炎国、维多利亚、乌萨斯、叙拉古、米诺斯、莱塔尼亚、卡西米尔、东国和哥伦比亚，使用同一展示根集合与 `preview-ok`，用于九国家版本完整体验验证；
  - `release`：构建 `releaseEditionIds` 与 `approved-only`，当前没有批准基线时必须列出不合格对象并失败；
- 未显式选择预设时采用 `showcase`；未知预设在生成页面前失败。预设内部显式绑定国家版本、根集合、内容策略与回退策略，不增加可以自由组合的第二环境变量；
- 路由、组件、搜索索引和产物验证只消费当前构建上下文中的同一国家版本集合与内容快照，不自行筛选注册表；
- 只构建一个国家版本时，页眉显示不可展开的当前版本标识；构建两个及以上版本时才提供可导航选择器。未进入当前构建范围的版本不产生空翻译、空页面、失效链接或占位选项；
- 维多利亚 AI 英式英语、乌萨斯 AI 俄译、叙拉古 AI 意大利语、米诺斯 AI 现代希腊语、莱塔尼亚 AI 德译、卡西米尔 AI 波兰语、东国语 AI 日译与哥伦比亚 AI 美式英语可以用于结构、字体、布局和功能预览，但在各自人工整体译审前始终是未批准运行时预览。本阶段九国家版本 `preview` 必须机械覆盖完整且不含回退，`release` 仍只允许炎国批准内容。

## 类型化内容与解析边界

- 语言无关事实只保存一次；所有访客或辅助技术可感知文字按 `editionId` 组织为类型化内容，并通过显式国家版本参数解析。页面和客户端不得从全局可变“当前语言”读取内容；
- 本地化内容至少按页面、消息组、平台品牌、地点、场次和剧目六类稳定记录组织。页面记录按世界和稳定页面 ID 区分；消息组按共享、筛选、搜索、票务与污染等真实消费者划分；平台显示名通过稳定平台 ID 关联，其他三类记录分别通过 `locationId`、`performanceId` 和 `productionId` 关联；
- 每个进入构建范围的国家版本通过一个显式完整包入口提供网站、节目与消息内容；解析器只注册该入口，不逐文件拼装国家版本，也不使用 glob、运行时路径或目录扫描发现内容；
- 每个完整包固定由 `site`、`messages`、`programs`、合并 `folio / original` 的 `productions`、里站污染投影与邀请内容，以及唯一 `index` 入口组成；`programs` 不保存完整剧目正文，各国家版本不得用反向导出或复制业务逻辑形成不同目录语法；
- 国家版本的运行时剧目详情可以按 `folio` 与 `original` 分区维护，但必须在完整包入口合并为同一个 `ProgramContent.productions`。消费者、回退和完整度验证只读取合并后的统一接口；
- 国家版本作者源允许以 typed partial records 保存集合外候选和尚未完成的整条记录，不要求每个作者文件对全局地点、场次或剧目注册表形成完整 `Record`；不得使用空字符串表示缺失，也不得在任意深层字段逐字符串拼接中文。只有解析后的当前构建快照对获选闭包保持严格完整类型；
- 记录级回退只属于不可部署的作者诊断入口：它按稳定记录返回实际 `sourceLocale` 和缺失或旧译原因，不生成页面，也不成为第四个构建 profile。`showcase`、`preview` 与 `release` 均通过同一严格解析边界拒绝任何缺失、旧译或回退；
- 完整本地化单位记录所依据的炎国源修订摘要。炎国源变化而目标版本未更新时，即使字段齐全也属于旧译；严格 `showcase`、`preview` 与 `release` 按各自范围拒绝旧译或回退；
- 源修订按当前构建快照内稳定记录和真实消息消费组计算；集合外实体或无关消息变化不得使整种语言或不相关记录失效，也不为新增语言复制整包 hash；
- 稳定 ID、ASCII 路由段、枚举、明确标识码、`LMD`、票号数值和纯装饰字符可以不翻译；页面元数据、导航、按钮、表单、状态、错误、无脚本反馈、ARIA 文本、搜索、污染叙事、结算与票面文字均属于本地化范围；
- 里站叙事投影使用稳定实体 ID 与页面职责定位，但可见异常文案、摘要、请柬信息和异常可访问名称仍属于国家版本内容；不得在脚本、CSS、图片或视觉资料中写死炎语，也不得用缺译、乱码或字体故障冒充污染；
- 等级 `3` 的统一剧目、短句、时间、地点、邀请标题与正文、继续／关闭操作、简短状态公告和页面职责变体必须在九个预览国家版本中作为同一完整记录通过严格解析，不运行时回退到炎语。逐字邀请可以是未经人工译审的预览内容，但不得将机械完整度误述为正式译文批准；
- 运营状态标签、原定排期、原因和公告均属于 `PerformanceContent` 的国家版本范围，不得在组件中写死炎语；`effectiveDateTime` 和 `previousDateTime` 是唯一日期事实，国家版本显示值由结构时间与有限格式策略生成，或在解析时验证年月日时分等价，不允许手写显示字符串改变排期；
- 搜索索引、列表、详情和票务输入从同一不可变构建快照派生，不为单个模组维护平行翻译事实。
- 水稻网与跳楼机使用语言无关稳定平台 ID 和 Logo 资产；炎语规范名称、其他国家版本的译名或音译、提示框标题、替代文本和可访问名称属于类型化国家版本内容。预览可以采用 AI 候选，正式发布前随所在国家版本一并人工译审；不得在 Logo、控制器或 CSS 中烘焙炎语兜底。

## 国家版本选择器

- 选择器切换国家版本而非局部界面语言。可见标签只使用注册表中的 `languageName.native`，每个选项使用自身技术 locale 的 `lang`，图形标识不能替代可访问文字；
- 两个及以上版本使用原生 `<details>` / `<summary>` 和普通链接列表作为基础结构；不使用无法可靠承载标识与语言文本的原生 `<select><option>`，也不为普通导航引入通用菜单库或自制 ARIA 菜单；
- 无 JavaScript 时全部选项仍可导航；增强只负责 `Escape`、焦点返回及确有需要的外部点击关闭。当前项具有 `aria-current` 或等价语义，最低 320px 下仍可到达；
- 选择器摘要的可访问名称同时包含当前本国语言名称与“选择国家版本”动作，不能由泛化 `aria-label` 覆盖可见当前值；单语言 showcase 也必须读出“当前版本 + 炎语”；
- 切换优先进入目标版本同一世界和同一稳定页面；没有等价内容时进入目标版本同一世界首页并给出可理解反馈。搜索词不跨版本携带；
- 里站切换复用既有 `archive-locale` 有效事件接口，每次切换至多增加一次事件，不复制两次保护或概率状态机；
- 选项使用国家版本注册中的稳定产品顺序，当前版本不移动位置，不对不同文字系统执行混合字母排序；
- 国家版本徽章通过显式 `editionId -> asset` 映射解析，不从路径、locale、显示名或 `badgeCode` 推导；九枚已注册徽章母版可以常驻所有构建产物，但只有当前构建集合产生选择器选项、内容或页面；
- 徽章使用透明正方形单色 SVG，以标准 `mask`、兼容性 `-webkit-mask` 和 `currentColor` 在既有 `28px` 槽位内着色。不可展开标识、选择器摘要与选项复用同一解析边界；图形为装饰性，本国语言名称和已有标签继续承担可访问名称；
- 徽章替换不得改变 `details` 披露、链接、等价页面目标、Escape 与外部点击关闭、里站污染判定、状态保持或无 JavaScript 导航。素材加载失败时保留槽位，文字与链接仍可用，不恢复字母方框；
- 选择器当前值和每个展开选项都保留自身准确 `lang`，并按该文字片段而非页面根语言解析系统字体；东国语页面中的希腊文、俄文与拉丁文字不得被日文字体栈支配。修正只调整系统字体顺序、字距和片段边界，不引入 Web Font 或通用菜单库；
- `badgeCode` 仍服务页脚事务文案，不因选择器替换而删除。上色徽章只属于非运行时视觉参考，不得被组件、样式或构建入口引用。

## 编码、语言标注与字体

- 仓库文本、结构化数据、HTML、客户端数据和 SVG 统一使用 UTF-8；字符编码与语言是不同维度；
- 页面根元素使用当前国家版本 locale；选项、专名或开发回退与页面主语言不同时，在最小包围元素上声明对应 `lang`；
- 本阶段使用系统字体和 `:lang()` 分别适配 `zh-CN`、`en-GB`、`ru`、`it`、`el`、`de`、`pl`、`ja-JP` 与 `en-US`，只依据可部署页面中观察到的缺字、断行、行高、全角标点、控件截字或窄屏外溢调整字体顺序、尺寸与间距；
- `ja-JP` 使用常见平台系统日文 serif / sans 字体回退及正常日语禁则换行，不使用固定高度、强制单行或省略号隐藏关键信息；只有标识码、日期和明确不可拆分的短字段可以保持单行；
- `en-GB`、`it`、`de`、`pl`、`el` 与 `ru` 优先使用非 CJK 的常见平台 serif / sans 系统字体，并以真实最长字符串验证头部、导航、选择器、卡片、搜索、票务、存单、页脚和污染投影；实测缺字、行高、重音／波兰字符或标点问题才允许调整顺序和间距；
- 选择器须在东国语双站的当前值与九个预览选项上实测中文、日文、拉丁扩展、希腊和西里尔文字的计算字体、文本边界和溢出；哥伦比亚语单项正常不能代替跨文字系统验证；
- 本阶段不引入 Web Font，也不提前为其他国家版本增加字体兼容分支。编码、`lang`、选择器和内容接口必须保持可扩展，尚未进入预览的文字系统留待对应版本开发时单独验证。

## 简体中文基线与开发顺序

- `zh-CN` 是唯一首发基线。必须先完成简体中文表站、里站、内容、功能及既有质量门禁，并经一次人工整体审核确认可发布，之后才能开始其他语言的正式内容开发；
- 简体中文阶段同时建立 locale 感知的路由和内容读取边界，但只发布炎国 `yan / zh-CN`；语言区域可以显示当前语言，不提供空下拉、未开发选项或“即将推出”入口；
- 开始其他语言的正式内容开发前，基于已批准简体中文版本建立轻量翻译范围清单。开发预览可以先由类型化基线机械生成同一范围，但不因此获得发布资格；每项至少定位来源文件或稳定内容 ID、需翻译字段或内容类别，以及所依据的简体中文基线版本；
- 翻译范围覆盖正文、结构化内容、导航、系统反馈、元数据、替代文本、搜索文本、素材内可见文字及其他访客或辅助技术可感知字符串；未发布草稿、纯装饰和无需翻译的专名不计缺失；
- 每轮只声明一个目标 `editionId` 与 locale 并依据同一清单开发。清单只界定范围，不复制译文，也不保存长期进度、人员或审核流水账。

## 回退、完整度与发布门禁

- 作者诊断可以按完整记录执行“目标国家版本 → 炎国”回退并生成只面向开发者的来源清单；该结果不进入沉浸式页面、静态路由或部署产物；
- 三个可部署 profile 共享严格解析器，构建范围内任一记录缺失、源修订过期或发生回退都在页面生成前失败；不得以“开发期”为由生成混合语言预览；
- 一个目标语言达到 `100%`，表示范围清单内全部必需项都已有目标语言内容，并经一次人工整体审核确认；进度可以使用百分比，正式发布门禁只使用“通过”或“不通过”；
- `release` 只发布 `releaseEditionIds` 中摘要匹配、内容与素材闭包完整的国家版本；任一对象不合格时构建失败。未完成版本可以存在于仓库和作者诊断输入，但不得进入正式入口；`showcase` 与九国家版本 `preview` 同样要求各自范围零缺失、零旧译和零回退，只是不要求内容已经获准正式发布；
- 简体中文基线变化后，只将受影响的范围项重新标记未完成；补译并人工确认后恢复发布资格，不因无关变化要求整种语言重审；
- 某国家版本有意不提供地区内容时使用显式内容状态，不用空字符串或从范围清单静默删除表示；
- 结算画面、纪念票、下载与打印版本均属于发布范围。界面、平台与存单使用当前国家版本的完整翻译和格式化规则；纪念票使用举办地语言和按规则需要的维多利亚语票面投影。

## 模组与状态边界

- 搜索按 `{editionId}:front` 与 `{editionId}:archive:{snapshotId}` 生成独立索引，`snapshotId` 只读取当前可访问快照记录；查询归一化使用当前 locale，不在浏览器加载其他国家版本索引后过滤；
- 搜索在归一化后按 Unicode 字素簇计数；炎国与东国至少 `2` 个字素，其他当前国家版本至少 `3` 个字素。门槛由国家版本搜索策略提供，本地化提示只接收数值；当前没有韩语规则，未来新文字系统必须显式定义自身门槛；
- 快照可访问状态、损坏日期显示、馆藏入口、同期搜索与结算失联说明都属于国家版本内容；九个预览版本必须完整提供，损坏记录不能以开发占位符或炎语回退进入可部署页面；
- 客户端筛选、搜索和污染脚本只接收当前页面需要的 locale 与消息子集；票务除当前国家版本界面内容外，可以接收当前可购买场次所需的举办地与维多利亚语受限票面投影。任何客户端都不得加载全部国家版本内容或保留炎语默认文案；
- 票篮、票务流程和冻结结果只保存稳定 ID、枚举和数值，显示标签由当前国家版本重新解析。切换国家版本时这些同标签页业务状态保持不变；未来若改为按国家版本隔离，必须先修改正式票务契约；
- 分区示意拓扑、图形锚点、报价百分比、互斥结果、路线、报价变体、旅程标签和印章语义保持语言无关；舞台方向、分区名称、场馆说明、合作通道、费用说明、失败记录、印章解释及可访问名称属于当前国家版本内容；
- 里站污染等级、有效事件数和稳定会话变体按叙事契约跨国家版本保持；搜索词、披露开合和滚动位置等瞬时输入不因此新增持久化要求；
- 纪念票的屏幕、SVG、下载和打印读取同一票面投影：主 `editionId` 由场次 `locationId` 对应的举办地决定；举办地不是维多利亚或哥伦比亚时再加入维多利亚语小字，二者之一为举办地时不重复第二套英语；
- 举办地与维多利亚语票面字段是当前可购买场次的受限依赖闭包，即使对应国家版本页面不在构建集合中也必须经过同一严格解析与资格检查；它们不产生对应页面、选择器选项或发布资格，客户端也不接收完整辅助语言包；
- 同一冻结结果切换国家版本后，网站、水稻网与存单界面使用目标版本重新呈现，票面仍按各场次举办地规则生成；票号、二维码、价格、Ending 历史、稳定票纹与印章语义保持一致。不得把本地化品牌名、印章文字或分区标签烘焙到语言无关图形资料中；
- 构建验证从当前构建范围派生路由、`lang`、canonical、robots、链接、搜索范围和选择器期望，不把炎国路径或中文句子作为其他版本的通用断言。
- 九个预览国家版本在表站与里站必须拥有同一组页面、搜索、筛选、表站票务、里站静态席位与失联结算、污染、选择器、状态恢复、下载、打印、键盘、无脚本和响应式路径；机械字符串完整度不能代替功能等价验证。

## Demo 基线

- 国家版本注册显式区分 `editionId`、`routePrefix` 与 locale，默认炎国 `showcase`、当前严格 `preview` 与显式炎国 `release` 通过同一构建快照解析入口工作；
- 页面、内容读取、搜索范围和语言显示保留 locale 边界，正式构建不会生成未发布国家版本；
- 九个国家版本的双时间层开发预览已建立完整包、零回退、国家版本选择器与状态边界；炎语以外八种目标语言译文均为未经过人工译审的技术预览内容。
- 国家版本选择器已通过显式 `editionId` 映射消费九枚透明单色徽章母版；徽章资产可以常驻产物，当前构建仍只显示自身集合内的选项，上色候选仍排除在运行时之外。

## Formal 增量

- 保留默认炎国 `showcase`、九国家版本 `preview` 与炎国 `release` 三个命名预设，并让它们消费同一构建快照和严格本地化解析入口；
- 在正式构建继续只发布炎国的前提下，保持其余八个国家版本完整双时间层预览、记录级内容解析、覆盖报告和构建范围驱动的静态生成；
- 让搜索、筛选、污染、票务界面与存单消费当前国家版本内容，搜索使用显式字素门槛，纪念票消费举办地与可选维多利亚语投影，并让票务与污染状态在切换国家版本后保持；
- 为里站等级 `2—3` 的可见叙事投影提供类型化九国家版本内容，保持稳定实体、路由和等级 `0` 源内容不变；
- 以原生结构、正方形单色徽章和系统字体验证九种语言的长文本、日文禁则换行、拉丁扩展与波兰字符、希腊文组合符、俄文长词、搜索归一化、等价页面、焦点、无脚本和最低 320px 路径；
- 后续版本继续按“一次一个国家版本”的流程建立范围清单、作者诊断和发布门禁，不把本阶段九国家版本视觉结果外推为未注册文字系统已适配。

## 验收

- 增加国家版本不要求逐个改写组件业务逻辑，显示名、路径前缀和技术 locale 不互相推导；
- 简体中文页面与入口不依赖其他国家版本整站即可构建、审核和发布，正式产物不含未开发版本入口；但可购买的境外场次必须具备其举办地和维多利亚语票面所需的受限、已批准字段，不能以整站未发布为由回退炎语；
- 作者诊断缺失不会进入页面；正式发布集合与最终九国家版本预览均不含回退内容；
- 选择器在表站与里站保持世界和等价页面，纯链接路径、键盘、焦点、320px 和无 JavaScript 行为成立；
- 选择器每个选项按自身 `lang` 使用可覆盖其文字系统的系统字体；东国语页面中的希腊文、俄文和拉丁文字没有异常全角字距、缺字或溢出；
- 正式炎构建与九国家版本预览分别只显示其构建集合内的国家版本选项；九枚徽章资产可以常驻，九枚徽章在 `28px` 槽位、表里站主题及交互状态下与相邻文字同色、可辨识且不被裁切；
- 同一内容在不同国家版本中保持稳定身份；票篮、冻结结果与污染状态在切换后保持，搜索和发布范围仍严格隔离；
- 水稻网与跳楼机在九国家版本中都有完整品牌显示名和可访问标题；票面按举办地选择主语言，并只在非维多利亚／哥伦比亚场次增加维多利亚语小字，不加载完整辅助语言包；
- 接入下一国家版本只需新增内容、术语、必要字体适配和明确构建集合项，不复制页面、领域事实或模组状态机。
- 当前没有批准内容时，默认 `showcase` 仍可部署，而显式 `release` 会以具体稳定 ID 和资格原因失败，不会把预览静默提升为正式内容。
