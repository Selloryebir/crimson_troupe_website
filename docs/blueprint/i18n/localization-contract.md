# BP-I18N-CORE｜本地化契约

## 用户结果

用户能够在受支持语言中理解导航、内容、状态和错误，不因切换语言丢失当前任务或叙事含义。

## 边界

- 负责 locale 解析、路由策略、格式化、翻译键、降级和布局适配；
- 不把中文原文作为程序键，不把机器翻译自动视为批准内容；
- 不要求 Demo 阶段立即翻译全部内容。

## 行为契约

- 稳定内容和翻译键不随展示语言变化；
- 缺失翻译使用明确的默认语言策略，不渲染空白界面；
- 日期、时间、数字、替代文本、元数据和搜索归一化都属于本地化范围；
- 表站正式语气与里站档案语气可以使用不同文案，但共享稳定概念 ID。

## Demo 基线

- 当前单语言界面保持可读；
- 新内容使用稳定 ID，为未来 locale 字段保留清晰迁移路径。

## Formal 增量

- 先为站点外壳和一个表站、一个里站模组接入第二语言及伪本地化；
- 验证长文本、字体、断行、搜索别名和语言切换后的焦点及路径；
- 根据真实发布语言静态生成对应页面。

## 验收

- 增加语言不要求逐个改写组件业务逻辑；
- 缺失翻译不会破坏导航和退出；
- 同一内容在不同语言中保持稳定身份。
