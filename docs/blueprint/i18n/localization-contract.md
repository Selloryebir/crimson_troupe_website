# BP-I18N-CORE｜国家版本与本地化契约

## 用户结果

用户能够在已经完整发布的国家版本中理解导航、内容、状态与错误；开发中的翻译缺失不会造成空白页面，也不会混入正式产物。

## 边界

- 负责国家版本注册、locale 解析、发布集合、翻译键、开发期回退、格式化、布局适配和翻译完整度门禁；
- 国家版本 ID `editionId`、公开路径段 `routePrefix` 与技术 locale 是不同字段，当前一一对应；
- 不把中文原文作为程序键，不从显示名推导 URL，不把机器翻译自动视为批准内容；
- 不要求简体中文基线完成前制作其他语言内容。

## 注册与路由协作

- `editionId` 与 `routePrefix` 必须显式存储，不能根据英文名、显示名或彼此拼接推导；显示名称也不得反向参与 URL 生成；
- 所有公开 URL、切换链接、canonical、搜索结果链接和静态生成路径使用对应 `routePrefix`；页面 `html lang`、日期、数字、分词和搜索归一化使用技术 locale；
- 技术 locale 只描述现实语言处理规则，不表示泰拉实体属于对应现实国家；拉特兰直接使用标准拉丁语 `la`，不增加项目私用 locale；
- 国家版本共享网站能力、稳定内容 ID 和主要结构；必要地区差异使用显式内容字段，不复制整套页面；
- 本矩阵已由人工确认完整、正确且不存在已知问题。除非人工明确要求修改具体值，否则不恢复并行 CSV，也不重复审计实体内容；实现仍需机械检查 ID 唯一性、路径格式和必填字段。

## 简体中文基线与开发顺序

- `zh-CN` 是唯一首发基线。必须先完成简体中文表站、里站、内容、功能及既有质量门禁，并经一次人工整体审核确认可发布，之后才能开始其他语言的正式内容开发；
- 简体中文阶段同时建立 locale 感知的路由和内容读取边界，但只发布炎国 `yan / zh-CN`；语言区域可以显示当前语言，不提供空下拉、未开发选项或“即将推出”入口；
- 开始其他语言前，基于已批准简体中文版本建立轻量翻译范围清单。每项至少定位来源文件或稳定内容 ID、需翻译字段或内容类别，以及所依据的简体中文基线版本；
- 翻译范围覆盖正文、结构化内容、导航、系统反馈、元数据、替代文本、搜索文本、素材内可见文字及其他访客或辅助技术可感知字符串；未发布草稿、纯装饰和无需翻译的专名不计缺失；
- 每轮只声明一个目标 `editionId` 与 locale 并依据同一清单开发。清单只界定范围，不复制译文，也不保存长期进度、人员或审核流水账。

## 回退、完整度与发布门禁

- 开发环境按“目标 locale → `zh-CN`”回退；回退不改变 URL、国家版本或搜索范围。页面根元素保留目标 locale，实际回退为中文的内容节点标记 `lang="zh-CN"`；
- 开发期缺失生成面向开发者的清单或构建报告，不在沉浸式页面中显示警告；
- 一个目标语言达到 `100%`，表示范围清单内全部必需项都已有目标语言内容，并经一次人工整体审核确认；进度可以使用百分比，正式发布门禁只使用“通过”或“不通过”；
- 正式构建只发布显式列入 `releaseLocales` 的语言；集合内任一语言不完整时发布失败。未完成语言可以存在于仓库和开发预览，但不得进入正式入口或形成中外文混排页面；
- 简体中文基线变化后，只将受影响的范围项重新标记未完成；补译并人工确认后恢复发布资格，不因无关变化要求整种语言重审；
- 某国家版本有意不提供地区内容时使用显式内容状态，不用空字符串或从范围清单静默删除表示；
- 结算画面、纪念票、下载与打印版本均属于发布范围，必须使用当前国家版本的完整翻译和格式化规则。

## Demo 基线

- 国家版本注册显式区分 `editionId`、`routePrefix` 与 locale，当前发布集合只包含 `yan / zh-CN`；
- 页面、内容读取、搜索范围和语言显示保留 locale 边界，构建不会生成未发布国家版本；
- 其他语言开发尚未开始，因此开发期中文回退与翻译完整度门禁暂不产生访客侧输出。

## Formal 增量

- 先完成只生成 `yan / zh-CN` 的国家版本注册、静态路由、内容读取和语言显示边界；
- 简体中文经人工确认可发布后，再按“一次一个国家版本”的流程建立范围清单、开发、回退报告和发布门禁；
- 验证长文本、字体、断行、搜索归一化、切换后的等价页面、焦点与路径。

## 验收

- 增加国家版本不要求逐个改写组件业务逻辑，显示名、路径前缀和技术 locale 不互相推导；
- 简体中文网站不依赖其他语言即可构建、审核和发布，正式产物不含未开发版本入口；
- 开发期缺失不会破坏导航或退出，正式发布集合不含回退内容；
- 同一内容在不同国家版本中保持稳定身份，票务及搜索遵守同一发布门禁。
