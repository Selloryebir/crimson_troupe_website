# BP-QLT-STAGES｜实现成熟度与正式门禁

蓝图使用统一阶段描述实现成熟度，不为 Demo 与 Formal 维护两套图纸。具体检查命令只在 `AGENTS.md` 和开发指南维护，本文件不复制运行日志。

## 阶段

- `planned`：目标和边界已明确，尚无完整用户闭环；
- `demo`：最小用户闭环可部署、可浏览，已知缺口在同一蓝图的 Formal 增量中说明；
- `candidate`：目标契约已经实现，正在验证正式内容、可靠性和发布条件；
- `formal`：正式范围内的内容、无障碍、性能、安全、权利和失败路径均达到发布要求。

`status` 与阶段不同：`active` 表示当前有效的正式蓝图，`retired` 表示已经终止且不再约束开发；二者不能表达代码完成度。尚未采纳的蓝图留在 `docs/drafts/blueprint/`。

## 晋级原则

- 晋级依据少量可观察结果，不要求问卷、会议记录或重复摘要；
- Formal 不等于必须接入后端，可靠的静态能力也可以正式发布；
- 暂无真实需求的后台、账号、遥测、实时插件和复杂抽象不能成为晋级前置条件；
- 未通过的条件保留为明确差距，不通过反复改写蓝图掩盖；
- 阶段变化只更新追踪表中的单一字段，不复制蓝图正文。

## 全阶段不变量

- 手机端与电脑端完成相同任务，最低 320 CSS 像素，并覆盖 375/390、768、1024、1280/1440 等代表视口及更宽桌面；
- 不出现页面级横向内容丢失、主要操作遮挡、文本脱离容器或仅可通过 hover 完成的任务；
- 表站与等级 `0` 里站核心内容在无 JavaScript 时可读，里站和高交互模组始终可退出或返回；
- 交互具有键盘路径，焦点与语义可靠，动画遵守减少动态效果；
- 不进行真实交易，不收集未声明数据；项目内容、创作资料和外部参考保持责任分离；
- 验证强度与实际改动风险相称，不让日常检查无理由升级为全仓重复门禁。

## 内容生命周期门禁

- 当前全部运行时内容默认属于未批准预览；阶段验收、分支合并、目录位置或构建成功都不能提升内容资格；
- `showcase` 为默认炎国可部署预览，`preview` 为国家版本矩阵中的九项严格预览，二者允许未批准内容但必须达到各自范围的完整闭包、零旧译与零回退；
- `release` 只接受摘要匹配的批准站点公共单元、根集合和场次闭包。正文、译文、素材、Artwork 参数、座席、权利状态、成员、顺序或焦点变化后对应资格失效；当前没有批准基线时，显式 `release` 失败是正确结果；
- 列表、首页、详情路由、搜索、票务和验证器必须消费同一构建快照；集合外实体不得通过深层 URL、搜索、票务或内容资产泄漏；九枚已注册国家徽记是允许常驻产物的全局品牌资产豁免，但不得产生未构建国家的页面或入口；未来若实现站点地图，也必须沿用该快照；
- 内容聚焦检查覆盖 ID、完整变体、根集合顺序与焦点、依赖闭包、翻译源修订、必要素材、派生时间集合和发布资格；日常内容改动不因此重复执行完整全仓门禁；
- 人工继续负责逐字文案、翻译质量、艺术方向和发布选择，自动摘要只检查当前精确版本，不冒充内容审核。

## 简体中文与多语言门禁

- 当前首发候选只包含完整的炎国 `yan / zh-CN` 双站；简体中文必须先通过既有工程门禁及一次人工整体发布审核，之后才允许开始其他语言正式内容开发；
- 其他国家版本必须完成其翻译范围清单的全部必需项，并经一次人工整体审核，才能加入 `releaseEditionIds`；集合中任一版本不完整时正式构建失败；
- fallback 只允许不可部署的作者诊断使用；`showcase`、`preview` 和 `release` 都不得含回退、旧译、未开发路由或未开发选择器选项；
- 国家版本注册、构建范围与正式发布范围必须分离。默认 `showcase` 构建炎国预览，`preview` 按国家版本矩阵顺序构建全部九项，显式 `release` 只消费 `releaseEditionIds = ['yan']` 的批准内容；未知预设在生成页面前失败；
- 最终可部署九国家版本预览与正式构建都必须对各自范围达到机械覆盖完整且零回退；炎语以外八种预览译文通过技术门禁不等于完成翻译人工审核，也不允许进入正式发布集合；
- 简体中文基线变化只使实际受影响的翻译范围项失效，不要求无关内容重复审核。

## 本阶段九国家版本预览门禁

- 炎国正式产物保持既有双站、页面、搜索、污染与票务功能；在既有五项预览上依次加入维多利亚、叙拉古、莱塔尼亚和卡西米尔，每次只扩展一个完整包并验证路由、`lang`、canonical、robots、链接、资源和搜索隔离，最终按国家版本矩阵顺序形成九项集合；
- 产物页面数由当前国家版本、日期快照规范路由与旧年份兼容重定向机械推导，不在门禁中维护固定总数；损坏快照记录不得增加页面、索引或内容根集合；
- 九种语言在表站首页、演出列表与详情、表站票务、里站首页、演出列表与详情、里站搜索等代表页面覆盖 320、390、768 与 1280 CSS 像素，并检查键盘、减少动态效果和无 JavaScript 路径；
- 国家版本选择器使用原生可导航结构、当前构建集合的正方形徽记和系统字体；九项在 320px 与常见窄屏高度内均可到达，无横向内容丢失、截字、缺字、焦点丢失或不可退出。日文使用正常禁则换行，拉丁扩展、希腊文与俄文使用实测系统字体序列；
- 状态确定性验证遍历全部预览国家版本，证明票篮、冻结结果和污染状态不保存显示文字且在切换后保持；里站国家版本切换仍至多触发一次污染判定；
- 九个国家版本必须具备等价的页面、搜索、筛选、表站票务、里站同期静态席位与失联结算、污染、选择器、下载、打印、键盘、无脚本和响应式路径；字符串覆盖率不能代替功能等价验证；
- 正式完整门禁执行一次后，预览只补充其独有的 locale 覆盖、预览构建和预览产物验证，不重复运行相同质量子门禁。

## 本阶段双时期视觉门禁

- 本阶段对现有双站艺术、剧目物料和污染表现进行一次完整升级；先用代表性剧目、跨时间层对照、陌生标题和 `0—3` 分镜通过一次人工艺术方向门，后续不逐资产重复审批；
- 先用表站首页、表站票务、里站首页、里站搜索和代表性剧目详情建立模式，再覆盖现有八类页面族；不得用少量样张或逐页特例替代整个运行时范围；
- 每个代表页面必须形成页面环境、内容表面和舞台或档案焦点三层视觉关系；表站体现当代编辑系统与受控电影舞台，里站等级 `0` 体现仪式轴线、嵌套框景和可查阅旧档案，差异不能只来自明暗或换色；
- 当前七个运行时可见剧目必须各有主体、观看路径和记忆色，列表与详情消费同一视觉身份；同一剧目的表站与里站等级 `0` 资产保持身份关联但不被理解为换色、损坏或升级；
- 九种预览语言分别覆盖桌面与最低 320px，并检查系统字体、长标题、日文假名与全角标点、拉丁扩展和波兰字符、希腊文组合符、俄文长词、导航、搜索反馈、票务状态、页脚和国家版本选择器；不得出现页面级横向内容丢失、强制单行、不可理解截断或关键缺字；
- 表站与里站等级 `0` 的色值、纹理、边框、暗角、图文叠加和动效不得削弱对比度、任务顺序、焦点、减少动态效果、无 JavaScript 降级、打印票面及退出路径；等级 `1—3` 可以按污染契约改变主内容视觉关系，但最低保护能力仍按下方污染门禁验收；
- 正式运行时只采用原创且权利边界明确的生成或绘制资产；生成图不含本地化标题、官方角色、徽记、独特边框、伪文字或近似复制的构图；
- 完成度由任务可完成性、双站辨识、跨页面一致性、九国家版本稳定性和剧目视觉区分共同判断，不使用与参考图的截图相似度、装饰数量或滤镜强度作为门禁。

## 能力化检查与浏览器证据

- 日常 `quality -- <paths>` 按实际变更能力追加内容、locale 或状态检查；纯文档不运行 Astro、代码 lint、构建或浏览器，普通 TypeScript 改动也不无理由执行两个 profile 构建；
- 阶段收口只运行一次完整质量门禁；其后只补当前完整门禁未覆盖的 preview locale、一次 preview 构建、preview 产物和代表性浏览器冒烟，不重复完整质量或 showcase 构建；
- 浏览器矩阵使用单一轻量入口覆盖桌面表站、320px 表站票务、320px 里站、日/希/俄最长头部、选择器键盘与无 JavaScript、搜索初始化失败、票务焦点与票面、减少动态效果、污染升级和可靠退出，不建立全语言乘全路由乘全视口截图系统；
- 响应式证据联合检查页面 `scrollWidth`、关键元素边界和当前聚焦元素是否仍在视口内；隐藏横向溢出或截图看似完整不能单独作为通过证据；
- 源码与静态产物门禁覆盖常见自动请求、`sendBeacon`、`EventSource`、远端 iframe/object/embed 和 CSS 远端 URL，不误伤普通外部导航链接；该门禁是受控仓库防回归，不声称证明任意混淆代码安全。

## 污染门禁

- 每轮前两次有效事件强制保持等级 `0`，从第 `3` 次起使用固定 `42%`。前 10 次实际概率判定达到等级 `3` 的理论概率约为 `86.2839%`，等价于从进入开始前 12 次有效事件；从进入开始前 10 次事件的对应概率约为 `72.5%`，不进行概率补偿；
- 自动化模拟、开发构建或受控体验测试应覆盖四个等级、五类触发、前两次保护、一次动作一次事件、概率成功与失败、封顶、刷新保持、主动清除和新标签页隔离；
- 任意等级不得改变 DOM 语义与标题层级、焦点和键盘顺序、替代文本、减少动态效果、搜索范围或视口安全；主导航、国家版本选择器、返回表站、页脚同人声明、邀请关闭与恢复路径保持正常呈现和操作；
- `0 / 3 / 6 / 10` 只作为等级 `0—3` 的感知验收标尺，不成为第二套运行时状态。等级 `1` 无需截图对照即可发现至少一处有因果的异常；等级 `2` 至少形成两个相关区块的矛盾；等级 `3` 接管主内容环境并达到明显认知崩坏；
- 等级 `1—3` 必须按“物件内部 → 物件边界 → 内容框景 → 页面环境”递进；删除线、通用红叉、全屏红线、无来源恐吓句、无因果随机位移和统一滤镜不得作为替代实现；
- 等级 `0—2` 不显示克莱布拉松演出信息；等级 `3` 按页面职责收束到请柬主轴，但稳定场次、合法 URL、搜索归属、任务数量与退出路径保持不变；
- 首页、本季与历史演出、场次／剧目详情、剧团、搜索和静态席位页分别按职责验证等级 `3` 投影；记录数量、排序、合法 `href`、搜索匹配／计数和稳定内容不因投影变化；
- 等级 `3` 页面初次呈现不自动打开邀请。只有受污染的主要内容触发共享语义对话框；可见关闭、`Escape`、焦点进入与返回、继续原合法链接、无 JavaScript 原导航均成立，导航、国家版本、页脚和返回表站不被拦截；
- 邀请使用错版外框、跨网格印章、重印、遮蔽、留白或字段矛盾表现为从当前页面伸出的实体物件，不退化为规整信息卡；完整邀请不作为 live region 自动朗读，只用一条简短本地化公告表达状态变化；九国家版本的投影与邀请字段零缺失、零旧译与零回退；
- 等级 `1—3` 各提供至少三种可复用构图族，并与页面职责组合。同一状态与规范路径刷新后构图相同；合格页面切换可以得到另一种同等级构图，但不调用第二次随机、改变污染值或降低强度；
- 非保护叙事控件可以连同真实命中框发生有界位移、倾斜、层叠或外观反转，桌面和 320px 下仍可聚焦、点击并执行原动作；不可读镜像、倒置、乱序和大尺度重复只使用不交互且不进入辅助技术阅读顺序的装饰副本；
- 不使用廉价跳脸、频闪、持续随机运动、自动弹窗、自动音频、强制全屏、自动下载、剪贴板或指针操作。减少动画在桌面与 320px 都显示同等强度的静态终态，不降低投影等级；
- 正式产物不得包含污染调试 UI 或控制代码，不能只用 CSS 隐藏。

## 票务门禁

- 覆盖至少一个成功、失败和网络波动结局，并验证失败、波动、支线取消与重试时票篮保持，成功后结果冻结且不重复生成；
- 三个可购场次的分区图、图外选择、价格和纪念票只消费各自实际 `TicketOffer`；特里蒙与维谢海姆区分池座、楼层和多个包厢，旧车站只出现 `C / B / A`。键盘、屏幕阅读顺序与 320px 路径不依赖点击 SVG；
- 未勾选场次时仍可切换预选分区且不会隐式入篮；勾选、改区、取消和返回选择阶段保持预选与票篮边界，空票篮不能提交；
- 三个场次使用彼此不同的未批准预览报价，旧车站共享等级明显较低；分区控件、价格计算、失败费用、存单和票面都从当前场次 `TicketOffer` 读取，删除分区后不留残余状态；
- 五个里站可售场次从单一“剧目 × 场馆报价键”矩阵获得各自最终 `TicketOffer[]`，不共用默认报价；至少一场缺少部分分区，同剧目异地和同地点异剧目均具有可观察价格差异；
- 报价矩阵固定按 `[C, B, A, S, BOX]` 使用正整数或 `'-'`，转换后有效分区非空、无重复且价格严格递增；人工调整候选价格只编辑矩阵，场次、组件和本地化不复制金额；
- 里站等级 `0` 静态席位页按同期事实显示场次、分区和价格，最终控件无链接且真实失活；无 JavaScript 下说明仍可读，不建立表站票篮、概率流程或结果下载；
- 以注入结果序列证明网络波动不连续、一次性挽留不重复、第三个需重新提交结果后必然通过席位回流或人工复核收束；不得以浏览器随机碰运气完成验收；
- 存单区分 `baseTotal`、`adjustments` 和 `settledTotal`，逐场纪念票只显示对应 `basePrice`；
- 优先线路原报价、挽留报价和失败服务费分别满足 `150%`、`148%` 与 `25%` 不变量；接受前信息完整，优先失败无票、无下载且不声称真实扣款；
- 屏幕、下载和打印版本包含同一必要信息，印章不遮挡场次、时间、分区、基础价格或二维码；
- 普通直接成功、网络恢复、回流成功与优先成功的组合印章可区分；相同冻结结果跨国家版本重新渲染时票号、票纹和印章语义稳定，不显示成就缺口或诱导重复刷取；
- 关闭模组、禁用脚本或模拟加载失败时，稳定票务页、不可用反馈和返回路径仍成立。

## 正式候选验收

- 直接访问、刷新、站内导航和浏览器历史覆盖表站与 `1091-07-01` 日期快照的核心页面，旧年份路径只重定向到正确等价规范路径；
- 桌面、窄屏、键盘、减少动态效果和无 JavaScript 路径满足上述不变量；
- 静态产物中的目标 URL、站内链接、本地资源、`lang`、canonical、robots 和重复 ID 均符合正式范围；
- 页面与内容通过已有权利、来源和人工内容审核，只有通过门禁的国家版本进入产物。
- 开发预览必须与正式发布资格清楚区分，不得把 AI 英译、日译、现代希腊语或俄译覆盖完整描述为已经人工审核或正式发布。
