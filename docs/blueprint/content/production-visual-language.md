# BP-CNT-PRODUCTION-VISUAL｜剧目视觉与猩红印版

## 用户结果

用户可以从剧目的图像、出版框架和记忆色辨认作品身份，并能把表站与里站等级 `0` 理解为同一剧团谱系下的两种时间层装帧；里站污染沿同一印版逻辑逐级越出物件，而不是退化为通用黑红滤镜、故障符号或随机破坏。原创视觉与经人工指定的里站官方活页修复资源分属两种来源，不互相冒充。

## 边界

- 负责剧目视觉身份、剧团出版制度、表站与里站等级 `0` 的时间层资产、猩红印版、物件污染接口、素材权利边界和艺术验收；
- `Production` 的稳定 ID、来源类别和字段归属由 `BP-FND-DOMAIN` 负责；可见标题、替代文本和国家版本内容由 `BP-CNT-CORE` 与 `BP-I18N-CORE` 负责；
- 污染等级、概率、触发和会话变体由 `BP-FND-NARRATIVE` 负责，页面级作用对象、编排时机和叙事投影由 `BP-MOD-ARCHIVE` 负责；本蓝图只声明物件内部焦点、记忆色、裁切安全区和可跨越接缝；
- 原创视觉不复制本地参考原图、角色、徽记、标题字形、边框或独特构图，不把标题推演写成游戏官方剧情，不要求全部剧目采用同一种中央画法；人工指定的官方活页修复封面仅作为里站特定来源的例外，须保留非原创身份和权利记录；
- 不把整页、HTML 文字、交互控件或每个污染等级烘焙成位图；不为没有页面消费者的剧目预制原创运行时资产。成对活页修复图允许完整存为里站资源，但不因此生成剧目实体、页面或构建输出。

## 剧团出版制度

原创剧目视觉的统一性来自剧团长期使用的出版制度，而不是统一画风。中央图像可以采用纹章、崇高风景、三联画、童书、博物学图谱、圣像、静物、民俗版画或拼贴；外围副文本使它们仍被理解为同一剧团制作、流通和归档的节目物件。下表约束原创资产，不要求重绘已经获准入库的官方活页修复图。

| 层级           | 稳定职能                                 | 创作约束                                                     |
| -------------- | ---------------------------------------- | ------------------------------------------------------------ |
| 纸面与物件边界 | 证明物料可被制作、流通和保存             | 建立材料与年代，不用褐色滤镜代替设计                         |
| 外框与角部     | 提供剧团归属、舞台口和出版秩序           | 继承密度和功能，不复制既有花纹、角饰或徽记                   |
| 上部题签       | 向观众清楚承诺节目                       | 图像内不依赖可读文字；本地化标题始终由 HTML 叠加             |
| 中央舞台       | 把标题压缩成可观看、可进入或可供奉的事件 | 每张先形成独立隐喻，不把不同标题塞进同一模板                 |
| 底部归属区     | 表达稳定印务、登记和档案制度             | 中轴固定原创归属标记的轮廓与安全区，不复制官方徽记或逐图变形 |
| 印刷表面       | 让异质画法属于同一物质世界               | 深墨轮廓、色块、陈金、颗粒和套色差按尺度分工，不遮盖构图     |
| 字体关系       | 补充剧目体裁                             | 图片标题可以有性格，运行时标题仍以本地化 HTML 保持可读       |

作者侧可以使用“双层委约”理解职责：剧目画师负责中央隐喻、媒介和记忆色；剧团艺术、印务或档案部门负责题签、框景、归属印记、登记和时间层装帧。该模型只指导本站创作，不宣称参考素材真实采用这些岗位或媒介。

## 剧目视觉档案协作

按稳定 `productionId` 维护的十三项身份、题义、构图机制与记忆色位于 [`BP-CNT-PRODUCTION-VISUAL-CATALOG`](production-visual-catalog.md)。本蓝图只规定所有剧目共同遵守的出版、时间层、污染和运行时结果；具体创作步骤、间接指称和可迁移修辞只由 [`剧目视觉创作指南`](../../guides/production-art-authoring.md) 负责。

视觉档案不自动生成运行时剧目或页面。原创时间层资产只有在剧目被内容集合选中且拥有真实页面消费者时才制作和登记；里站活页修复图的成对资源入库按下述来源例外处理。

## 时间层资产与猩红印版

### 时间层轴

- 原创表站资产使用完整矩形、清楚套色、剧目专属色和当代编辑裁切；不安来自题义的第二读法，不存在运行时污染；
- 原创里站等级 `0` 使用独立的闭合猩红装帧：煤黑边、半透明猩红烟版、旧金内线、重复裂口和不规则外缘均有意对齐，属于 1084 剧团正式物料；
- 外围出版框架默认维持可辨认的中轴和左右对称，题义需要的缺席、断裂或空间悖论在中央图像中有意破坏秩序；不把生成误差或无意义不对称解释成戏剧性；
- 原创的两种时间层资产共享剧目身份，但不被描述为升级、修复、损坏、替代或先后迭代。同一剧目实际进入两个时间层时才制作成对运行时资产；尚未采用的时间层不预制无消费者副本。

官方活页修复资源是上述原创时间层制度的受控例外：普通版和猩红版均归里站 `archive`，不是表站与里站的对应关系。完整的 13 对图像可作为里站资源保存，实际输出由当前内容快照与投影消费者决定。来源、文件摘要和权利范围以 `docs/sources/folio-cover-restoration.md` 为准。

里站活页封面按同一污染状态切换：等级 `0` 全部普通版；等级 `1` 按会话种子从当前快照的活页剧目集合抽取最接近三分之一的剧目使用对应猩红版（当前 8 项取 3 项）；等级 `2` 全部使用各自猩红版；等级 `3` 全部使用猩红版《摇篮曲》。抽取按稳定剧目 ID 进行，刷新、语言切换、列表与详情及重复场次保持同一身份结果，不按当前页面卡片数量重新抽取。等级 `3` 的来源身份可以仅作为投影资源存在，不因此新增普通剧目实体或路由。

普通与猩红版均完整显示，保留原有透明撕纸边缘；不添加重复题签、重度滤镜、放大裁切或前景遮罩覆盖修复细节。可选版本在临近视口时加载，成功解码后替换同一个图像元素。等级变化时立即撤下不匹配的旧封面，包括离屏记录；等级 `2` 和 `3` 在慢加载或失败时只保留局部中性占位、当前等级标题与合法链接，不用其他等级封面降级，不出现对应猩红与猩红《摇篮曲》混用。等级 `1` 图片失败可保留普通封面；状态回退恢复普通版。无 JavaScript 时保留普通版与合法导航，不增加全页等待或遮罩。

### 猩红印版结构

“印版”是本站组织视觉的艺术层，不声称真实印刷工艺。

| 层次             | 可见结构                                         | 叙事职能                               | 制作约束                                 |
| ---------------- | ------------------------------------------------ | -------------------------------------- | ---------------------------------------- |
| 剧目身份底版     | 中央主体、观看路径、题签区、剧目主色和记忆色     | 回答“这是什么剧目”                     | 不能被统一黑红处理抹平                   |
| 边缘煤黑版       | 角部、两侧和下缘不均匀压暗，中心保留观看窗口     | 把活页变为被收存或押入舞台口的物件     | 不使用四边等量暗角或整个容器滤镜         |
| 半透明猩红烟版   | 氧化红、焦红和灰粉红的大尺度薄烟、擦印和局部色雾 | 宣示旧剧团装帧权力并允许下层记忆色存活 | 不使用单一纯红蒙版                       |
| 重复裂口版       | 题签下缘、中部上扬、侧边和底缘的浅芯红黑裂口     | 让共用印版跨过既有出版边界             | 不是发光线、删除线、涂鸦或相同的 X       |
| 不规则物件轮廓版 | 略扩大的焦黑外缘、红边和透明缺口                 | 让活页具有厚度并能与页面环境衔接       | 不裁掉焦点、标题、替代文本主体或交互区域 |

大尺度烟幕、中尺度裂口和小尺度纸纤维不能在同一位置同时高强度出现；层次来自尺度分工，不来自纹理数量。

### 污染接口

每个可被污染的剧目或人物视觉至少声明：

- 不得遮挡的标题、面部或主体焦点；
- 必须保留的剧目记忆色；
- 可被压暗的边角和空场；
- 适合错版的颜色层；
- 裂口应顺应或逆转的观看路径；
- 等级 `2` 可以跨越的内外框接缝；
- 等级 `3` 可以与页面环境衔接的边界方向；
- 320px 裁切和减少动态效果下的稳定结果。

通用组件依据显式资料选择确定性视觉档案，不通过 DOM 顺序或每次渲染随机猜测。页面级对象、等级、会话变体、派生构图和应用时机不由本蓝图或图片元数据拥有。

## 混合资产与网页转译

- 原创剧目主体、复杂背景、人物和场景使用无文字位图；等级 `1—3` 使用少量透明污染层、印版遮罩和轻量 CSS，不为每级生成完整页面大图；
- 导航、按钮、正文、标题、状态、焦点和响应式布局继续使用语义化 HTML/CSS 或项目自有简单矢量；团标使用经人工采纳的透明哑光或金属母版，由构建管线生成现代压缩格式，仍由相邻 HTML 品牌名承担可读身份，图片中的绶带文字不成为唯一信息。里站等级 `1—3` 可以污染这些叙事载体的可见装帧，但不得把导航、语言、返回、声明、退出或合法链接烘焙进图片；
- 正式资产进入 `src/assets/`，声明明确宽高、焦点和裁切，使用响应式尺寸与现代压缩格式，非首屏懒加载；
- 原创剧目视觉生成只使用本蓝图和作者指南的文字要求，不使用参考原图作图生图输入；这条原创流程限制不把已登记的官方活页修复图误写成原创生成物。团标的已批准例外以项目负责人提供的正式 Logo 为身份锚点、以蚀刻章集合归纳材质语言，来源、人工授权和不得复制项由 `docs/sources/troupe-logo-provenance.md` 记录；所有原创生成结果仍检查构图近似、伪文字、官方标识、角色、独特边框和权利风险；
- 页面环境只抽取出版制度的空间逻辑，不把高密度封面纹理平铺到正文后：表站用清洁纸面、现代舞台暗面、精准裁切和开放留白，里站用深廊外围、旧纸阅读岛与闭合框景；
- 等级 `3` 可引用一份可替换的原创投影视觉，使原本不同的剧目物件在页面中显示同一演出身份，再以少量透明印版、裁切遮罩和轻量 CSS 将猩红印版扩展到页面环境。不为每张记录或每个污染等级生成平行大图，也不在图片中烘焙本地化标题或邀请正文；
- 剧目视觉物件及其真实链接外框可以发生有界位移、倾斜、越界和空间层叠，命中框、焦点轮廓、可访问名称与原链接随真实物件保持。不可读镜像、倒置、乱序与大尺度重复只生成装饰副本；副本不成为第二个替代文本、链接、焦点或屏幕阅读项。窄屏裁切优先保留真实物件与保护能力，而不是保全全部装饰副本；
- 团标以弧形眼框、左笑右悲且分别朝外的双面具、指向面具的放射条、垂直剑形中轴及下方 `CRIMSON TROUPE` 绶带保持品牌身份；不是菱形背板或相向面具。保留人工选定的哑光与金属两种设计，各自复用唯一母版，不逐处重新生成，也不强行把两版已采纳的材质和轮廓细节改成相同像素；
- 表站与里站的页头、页尾、海报独立印记、邀请章及其他小型团标默认使用哑光版；双站首页大展示显式使用金属版，表站在当前巡演季区域形成品牌焦点，不覆盖主标题、重点剧目与行动入口。变体与响应式尺寸分开指定，小标不因位于首页而自动切成金属，污染与国家版本不改变素材选择；官方活页封面内嵌团标不因此重绘；
- 两版外背景与护手周围空隙保持真实透明，眼框内部有意保留深墨内衬；透明棋盘不能烘焙为可见底色。接入不改变已采纳前景，构建输出保留完整轮廓、比例、材质和透明边缘，不将放大像素尺寸当作新增细节；
- 形状错误的 A 版“舞台印章”和旧 D 版环境光衍生稿已淘汰，不属于可采用备选，也不得重新接入运行时。具体来源、母版摘要及权利边界由来源记录拥有，不把人工采用等同于权利方发布许可；
- 人物相框只有在已有人员内容需要视觉承载时使用，不为展示样式而新增人物实体或肖像；人物身份与链接保持在框外 HTML。

## 非目标

- 让全部剧目使用同一中央构图、配色或边框；
- 只按英文或任一单独国家版本标题直画中心名词，把其他标题提供的关系与意象丢弃；
- 把原创的两种时间层资产解释为损坏、升级、修复或先后迭代；官方活页普通／猩红版的里站污染切换遵循上述来源例外，不把它们误作表里站对应关系；
- 因 13 对里站活页修复资源已入库，就自动建立尚未采用的运行时剧目实体、详情或页面消费者；
- 用统一红色、噪点、暗角、故障、眼睛、血迹、乱码或恐怖字体制造“猩红”；
- 让生成图片取代本地化标题、替代文本、页面结构、任务反馈或可访问控件。

## Demo 基线

- 当前表站实际可见剧目使用项目生成的无文字压缩资产；里站获选活页剧目在等级 `0` 使用普通版修复封面，等级 `1—3` 按同一会话状态切换对应猩红版或猩红版《摇篮曲》。独立团标按小标哑光、首页大展示金属分工；
- 剧目稳定 ID、来源类别、当前构建范围的国家版本标题、时间层资产记录、来源摘要和权利状态已经与场次关系分离；
- 页面已提供按时间层装帧的剧目视觉和等级 `1—3` 的确定性物件污染作用点；当前资产仍属于候选预览，不因此取得正式发布资格。

## Formal 增量

- 先以一个当前剧目、一个另一时间层对照和一个陌生标题证明创作协议，再建立满足真实需要的最小资料和资产管线；
- 为尚缺实际时间层视觉的运行时剧目制作原创资产；已采用的里站活页修复封面维持明确来源、里站归属和页面消费者边界；
- 让里站污染从物件内部、物件边界、内容框景逐级进入页面环境，同时保留主体、记忆色和可理解观看窗口；
- 允许物件与主内容编排在高污染下成为叙事载体，同时让不可读视觉副本与真实交互、替代文本和保护区保持职责分离；
- 资产通过权利、当前预览国家版本、响应式、可访问性、性能和人工艺术方向门后才能成为正式运行时素材。

## 验收

- 陌生标题只凭文字指导可以形成同一出版制度下的新作，且不复刻 13 项任一构图；
- 同一剧目的原创表站与里站等级 `0` 视觉对照可辨认为同一身份，但不会被理解为先后损坏、升级或修复；里站活页普通版与猩红版不会被误映射为两个时间层；
- 每个可见剧目拥有独立主体、观看路径和记忆色，遮住标题后仍不只靠换色区分；
- `0—3` 的物件影响按“内部 → 边界 → 框景 → 环境”递进，不依赖红色、噪点和位移累加；
- 去掉纹理和装饰后，主体剪影、信息结构和观看路径仍成立；
- 原创图片不含依赖阅读的伪文字、官方徽记、角色、独特边框或权利不清内容；官方活页修复封面必须标识非原创来源，不以图内文字取代本地化 HTML 标题。本地化标题、替代文本、焦点、320px 裁切、减少动态效果和可靠退出不因艺术处理退化。
- 双站页头、页尾、海报独立印记和邀请章默认哑光，首页大展示显式金属；同页大小标可并存且不串用。实际压缩输出在浅色、深色、窄屏及高像素密度下保持透明与完整轮廓，不遮挡文字或按钮；已淘汰的 A、旧 D 环境光衍生稿与原候选 B、C 均不进入正式资产集合。
