# BP-CNT-PRODUCTION-VISUAL｜剧目视觉与猩红印版

## 用户结果

用户可以从每个剧目的原创图像、出版框架和记忆色辨认作品身份，并能把表站与里站等级 `0` 理解为同一剧团谱系下的两种时间层装帧；里站污染沿同一印版逻辑逐级越出物件，而不是退化为通用黑红滤镜、故障符号或随机破坏。

## 边界

- 负责剧目视觉身份、剧团出版制度、表站与里站等级 `0` 的时间层资产、猩红印版、物件污染接口、素材权利边界和艺术验收；
- `Production` 的稳定 ID、来源类别和字段归属由 `BP-FND-DOMAIN` 负责；可见标题、替代文本和国家版本内容由 `BP-CNT-CORE` 与 `BP-I18N-CORE` 负责；
- 污染等级、概率、触发和会话变体由 `BP-FND-NARRATIVE` 负责，页面级作用对象、编排时机和叙事投影由 `BP-MOD-ARCHIVE` 负责；本蓝图只声明物件内部焦点、记忆色、裁切安全区和可跨越接缝；
- 不复制本地参考原图、角色、徽记、标题字形、边框或独特构图，不把标题推演写成游戏官方剧情，不要求全部剧目采用同一种中央画法；
- 不把整页、HTML 文字、交互控件或每个污染等级烘焙成位图，不为当前没有页面消费者的剧目预制运行时资产。

## 剧团出版制度

剧目视觉的统一性来自剧团长期使用的出版制度，而不是统一画风。中央图像可以采用纹章、崇高风景、三联画、童书、博物学图谱、圣像、静物、民俗版画或拼贴；外围副文本使它们仍被理解为同一剧团制作、流通和归档的节目物件。

| 层级           | 稳定职能                                 | 创作约束                                                     |
| -------------- | ---------------------------------------- | ------------------------------------------------------------ |
| 纸面与物件边界 | 证明物料可被制作、流通和保存             | 建立材料与年代，不用褐色滤镜代替设计                         |
| 外框与角部     | 提供剧团归属、舞台口和出版秩序           | 继承密度和功能，不复制既有花纹、角饰或徽记                   |
| 上部题签       | 向观众清楚承诺节目                       | 图像内不依赖可读文字；本地化标题始终由 HTML 叠加             |
| 中央舞台       | 把标题压缩成可观看、可进入或可供奉的事件 | 每张先形成独立隐喻，不把不同标题塞进同一模板                 |
| 底部归属区     | 表达稳定印务、登记和档案制度             | 中轴固定原创归属标记的轮廓与安全区，不复制官方徽记或逐图变形 |
| 印刷表面       | 让异质画法属于同一物质世界               | 深墨轮廓、色块、陈金、颗粒和套色差按尺度分工，不遮盖构图     |
| 字体关系       | 补充剧目体裁                             | 图片标题可以有性格，运行时标题仍以本地化 HTML 保持可读       |

作者侧可以使用“双层委约”理解职责：剧目画师负责中央隐喻、媒介和记忆色；剧团艺术、印务或档案部门负责题签、框景、归属印记、登记和时间层装帧。该模型只指导本站创作，不宣称参考素材真实采用这些岗位或媒介。

## 题义与视觉身份

### 间接指称方法

封面不是剧情摘要。创作前并列阅读全部已知国家版本标题，分别提取字面对象、动作、关系和文化联想，再确定共同主意象与只作次义的分歧；稳定 `productionId` 和最方便读取的语言都不得自动成为视觉主来源。优先描绘题名对象的痕迹、容器、作用空间、仪式、后果或缺席位置，而非对象全貌。每项视觉同时具备：

1. **公开承诺：** 第一眼可理解的体裁、情绪或观看诱因；
2. **隐藏代价：** 同一象征在第二次阅读中产生的服从、封印、迷失、牺牲、捕食、空缺或焚烧；
3. **保留疑问：** 画面不回答谁在主持、谁已离开、道路能否抵达或主体是否真实存在。

不安必须从剧目隐喻内部生长；完成普通宣传画后追加眼睛、血迹、乱码或恐怖字体不属于本系统。

### 十三项活页题义

下列条目绑定 `docs/references/production-title-reference.md` 的稳定 `productionId`。艺术史名称只描述视觉近似，不是官方来源、真实媒介或剧情事实。

#### `ode-au-triomphe`｜凯旋颂

- **身份：** 轴对称仪仗纹章位于深蓝圆盘与放射结构中心，金色纵轴兼具刃、圣物与授予标记；
- **题义：** 凯旋通过战后宣告、授勋和公共见证呈现，隐藏代价是服从权力；
- **机制：** 对颂歌、荣誉、王权和纪念采用“竖立—放射—授予”，避免军队、旗海和胜者肖像；
- **记忆色：** 钴蓝与旧金必须存活，猩红外围与蓝金核心冲突，不把它改成红金庆典。

#### `der-ring`｜湖中至宝

- **身份：** 湖泊被山体和岩隙收成圣物匣，无来源的水下金光、回环水纹和无法抵达湖心的路径共同暗示秘藏，不直接陈列珠宝指环；
- **题义：** 湖本身同时是宝物、封印、入口和召唤关系，危险来自尺度失衡、循环观看和被框住的路径；
- **机制：** 对秘宝、禁物或“某地之物”采用“引入—抬升—封存”，让地形、倒影和路径服务目标；
- **记忆色：** 湖青与冷水深度保留，焦红只进入框景和水面边缘。

#### `one-hundred-and-one-days`｜一百零一日

- **身份：** 多联尖拱承载不同时相和塔楼剪影，一处暖色断裂截断纵轴；
- **题义：** 数量成为时间容器的累积，第 101 日是抵达、灾变或揭示；
- **机制：** 对期限、日期、轮次和季节采用“分段—积累—断裂”，以重复构件表现过程，以单一异常表现临界点；
- **记忆色：** 暮橙和断裂已经承担紧张，污染主要来自外围黑版与接缝，不继续堆高红色饱和度。

#### `lone-wander`｜独行客

- **身份：** 磨损面罩、行囊、带状物和工具组成近似人像的物件团块；
- **题义：** 人被携带物替代，韧性、匿名、滑稽和旅途耗损同时成立；
- **机制：** 对职业、无名角色和身份采用“堆积—拟人—负重”，用少量磨损物件组成生活方式剪影；
- **记忆色：** 低彩度金属依赖硬轮廓，猩红强化炭黑、锈红和物件边缘，不以降饱和为主。

#### `wonderland-in-dream`｜梦中奇缘

- **身份：** 背向观者的同行者、盘旋道路和远方建筑形成邀请，空间关系存在一处明确悖论；
- **题义：** 同行与目的地诱人，道路却不断延宕并暗示不可返回；
- **机制：** 对梦境、冒险、乐园和同行采用“邀请—行进—延宕”，只植入一条空间悖论；
- **记忆色：** 浅色路径是观看轴，裂口应顺应或阻断它，不随机横穿主体。

#### `frost-deer-and-snow-doe`｜霜牡与雪牝

- **身份：** 两个鹿角拟人形体反向交叠，角枝、肢体、花与雪晶组成共享剪影，并保留一项非对称差异；
- **题义：** 亲密、难以分辨、标本化保存和牺牲并存；
- **机制：** 对双生、盟誓、爱侣和对立采用“缠绕—镜映—冻结”，不并排两张独立头像；
- **记忆色：** 冰蓝、银白与少量冷青作为寒冷残片存活，烟红只改变关系压力。

#### `light-of-heria`｜赫里亚之辉

- **身份：** 无面正面形象位于严格中轴的圣龛，力量依附纵向器物、冠环和放射结构；
- **题义：** 光被无名权威持有和分配，身份缺席使崇高转为不可验证的服从；
- **机制：** 对启示、戒律、圣名和光辉采用“显现—端坐—服从”，省略一项身份信息；
- **记忆色：** 完整秩序本身已经不可信，猩红只强化献祭性，不毁掉圣像。

#### `sette-collis-mother-wolf`｜七丘的狼母

- **身份：** 深色狼形剪影占据月盘与领地地平线，庇护和捕食共享同一图腾；
- **题义：** 母性不被甜化，祖源、领地、保护和危险并存；
- **机制：** 对神话动物、祖先和城邦象征采用“庇护—仰望—占据”，不靠幼崽或说明场景解释亲缘；
- **记忆色：** 夜蓝、月金和黑狼的主从关系保留，猩红改变守护的解释而不替换象征。

#### `the-dawn`｜初晓

- **身份：** 近黑前景、远山与层云逐级变亮，不出现太阳，只由云隙和地平线显露冷白与晨粉；
- **题义：** 黎明是长夜末端的明度与色温变化，克制希望需要凝视；
- **机制：** 对时刻、气候、觉醒和消逝采用“压暗—远望—显露”，以明度路径替代太阳、时钟或眼睛；
- **记忆色：** 红灰可以让黎明接近暮色，但远处亮点必须留下。

#### `the-golden-fowlbeast`｜金羽兽

- **身份：** 枝叶、巢或花冠环抱金色卵形圣物，生物本体缺席；
- **题义：** 宝贵生命以遗留物、孕育结构或目击痕迹存在，观者无法判断它是否已离开；
- **机制：** 对传奇生物和不可见角色采用“环抱—孕育—留空”，不直画全貌；
- **记忆色：** 植物青绿与卵金保持辨识，猩红只改变巢的庇护含义。

#### `wild-gold`｜狂野之金

- **身份：** 货币、器械、容器、肉质错觉和日常物件形成不断增殖、吞并和倾倒的拼贴团块；
- **题义：** 价值系统获得欲望和消化能力，一件普通物件把荒诞固定在现实消费关系中；
- **机制：** 对资本、制度、欲望和社会讽刺采用“增殖—吞并—倾倒”，不画成单一金库或财富人物；
- **记忆色：** 锈红可以产生肉质错觉但不使用写实血腥，污染改变材料关系而非继续降饱和。

#### `the-lullaby`｜摇篮曲

- **身份：** 歌者、儿童和摇篮缺席，灯下空间与声音、气流或记忆般的曲线共同存在；
- **题义：** 安抚与“本应有人”的空缺同时成立；
- **机制：** 对歌曲、耳语、梦话和回声采用“照亮—飘移—缺席”，描绘作用空间和残留轨迹，不使用乐符说明声音；
- **记忆色：** 夜蓝、灯火暖色和空白空间保留，猩红只侵入声音残迹或边缘。

#### `the-carnival`｜欢欣鼓舞

- **身份：** 无人场地中的火源、旗帜、帐幕或重复轮廓形成集体节奏，所有动势围绕同一仪式焦点上升；
- **题义：** 欢乐先以聚集和共同观看邀请观者，第二眼显露失控、焚烧或献祭；
- **机制：** 对节庆、群众事件和集体情绪采用“聚集—上升—燃烧”，不使用拥挤人群概述狂欢；
- **记忆色：** 节庆暖色与夜场深色共同保留，猩红印版不能消灭火源层次。

### 可迁移修辞

| 修辞         | 适用题义                     | 构图关系                   | 需要避免                         |
| ------------ | ---------------------------- | -------------------------- | -------------------------------- |
| 仪式压缩     | 荣誉、权力、戒律、启示       | 竖立、放射、授予或服从     | 直画军队、统治者或现成宗教符号   |
| 不可触及目标 | 秘宝、禁物、目的地           | 引入、抬升、封存或延宕     | 手持物陈列和说明性藏宝图         |
| 临界过程     | 日期、期限、季节、觉醒       | 分段、积累、断裂或显露     | 大量同质计数和直白时钟           |
| 物件代身     | 职业、身份、缺席人物         | 堆积、拟人、负重或留空     | 通用角色肖像                     |
| 关系剪影     | 双生、盟誓、祖源、庇护       | 缠绕、镜映、冻结或占据     | 并排头像和说明性亲缘场景         |
| 作用空间     | 声音、梦境、气候、记忆       | 照亮、飘移、远望或延宕     | 乐符、眼睛和粒子替代空间逻辑     |
| 系统增殖     | 欲望、制度、消费、群众性事件 | 增殖、吞并、聚集、上升燃烧 | 无因果拼贴、通用血腥和装饰性混乱 |

该表用于选择观看关系，不是七套固定模板。新标题先确定它如何作用于观者，再选择画法、媒介和颜色。

## 时间层资产与猩红印版

### 时间层轴

- 表站资产使用完整矩形、清楚套色、剧目专属色和当代编辑裁切；不安来自题义的第二读法，不存在运行时污染；
- 里站等级 `0` 使用独立的闭合猩红装帧：煤黑边、半透明猩红烟版、旧金内线、重复裂口和不规则外缘均有意对齐，属于 1091 剧团正式物料；
- 外围出版框架默认维持可辨认的中轴和左右对称，题义需要的缺席、断裂或空间悖论在中央图像中有意破坏秩序；不把生成误差或无意义不对称解释成戏剧性；
- 两种资产共享剧目身份，但不被描述为升级、修复、损坏、替代或先后迭代。同一剧目实际进入两个时间层时才制作成对运行时资产；尚未采用的时间层不预制无消费者副本。

### 猩红印版结构

“印版”是本站组织视觉的艺术层，不声称真实印刷工艺。

| 层次             | 可见结构                                         | 叙事职能                               | 制作约束                                 |
| ---------------- | ------------------------------------------------ | -------------------------------------- | ---------------------------------------- |
| 剧目身份底版     | 中央主体、观看路径、题签区、剧目主色和记忆色     | 回答“这是什么剧目”                     | 不能被统一黑红处理抹平                   |
| 边缘煤黑版       | 角部、两侧和下缘不均匀压暗，中心保留观看窗口     | 把活页变为被收存或押入舞台口的物件     | 不使用四边等量暗角或整个容器滤镜         |
| 半透明猩红烟版   | 氧化红、焦红和灰粉红的大尺度薄烟、擦印和局部色雾 | 宣示旧剧团装帧权力并允许下层记忆色存活 | 不使用单一纯红蒙版                       |
| 重复裂口版       | 题签下缘、中部上扬、侧边和底缘的浅芯红黑裂口     | 让共用印版跨过既有出版边界             | 不是发光线、删除线、涂鸦或相同的 X       |
| 不规则物件轮廓版 | 略扩大的焦黑外缘、红边和透明缺口                 | 让活页具有厚度并能与页面环境衔接       | 不裁掉焦点、标题、替代文本主体或交互区域 |

大尺度烟幕、中尺度裂口和小尺度纸纤维不能在同一位置同时高强度出现；层次来自尺度分工，不来自纹理数量。

### 污染接口

每个可被污染的剧目或人物视觉至少声明：

- 不得遮挡的标题、面部或主体焦点；
- 必须保留的剧目记忆色；
- 可被压暗的边角和空场；
- 适合错版的颜色层；
- 裂口应顺应或逆转的观看路径；
- 等级 `2` 可以跨越的内外框接缝；
- 等级 `3` 可以与页面环境衔接的边界方向；
- 320px 裁切和减少动态效果下的稳定结果。

通用组件依据显式资料选择确定性视觉档案，不通过 DOM 顺序或每次渲染随机猜测。页面级对象、等级、稳定会话变体和应用时机不由本蓝图或图片元数据拥有。

## 混合资产与网页转译

- 剧目主体、复杂背景、人物和场景使用原创无文字位图；等级 `1—3` 使用少量透明污染层、印版遮罩和轻量 CSS，不为每级生成完整页面大图；
- 导航、Logo、按钮、正文、标题、状态、焦点和响应式布局继续使用语义化 HTML/CSS 或项目自有简单矢量；图片不承载唯一信息；
- 正式资产进入 `src/assets/`，声明明确宽高、焦点和裁切，使用响应式尺寸与现代压缩格式，非首屏懒加载；
- 生成输入只使用本蓝图和作者指南的文字要求，不使用参考原图作图生图输入。生成后检查构图近似、伪文字、官方标识、角色、独特边框和权利风险；
- 页面环境只抽取出版制度的空间逻辑，不把高密度封面纹理平铺到正文后：表站用清洁纸面、现代舞台暗面、精准裁切和开放留白，里站用深廊外围、旧纸阅读岛与闭合框景；
- 方形品牌标使用“菱形外界、圆形舞台口、双帷幕负形和下降光束”的原创轮廓，固定在封面下方中轴归属区，并由同一个矢量源叠加，避免逐图生成造成漂移；里站可以改变套色、纸面和印章材质，但不复制参考徽记，也不把同一标记任意换成另一图案；
- 人物相框只有在已有人员内容需要视觉承载时使用，不为展示样式而新增人物实体或肖像；人物身份与链接保持在框外 HTML。

## 非目标

- 让全部剧目使用同一中央构图、配色或边框；
- 只按英文或任一单独国家版本标题直画中心名词，把其他标题提供的关系与意象丢弃；
- 把普通与猩红资产解释为损坏、升级、修复或后期污染；
- 为 13 项参考标题自动建立运行时实体、详情或素材；
- 用统一红色、噪点、暗角、故障、眼睛、血迹、乱码或恐怖字体制造“猩红”；
- 让生成图片取代本地化标题、替代文本、页面结构、任务反馈或可访问控件。

## Demo 基线

- 当前表里站已有可部署剧目列表与详情，并使用通用几何视觉保持内容可辨；
- 剧目稳定 ID、来源类别和三国家版本标题已经与场次关系分离；
- 当前尚未完成剧目专属原创资产、时间层装帧资料和物件污染接口。

## Formal 增量

- 先以一个当前剧目、一个另一时间层对照和一个陌生标题证明创作协议，再建立满足真实需要的最小资料和资产管线；
- 为当前运行时实际可见的剧目制作其实际时间层原创资产，并让现有页面模式使用同一出版制度；
- 让里站污染从物件内部、物件边界、内容框景逐级进入页面环境，同时保留主体、记忆色和可理解观看窗口；
- 资产通过权利、三语言、响应式、可访问性、性能和人工艺术方向门后才能成为正式运行时素材。

## 验收

- 陌生标题只凭文字指导可以形成同一出版制度下的新作，且不复刻 13 项任一构图；
- 同一剧目的表站与里站等级 `0` 对照可辨认为同一身份，但不会被理解为先后损坏、升级或修复；
- 当前每个可见剧目拥有独立主体、观看路径和记忆色，遮住标题后仍不只靠换色区分；
- `0—3` 的物件影响按“内部 → 边界 → 框景 → 环境”递进，不依赖红色、噪点和位移累加；
- 去掉纹理和装饰后，主体剪影、信息结构和观看路径仍成立；
- 图片不含依赖阅读的伪文字、官方徽记、角色、独特边框或权利不清内容；三语 HTML 标题、替代文本、焦点、320px 裁切、减少动态效果和可靠退出不因艺术处理退化。
