# BP-CNT-PRODUCTION-VISUAL-CATALOG｜剧目视觉身份档案

## 用户结果

人工或智能体可以按稳定 `productionId` 定位已经采纳的题义、构图机制与记忆色，并在不重读原始参考图的情况下为对应剧目制作符合剧团出版制度的原创视觉。

## 边界

- 本蓝图只保存按 `productionId` 增长的视觉身份档案；剧团出版制度、时间层装帧、猩红印版、污染接口、素材权利和运行时验收由 `BP-CNT-PRODUCTION-VISUAL` 负责；
- 标题形式与来源映射以 `docs/sources/official-folio-productions.md` 为准，实际创作步骤以 `docs/guides/production-art-authoring.md` 为准；
- 艺术史名称只描述视觉近似，不是官方来源、真实媒介或剧情事实；档案不自动生成运行时实体、页面或资产；
- 新增剧目时成组增加一项身份、题义、构图机制与记忆色，不为每项剧目建立独立蓝图。

## 活页剧目视觉档案

### `ode-au-triomphe`｜凯旋颂

- **身份：** 轴对称仪仗纹章位于深蓝圆盘与放射结构中心，金色纵轴兼具刃、圣物与授予标记；
- **题义：** 凯旋通过战后宣告、授勋和公共见证呈现，隐藏代价是服从权力；
- **机制：** 对颂歌、荣誉、王权和纪念采用“竖立—放射—授予”，避免军队、旗海和胜者肖像；
- **记忆色：** 钴蓝与旧金必须存活，猩红外围与蓝金核心冲突，不把它改成红金庆典。

### `der-ring`｜湖中至宝

- **身份：** 湖泊被山体和岩隙收成圣物匣，无来源的水下金光、回环水纹和无法抵达湖心的路径共同暗示秘藏，不直接陈列珠宝指环；
- **题义：** 湖本身同时是宝物、封印、入口和召唤关系，危险来自尺度失衡、循环观看和被框住的路径；
- **机制：** 对秘宝、禁物或“某地之物”采用“引入—抬升—封存”，让地形、倒影和路径服务目标；
- **记忆色：** 湖青与冷水深度保留，焦红只进入框景和水面边缘。

### `one-hundred-and-one-days`｜一百零一日

- **身份：** 多联尖拱承载不同时相和塔楼剪影，一处暖色断裂截断纵轴；
- **题义：** 数量成为时间容器的累积，第 101 日是抵达、灾变或揭示；
- **机制：** 对期限、日期、轮次和季节采用“分段—积累—断裂”，以重复构件表现过程，以单一异常表现临界点；
- **记忆色：** 暮橙和断裂已经承担紧张，污染主要来自外围黑版与接缝，不继续堆高红色饱和度。

### `lone-wander`｜独行客

- **身份：** 磨损面罩、行囊、带状物和工具组成近似人像的物件团块；
- **题义：** 人被携带物替代，韧性、匿名、滑稽和旅途耗损同时成立；
- **机制：** 对职业、无名角色和身份采用“堆积—拟人—负重”，用少量磨损物件组成生活方式剪影；
- **记忆色：** 低彩度金属依赖硬轮廓，猩红强化炭黑、锈红和物件边缘，不以降饱和为主。

### `wonderland-in-dream`｜梦中奇缘

- **身份：** 背向观者的同行者、盘旋道路和远方建筑形成邀请，空间关系存在一处明确悖论；
- **题义：** 同行与目的地诱人，道路却不断延宕并暗示不可返回；
- **机制：** 对梦境、冒险、乐园和同行采用“邀请—行进—延宕”，只植入一条空间悖论；
- **记忆色：** 浅色路径是观看轴，裂口应顺应或阻断它，不随机横穿主体。

### `frost-deer-and-snow-doe`｜霜牡与雪牝

- **身份：** 两个鹿角拟人形体反向交叠，角枝、肢体、花与雪晶组成共享剪影，并保留一项非对称差异；
- **题义：** 亲密、难以分辨、标本化保存和牺牲并存；
- **机制：** 对双生、盟誓、爱侣和对立采用“缠绕—镜映—冻结”，不并排两张独立头像；
- **记忆色：** 冰蓝、银白与少量冷青作为寒冷残片存活，烟红只改变关系压力。

### `light-of-heria`｜赫里亚之辉

- **身份：** 无面正面形象位于严格中轴的圣龛，力量依附纵向器物、冠环和放射结构；
- **题义：** 光被无名权威持有和分配，身份缺席使崇高转为不可验证的服从；
- **机制：** 对启示、戒律、圣名和光辉采用“显现—端坐—服从”，省略一项身份信息；
- **记忆色：** 完整秩序本身已经不可信，猩红只强化献祭性，不毁掉圣像。

### `sette-collis-mother-wolf`｜七丘的狼母

- **身份：** 深色狼形剪影占据月盘与领地地平线，庇护和捕食共享同一图腾；
- **题义：** 母性不被甜化，祖源、领地、保护和危险并存；
- **机制：** 对神话动物、祖先和城邦象征采用“庇护—仰望—占据”，不靠幼崽或说明场景解释亲缘；
- **记忆色：** 夜蓝、月金和黑狼的主从关系保留，猩红改变守护的解释而不替换象征。

### `the-dawn`｜初晓

- **身份：** 近黑前景、远山与层云逐级变亮，不出现太阳，只由云隙和地平线显露冷白与晨粉；
- **题义：** 黎明是长夜末端的明度与色温变化，克制希望需要凝视；
- **机制：** 对时刻、气候、觉醒和消逝采用“压暗—远望—显露”，以明度路径替代太阳、时钟或眼睛；
- **记忆色：** 红灰可以让黎明接近暮色，但远处亮点必须留下。

### `the-golden-fowlbeast`｜金羽兽

- **身份：** 枝叶、巢或花冠环抱金色卵形圣物，生物本体缺席；
- **题义：** 宝贵生命以遗留物、孕育结构或目击痕迹存在，观者无法判断它是否已离开；
- **机制：** 对传奇生物和不可见角色采用“环抱—孕育—留空”，不直画全貌；
- **记忆色：** 植物青绿与卵金保持辨识，猩红只改变巢的庇护含义。

### `wild-gold`｜狂野之金

- **身份：** 货币、器械、容器、肉质错觉和日常物件形成不断增殖、吞并和倾倒的拼贴团块；
- **题义：** 价值系统获得欲望和消化能力，一件普通物件把荒诞固定在现实消费关系中；
- **机制：** 对资本、制度、欲望和社会讽刺采用“增殖—吞并—倾倒”，不画成单一金库或财富人物；
- **记忆色：** 锈红可以产生肉质错觉但不使用写实血腥，污染改变材料关系而非继续降饱和。

### `the-lullaby`｜摇篮曲

- **身份：** 歌者、儿童和摇篮缺席，灯下空间与声音、气流或记忆般的曲线共同存在；
- **题义：** 安抚与“本应有人”的空缺同时成立；
- **机制：** 对歌曲、耳语、梦话和回声采用“照亮—飘移—缺席”，描绘作用空间和残留轨迹，不使用乐符说明声音；
- **记忆色：** 夜蓝、灯火暖色和空白空间保留，猩红只侵入声音残迹或边缘。

### `the-carnival`｜欢欣鼓舞

- **身份：** 无人场地中的火源、旗帜、帐幕或重复轮廓形成集体节奏，所有动势围绕同一仪式焦点上升；
- **题义：** 欢乐先以聚集和共同观看邀请观者，第二眼显露失控、焚烧或献祭；
- **机制：** 对节庆、群众事件和集体情绪采用“聚集—上升—燃烧”，不使用拥挤人群概述狂欢；
- **记忆色：** 节庆暖色与夜场深色共同保留，猩红印版不能消灭火源层次。

## 维护与验收

- 新增或修订档案时按 `productionId` 核对身份、题义、机制和记忆色四类字段；标题变化不自动改写稳定 ID；
- 同一档案可以指导不同时间层资产，但不得把普通与猩红装帧解释为升级、损坏或替代；
- 档案只提供剧目身份，不能取代创作指南要求的原创构思，也不能成为复制既有构图的模板；
- 运行时只消费实际被内容集合选中且完成资产登记的剧目，不因档案存在而生成空页面。
