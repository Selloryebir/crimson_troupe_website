# BP-MOD-SEARCH｜站内搜索

> 本文件是完整模组蓝图示例：一份蓝图同时指导组件、数据和客户端行为，而不是按源文件类型拆分。

## 用户结果

用户可以快速定位剧目、页面和档案线索，并使用键盘完成搜索和结果选择。

## 边界

- 负责搜索入口、查询、结果呈现、键盘浏览和结果路由；
- 消费已审核的搜索索引，不复制剧目正文；
- 可以提供进入旧档案的线索，但不拥有世界切换状态；
- 不执行远端请求，不记录查询或用户身份。

## 行为契约

- 输入为用户当前查询和类型化搜索条目；
- 空查询、无结果、普通结果和档案结果都有文本反馈；
- 剧目结果交给剧目详情能力，页面结果导航到明确位置，档案结果请求叙事状态切换；
- JavaScript 不可用时，页面的常规导航和节目内容仍然可读。

## 双时间层、内容与本地化

- 表站结果保持专业、清晰和可预期；
- 异常结果可以制造时间矛盾，但必须保留可理解的标签和返回能力；
- 搜索条目从稳定内容生成，专有名词、别名和归一化规则由本地化契约约束。

## Demo 基线

- `/` 打开搜索，输入内容后显示匹配结果；
- 键盘可以移动、选择并关闭结果；
- 搜索能够连接剧目详情、页面锚点和旧档案入口。

## Formal 增量

- 接入 locale 感知的分词、别名和专有名词矩阵；
- 内容规模证明需要后，再考虑构建期索引分片或独立搜索页面。

## 验收

- 搜索结果与其来源内容使用同一稳定 ID；
- 空状态、无结果和错误不会表现成界面失效；
- 档案结果不能绕过叙事状态的可靠退出规则。
