# BP-MOD-SEARCH｜分域站内搜索

## 用户结果

用户可以在当前国家版本、当前世界和当前快照内定位场次、剧目和页面，并使用独立搜索 URL 与键盘完成查询和结果选择。

## 边界

- 负责搜索入口、查询、构建期索引、结果呈现、键盘浏览和结果路由；
- 消费当前构建快照允许公开的内容、稳定领域 ID 与本地化术语，不复制正文；
- 里站搜索提交可以请求一次污染判定，结果呈现可以被污染，但搜索不拥有污染状态；
- 不执行远端请求，不记录查询或用户身份，也不把范围隔离描述为访问控制或保密机制。

## 范围与索引契约

```text
{editionId}:front                    -> /{routePrefix}/search/
{editionId}:archive:{snapshotId}     -> /{routePrefix}/archive/site/1084-07-01/search/
```

- 每个范围在构建期生成独立索引和结果路由，不先加载全站索引再在浏览器中过滤；
- 表站搜索不能返回里站或其他国家版本内容；里站搜索不能返回表站、其他年份或其他国家版本内容；
- 范围隔离是内部索引契约，不是访客侧叙事。表站只以“本站”或当前剧团网站口吻说明搜索对象；里站等级 `0` 只以同期名录口吻说明搜索对象。访客侧不得出现“表站”“里站”“不包含历史快照”或主动揭示另一时间层的排除说明；
- 可见范围提示没有独立信息价值时统一简化为当前国家版本的“搜索范围：本站内容”等价文案；页面标题、元描述、索引摘要、脚本消息和无 JavaScript 反馈遵守相同语义；
- 索引条目使用稳定实体 ID、当前构建策略允许的标题、摘要、类型、别名和目标 URL；`approved-only` 只接受摘要匹配的批准内容，预览构建可以索引其明确选择的完整预览变体；
- 每个索引只从当前国家版本已经解析完成的页面、地点、场次、剧目和术语内容生成；客户端只接收当前索引及当前 locale，不维护中文默认文案或加载其他版本后再过滤；
- 搜索索引与结果路由只从统一不可变构建快照派生，不直接遍历全局内容注册表；集合外内容不生成可搜索的隐藏详情；
- 切换国家版本或表里站时不沿用搜索词；搜索结果链接保持当前范围并导航至合法详情或页面 URL；
- 空查询、无结果、索引不可用和普通结果均提供直接、非角色表演式的文本反馈；
- 搜索页默认只显示一处可理解的不可用反馈；脚本完整解析当前索引和消息、成功绑定事件后，才原子启用表单并隐藏该反馈。无 JavaScript 或初始化中途失败时不得同时留下重复警告和可提交但无结果的假控件；
- 查询和索引使用同一 `NFKC` 与当前 locale 小写归一化。日文、希腊文和俄文不引入分词库；本阶段验证希腊文大小写与词尾 sigma、俄文大小写，不自动去除希腊文重音，不合并俄文 `ё / е`，也不承诺词干或形态学搜索；
- JavaScript 不可用时，独立搜索页仍提供范围说明、常规导航和上述唯一不可用反馈，其他页面内容不受影响。

## 污染协作

- 提交一次里站搜索只增加一次有效污染事件；如果提交同时导航，不再由通用页面导航重复计数；前两次保护与概率由叙事状态统一处理；
- 里站搜索结果的排版、措辞变体或视觉痕迹可以依据当前污染等级变化；
- 污染不得改变索引范围、实体 ID、内容归属、目标 URL、键盘顺序或返回能力。
- 克莱布拉松不进入等级 `0` 索引、关键词或稳定摘要；等级 `3` 可以用已经本地化的可见投影重释结果关系，但匹配仍基于原索引，结果数量、实体和链接保持不变。
- 等级 `3` 的结果标题、摘要和地点可收束为同一邀请回应，但查询文本和结果计数仍属于原搜索。只在访客点击受污染结果时调用 `BP-MOD-ARCHIVE` 的邀请回应；关闭后恢复原结果焦点，继续后导航至该结果原合法 URL。

## Demo 基线

- 表站与当前可访问快照分别拥有构建期索引和独立搜索页，结果不会跨世界或国家版本；
- 查询、空状态、无结果、键盘路径和无 JavaScript 不可用反馈均可理解；
- 里站每次搜索提交只向叙事状态请求一次污染判定。

## Formal 增量

- 为当前发布的炎国表站与日期快照分别生成构建期索引和独立搜索页；
- 接入 locale 感知的归一化、已批准标准形式与别名；
- 让索引、输入提示、空状态、错误与结果类型全部由当前国家版本内容提供，不把炎国文案作为客户端兜底；
- 以同一同期口吻修正五个预览国家版本的搜索介绍、范围提示、元数据、消息和索引摘要，不把内部范围键暴露为访客文案；
- 让索引和结果路由消费统一构建快照，移除与根集合平行的硬编码对象矩阵；
- 只有内容规模证明需要时，才考虑索引分片或更复杂的客户端查询能力。

## 验收

- 表站查询无法得到里站结果，里站查询无法得到表站或其他快照结果；
- 搜索结果与来源内容使用同一稳定 ID，链接可直接访问且保持当前范围；
- 空状态、错误和无 JavaScript 状态不会表现为界面失效；
- JavaScript 初始化失败时只有一处明确不可用反馈，不保留伪可用搜索表单；
- 里站一次提交至多触发一次污染判定，任意污染等级都不改变索引事实。
