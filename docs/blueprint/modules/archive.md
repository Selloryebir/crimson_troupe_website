# BP-MOD-ARCHIVE｜旧剧团档案

## 用户结果

用户能够发现、浏览并回应旧剧团档案，同时始终知道如何返回当前时间。

## 边界

- 负责恢复记录、异常演员表、邀请反馈和档案内部语气；
- 通过叙事状态请求进入或退出，不自行拥有全局世界状态；
- 可以制造不安，不使用真实欺骗、恶意下载、强制全屏或不可退出流程。

## 行为契约

- 档案记录使用稳定 ID 和类型化内容；
- 展开记录、接受或拒绝邀请均提供文本及键盘反馈；
- 新档案必须提供语义化触发器，并说明它对现有叙事阶段的影响；
- 动效关闭或脚本失败时，返回路径仍然存在。

## Demo 基线

- 用户可以通过馆藏编号、快捷键或异常搜索结果进入；
- 记录可以展开，邀请可以接受或拒绝；
- 退出操作始终返回表站。

## Formal 增量

- 当渐变污染阶段建立后，档案根据被授予的阶段表现异常，不直接污染其他模组；
- 扩充内容前建立档案来源、原创状态和多语言字段。

## 验收

- 所有进入方式共享同一世界切换契约；
- 所有叙事分支都保留可靠退出；
- 里站不只是表站的暗色换肤。
