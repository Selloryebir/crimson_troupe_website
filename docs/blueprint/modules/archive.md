# BP-MOD-ARCHIVE｜1091 旧剧团网站

## 用户结果

用户能够直接进入或从表站发现一个内容完整、年代可信的 1091 旧剧团网站，并在其上经历受控污染，始终保有正常浏览和返回表站的能力。

## 边界

- 负责里站等级 `0` 的页面内容与任务、里站导航语气、污染判定触发及各等级的受控呈现；
- 通过叙事状态接口读取污染等级、请求一次判定或返回表站，不自行复制全局状态机；
- 搜索索引隔离由搜索蓝图负责，领域实体由领域语言蓝图负责；
- 可以制造不安，不使用真实欺骗、恶意下载、强制全屏、伪系统警告、闪烁滥用或不可退出流程。

- 里站表现泰拉历 1091 年当时实际存在的旧剧团官网；年份是内容、编排、用词、视觉和媒介质感的依据；
- 最小页面集合包括首页、本季演出、历史演出、剧团、搜索及独立票务页。任务名称与表站一致，内容、布局、导航语言和浏览节奏不要求逐页对应；
- “本季演出”由固定 `1091-07-01 00:00` 快照时钟与有效排期派生；这些场次在表站“现在”的视角下均已发生。里站时钟不随现实时间、刷新或污染变化；
- 里站所有场次当前均不可购买，不进入 `TicketBasket`、票务流程或成功结算。票务页只显示符合历史快照语境的不可用反馈和有效返回路径；
- 等级 `0` 已通过泰拉化的配色、排版、信息组织、媒介质感和用词体现更早年代，不直接套用现实早期网页、维多利亚印刷品、VHS 故障或特定现实技术规格；
- 等级 `0` 以正面轴线、中心舞台、拱门、长廊、肖像或登记卡式框景、较窄正文列、登记簿列表、旧纸与深色环境建立完整的仪式档案剧场；首页以邀请与剧团权威进入告示和本季登记，演出内容以登记簿或旧节目单组织，搜索和不可购票页保持同一旧站事务语言；

- 污染不能替代等级 `0` 的内容建设；脚本失败时等级 `0` 的核心内容和返回入口仍然成立。

## 污染触发契约

以下用户行为各向叙事状态请求一次污染判定：

1. 从表站点击进入里站；
2. 通过地址栏、书签或外部链接直接进入里站；
3. 在里站内点击进入另一个里站页面；
4. 在里站内切换国家版本或语言；
5. 提交一次里站搜索。

每个用户动作最多增加一次有效事件。进入里站是第 `1` 次事件，第一次内部导航、国家版本切换或搜索提交是第 `2` 次，两者都强制保持等级 `0`；从第 `3` 次事件开始才执行固定 `42%` 判定。搜索提交若发生页面导航，由搜索事件拥有该事件，不再由通用导航重复计算；随后点击结果属于下一次导航事件。刷新、浏览器前进或后退、锚点跳转、披露、下载、复制、输入搜索字符、查询参数的非提交变化及页面自身重渲染不增加事件，也不清除等级、事件数或稳定变体。

## 污染呈现契约

| 等级 | 叙事状态 | 表现边界                                                                                         |
| ---- | -------- | ------------------------------------------------------------------------------------------------ |
| `0`  | 原始快照 | 年代网站本身完整成立，不出现异常                                                                 |
| `1`  | 轻度污染 | 印版错位、重复编号、局部登记痕迹和一处跨材料对应，不破坏任务顺序与正文可读性                     |
| `2`  | 中度污染 | 档案窗受控叠放、图像或相框空间失序、关系矛盾和物件越出内框，页面归属仍明确                       |
| `3`  | 重度污染 | 猩红印版接管页面环境，记录、尺度、方向与空间关系近乎崩坏，各页面按职责收束到克莱布拉松与同一请柬 |

- 除表里切换入口、里站返回入口和页脚同人声明外，其他可见元素可以成为经过编排的污染对象；
- 污染只作用于呈现层和经过编排的叙事变体，不永久改写源内容、翻译完整度、索引归属或路由；
- 等级 `1—3` 的投影只读取同一个等级 `0` 构建快照与当前标签页状态；会话结束或主动返回表站后无需修复底层内容即可恢复完整等级 `0`；
- 真实日期、地点、编号和场馆只由等级 `0` 稳定内容拥有；等级 `2—3` 通过独立、本地化、可逆的展示投影改变访客所见，不形成平行事实源；
- 等级 `0—2` 的稳定场次、可见演出信息、搜索摘要、关键词和 URL 不得泄露克莱布拉松。等级 `3` 才显示克莱布拉松林地城堡、同一演出和请柬信息，且不把它们写回普通场次或等级 `0` 索引；
- 等级 `3` 不机械替换全站同一句话：首页表现筛选，列表收束登记关系，演出与剧目详情重释角色和观看条件，剧团页重释职务，搜索只改变可见摘要，不可购票页重释已登记席位；所有链接仍指向原有合法实体和 URL；
- 等级 `3` 的投影视觉可以接管页面环境，但不能改变页面 H1 的任务主次、主动偷取焦点或把整段请柬作为 live region 朗读；状态变化只通过一条简短、本地化的辅助公告表达；
- 污染编排依据页面类型、等级与稳定会话变体选择确定性的作用对象、侵入方向和应用时机。剧目物件内部的焦点、记忆色、裁切安全区与可跨越接缝由 `BP-CNT-PRODUCTION-VISUAL` 拥有；页面层不得以 DOM 顺序或运行时随机猜测保护范围；
- “受控”约束状态、因果、可逆性和真实交互安全，不限制等级 `3` 的视觉强度。等级 `3` 可以通过递归页面、方向冲突、跨平面请柬、镜像或旋转的视觉副本、非常规遮蔽和尺度错认制造认知崩坏；真实交互层保持直立、可聚焦、可点击且不被视觉副本接管；
- 污染可以在站内叙事中诱导访客选择不合常理的观看或登记路径，但不得诱导站外危险行为、下载、付款、提交真实身份或放弃退出能力；
- 删除线、通用红叉、全屏红线、现实错误弹窗、无来源恐吓句、全局降饱和和真实文字容器位移不属于有效污染语言；不以另一句血字警告替换旧占位表现；
- 等级 `1—3` 以“物件内部 → 物件边界 → 内容框景 → 页面环境”逐步扩大同一印版和编排因果，每一级都能辨认出升级关系，不通过统一噪点、无约束随机 CSS 或多个无关故障的机械叠加代替设计；
- 污染不得改变 DOM 语义、焦点与键盘顺序、减少动态效果、替代文本、可理解的异常占位、视口安全和无 JavaScript 降级。
