## 污染触发契约

以下用户行为各向叙事状态请求一次污染判定：

1. 从表站点击进入里站；
2. 通过地址栏、书签或外部链接直接进入里站；
3. 在里站内点击进入另一个里站页面；
4. 在里站内切换国家版本或语言；
5. 提交一次里站搜索。

每个用户动作最多增加一次有效事件。进入里站是第 `1` 次事件，第一次内部导航、国家版本切换或搜索提交是第 `2` 次，两者都强制保持等级 `0`；从第 `3` 次事件开始才执行固定 `42%` 判定。搜索提交若发生页面导航，由搜索事件拥有该事件，不再由通用导航重复计算；随后点击结果属于下一次导航事件。刷新、浏览器前进或后退、锚点跳转、披露、下载、复制、输入搜索字符、查询参数的非提交变化及页面自身重渲染不增加事件，也不清除等级、事件数或稳定变体。

- 1093与1096损坏记录只提供可理解状态，不能获得焦点或生成路由；旧年份路径到规范日期路径的重定向不形成第二套正文或错误 canonical；
- 等级 `0` 在没有污染时已经具有独立年代感和可完成的核心任务；
- 等级 `0` 的可售事实、分区和价格属于 1084 同期内容，而最终结算固定失联；该页面不建立表站票篮、概率流程或下载结果；
- 全部触发遵守“一次动作至多一次判定”，全部等级保留语义、键盘、视口和退出底线；
- 进入与第一次内部有效动作始终保持等级 `0`，刷新不清零、不追加事件或重新获得保护；
- 等级 `1—3` 使用同一出版和编排逻辑递进，等级 `3` 在不改稳定实体、URL 或搜索归属的前提下按页面职责收束到请柬主轴；
- 等级 `1` 的异常无需截图对照即可辨认，等级 `2` 形成跨区块矛盾，等级 `3` 接管主内容环境；同等级页面切换可以改变构图，刷新不产生无意义跳换；
- 主导航、国家版本选择器、返回表站、页脚声明和邀请退出保持可靠；非保护叙事控件可以发生有界空间变化，但焦点、命中框、链接与原动作不失效；
- 五个里站可售场次不再共用同一报价，至少一场使用不完整分区集合；同剧目异地和同地点异剧目均具有可观察报价差异；
- 污染升级不改变页面标题层级或当前焦点，辅助技术只收到简短状态公告而不会重复朗读整份投影；
- 里站不会被理解为表站的暗色换肤，也不会因污染模组失效而不可浏览。
