# BP-MOD-ARCHIVE｜1091 旧剧团网站

## 用户结果

用户能够直接进入或从表站发现一个内容完整、年代可信的 1091 旧剧团网站，并在其上经历受控污染，始终保有正常浏览和返回表站的能力。

## 边界

- 负责里站等级 `0` 的页面内容与任务、里站导航语气、污染判定触发及各等级的受控呈现；
- 通过叙事状态接口读取污染等级、请求一次判定或返回表站，不自行复制全局状态机；
- 搜索索引隔离由搜索蓝图负责，领域实体由领域语言蓝图负责；
- 可以制造不安，不使用真实欺骗、恶意下载、强制全屏、伪系统警告、闪烁滥用或不可退出流程。

## 等级 0 网站契约

- 里站表现泰拉历 1091 年当时实际存在的旧剧团官网；年份是内容、编排、用词、视觉和媒介质感的依据；
- 最小页面集合包括首页、本季演出、历史演出、剧团、搜索及独立票务页。任务名称与表站一致，内容、布局、导航语言和浏览节奏不要求逐页对应；
- “本季演出”是相对 1091 快照尚未举行的 `Performance` 集合；这些场次在表站“现在”的视角下均已发生；
- 里站所有场次当前均不可购买，不进入 `TicketBasket`、票务流程或成功结算。票务页只显示符合历史快照语境的不可用反馈和有效返回路径；
- 等级 `0` 已通过泰拉化的配色、排版、信息组织、媒介质感和用词体现更早年代，不直接套用现实早期网页、维多利亚印刷品、VHS 故障或特定现实技术规格；
- 等级 `0` 以正面轴线、中心舞台、拱门、长廊、肖像或登记卡式框景、较窄正文列、登记簿列表、旧纸与深色环境建立完整的仪式档案剧场；首页以邀请与剧团权威进入告示和本季登记，演出内容以登记簿或旧节目单组织，搜索和不可购票页保持同一旧站事务语言；
- 深廊黑、煤烟黑和漆木暗面形成环境，旧纸和褪色墨承担阅读，帷幕红、旧金、烛光琥珀与烟紫灰组织礼仪层级；鲜血红留给异常和关键诱导，不成为等级 `0` 的默认主行动色；
- 双线、刻线、旧金框饰、纸纹、轻微褪色和套印差异只作为有密度上限的装饰与媒介痕迹，不移动语义 DOM、点击区域或焦点，不降低导航、搜索反馈、返回入口和页脚声明的对比度；
- 对称骨架用于入口与框景，不强迫长文、列表和搜索结果居中；结构线、框景线和装饰线分工明确，普通信息不重复套多层边框；
- 等级 `0` 不出现随机抖动、扫描线、持续闪烁、现实系统故障图标或通用哥特噪声；年代感来自泰拉内排版、媒介和礼仪结构；
- 污染不能替代等级 `0` 的内容建设；脚本失败时等级 `0` 的核心内容和返回入口仍然成立。

## 污染触发契约

以下用户行为各向叙事状态请求一次污染判定：

1. 从表站点击进入里站；
2. 通过地址栏、书签或外部链接直接进入里站；
3. 在里站内点击进入另一个里站页面；
4. 在里站内切换国家版本或语言；
5. 提交一次里站搜索。

每个用户动作最多判定一次。搜索提交若发生页面导航，由搜索事件负责判定，不再由通用导航重复计算；随后点击结果属于新的页面导航，可以再次判定。刷新、浏览器前进或后退、锚点跳转、输入搜索字符、查询参数的非提交变化及页面自身重渲染不触发判定。

## 污染呈现契约

| 等级 | 叙事状态 | 表现边界                                                                     |
| ---- | -------- | ---------------------------------------------------------------------------- |
| `0`  | 原始快照 | 年代网站本身完整成立，不出现异常                                             |
| `1`  | 轻度污染 | 少量漏印、手写划线、图像乳剂痕迹和不一致红色批注，不破坏信息顺序与正文可读性 |
| `2`  | 中度污染 | 局部涂黑、套印偏移、画像缺损、边框覆盖和内容矛盾，主导航与搜索归属仍明确     |
| `3`  | 重度污染 | 大块黑红侵入、框景撕裂、受控视觉越界和明显叙事失真，核心浏览及退出仍可操作   |

- 除表里切换入口、里站返回入口和页脚同人声明外，其他可见元素可以成为经过编排的污染对象；
- 划线、涂黑、图片红叉、图片异常、受控错位和叙事替换可以使用，但不能成为无约束随机噪声；
- 污染只作用于呈现层和经过编排的叙事变体，不永久改写源内容、翻译完整度、索引归属或路由；
- 污染表现为旧媒介和剧场秩序被逐步改写，不通过统一噪点滤镜或无约束随机 CSS 代替等级设计；
- 等级 `1—3` 逐步破坏等级 `0` 已建立的轴线、框景、印刷和叙事可信度：等级 `1` 以局部漏印、批注和乳剂痕迹为主，等级 `2` 增加受控覆盖、画像缺损和边框侵入，等级 `3` 才允许明显黑红越界和框景撕裂；每一级都能从前一级辨认出升级关系；
- 污染不得改变 DOM 语义、焦点与键盘顺序、减少动态效果、替代文本、可理解的异常占位、视口安全和无 JavaScript 降级。

## Demo 基线

- 里站拥有独立的 1091 页面树、主导航、详情、搜索、不可购票页和可靠返回路径；

- 四级污染及五类触发只改变受控呈现，不改变语义 DOM、搜索范围、视口安全或退出能力。
