# 创意内容工作区

本目录保存尚未直接进入网站运行数据的原创叙事材料，例如剧目提案、人物小传、城市巡演概念、档案线索和文案实验。

## 内容分层

- **已采用内容：** 已进入 `src/`，在文档中链接到对应实现，不重复维护正文。
- **候选提案：** 可讨论但尚未批准进入网站，必须标记状态、目标时间层和预期入口。
- **外部事实：** 不放在本目录，应进入 `docs/references/` 并记录来源。
- **官方设定与同人补完：** 必须明确区分；无法确认的内容标为“待核实”，不得静默补全。

## 推荐提案字段

```yaml
title: 提案名称
status: draft | review | accepted | rejected
realm: front | archive | shared
purpose: 希望产生的体验或叙事作用
entry_point: 用户如何遇见它
content: 核心内容摘要
canon_boundary: 官方事实、推断与原创部分的边界
implementation_notes: 可能影响的源码模块
```

只有被采用并实现的内容才从这里迁移到 `src/data/` 或对应的 Astro 组件；迁移后保留决策摘要，不建立两个并行事实源。
