# 票务平台 Logo 视觉转译研究

记录日期：2026-09-02

本研究分析项目负责人提供的两份本地现实平台 Logo 参考，目标是为虚构票务平台“水稻网”和“跳楼机”提取可迁移的设计原则。参考图本身不进入仓库或运行时；可观察事实、项目推断与最终设计选择在下文分开记录。

## 证据边界

- `local-reference-materials/` 中的本地参考 A 与参考 B 是本次唯一图像证据；来源身份由项目负责人说明，未使用参考图之外的品牌故事解释其官方含义。参考文件名不进入项目文档或运行时索引。
- “聚合入口”“稳定循环”“速度与风险”等属于项目设计推断，不是现实平台的官方品牌陈述。
- 来源文件的哈希、尺寸、许可缺口和仓库存放边界见 [`../sources/ticketing-platform-logo-provenance.md`](../sources/ticketing-platform-logo-provenance.md)。

不能用“把花瓣换成稻粒”或“把圆环换成另一种圆形设施”的方式完成转译；那仍会保留参考商标最强的构图识别。项目只继承抽象视觉问题的解决方法，重新建立语义、拓扑和剪影。

## 水稻网

### 语义合成

- 一株从地面生长的水稻直接对应平台名称，不叠加水滴、网络节点或其他第二层隐喻；
- 单一主茎、短分枝与六枚等尺寸稻粒形成自下而上的生长节奏；
- 弧形地面同时提供稳定基线，并使植物不被误读为悬空的花枝。

### 视觉决定

- 暖白圆角底板留出呼吸空间，深湖青主茎和地面建立稳定骨架；
- 六枚稻粒使用明度接近的洋红、紫、蓝、青、绿、橙分配色彩，彼此不重叠且大小一致；
- 构图不使用环形放射、黑色中心或参考图的色序，单色化后仍保留“从地面长出的水稻”剪影；
- 圆头粗线与大颗粒适配页面 `56—88px` 显示，并以 `32px` 作为额外缩放检查。

## 跳楼机

### 语义合成

- 塔顶、横梁和双导轨建立明确的垂直机械设施，而不是闭合循环；
- 居中的珊瑚色乘坐舱表达突然坠落、速度和风险；
- 导轨从塔顶贯穿至支承基座，宽底脚与地面平台补齐设施的完整形象；
- 中性炭灰底板避免使用具有强烈品牌联想的特色底色，暖白结构维持商业平台的可读与可信外观。

### 视觉决定

- 使用不透明高圆角方形底板、少量大视觉块和统一粗尺度，不加入圆环、A 形支架、人物、座椅孔洞、警示文字或下载箭头；
- 与水稻网的弧形地面、分枝和多色稻粒保持完全不同的纵向剪影，急迫感来自空间关系和色彩，不通过闪烁、动画或误导性交互制造；
- `32px` 下应继续辨认塔顶、塔架、舱体和完整基座，细节不得退化成梳齿或粘连。

## 共同验收

- SVG 使用正方形 `viewBox`，无 `<text>`、字体、脚本、动画、滤镜、外链或位图；
- 图形在 `32px`、对话框 `56px` 和页面品牌区 `60—88px` 保持清楚，不因颜色移除而失去主要剪影；
- 两枚 Logo 不只是同形换色，与两张参考图并排时也不出现参考商标的核心轮廓组合；
- 平台名称、语言和可访问身份继续由类型化国家版本内容与相邻 HTML 承担；
- 2026-09-02，项目负责人完成人工视觉验证并采用两枚当前 SVG；后续修改仍须重新经过视觉与权利审核，不能沿用本次批准。
