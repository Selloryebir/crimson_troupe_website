# 里站年代设计的参考与转译

本研究记录里站年代设计的参考与转译依据，不独立约束源码，也不主张泰拉年代与现实互联网年份一一对应。已采纳的艺术与功能边界分别由 [`BP-FND-EXPERIENCE`](../blueprint/foundation/experience-system.md) 和 [`BP-MOD-ARCHIVE`](../blueprint/modules/archive.md) 维护。

记录日期：2026-09-14。

## 来源与可借鉴项

- CERN 的历史说明将早期 Web 描述为把超文本与网络连接为信息系统。可借鉴“文档和目录先于展示”的任务组织，不复制首站页面、文本或独特布局。[CERN：Web 简史](https://home.cern/science/computing/the-birth-of-the-web/short-history-web/)
- W3C 的 CSS 历史说明结构与呈现分离是长期目标。这里借鉴有限样式下的排印秩序，而不回退到旧技术限制。[W3C：CSS 历史](https://www.w3.org/Style/CSS20/history.html)
- W3C 表格规范区分真实表格关系与纯布局表现。登记栏可以有分栏视觉，但不能因此将页面主体改为无语义布局表格。[W3C：表格布局](https://www.w3.org/TR/CSS2/tables.html)

## 本项目的设计推论

采用刊头与目录分行、有限宽度、段落优先、明确文字链接、登记式信息层级；用现有旧剧场的漆木环境、未漂白纸、深墨和少量套红完成泰拉化。表站保留现代编辑节奏，里站增强“先查阅、再受邀请”的页面秩序。以上是项目设计判断，并非来源网站推荐或泰拉官方设定。

## 明确排除

不复制 CERN 或任何真实旧网站；不加入访问计数、施工 GIF、跑马灯、浏览器推荐标志、假错误、frames、固定桌面宽度或鼠标专用交互。不引入第三方素材、外部字体或运行时请求。高清封面与透明团标保持原样，不以低清晰度模拟技术年代。
