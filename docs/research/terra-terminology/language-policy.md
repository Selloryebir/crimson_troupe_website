# 术语与多语言候选的研究方法

本方法服务于研究候选，不改变现有国家版本注册、人工批准或发布门禁。研究日期为2026-09-15；本轮未找到某译名，不等于证明该语言从未有过官方译名。

## 先确定身份，再选择拼写

一个概念可以有多种形式；同一种形式也可以指向不同概念。不能以中文字符串作为跨语言主键。

- 卢西恩、傀影、新任酒神属于人物本名、代号及后续身份关系；旧团长不能因同名酒神而并入这个人物。
- 沃尔西尼与新沃尔西尼不是随语言切换的同一地点标签；旧城时代称呼和新建城市身份分别处理。
- 乌萨斯、杜林、阿戈尔可能是国家／文明与种族名称。文章中的所指由上下文决定，不做全局查找替换。
- 源石是物质，矿石病是疾病，感染者是人群；不得将“源石病”当作已核官方中文名称。
- `Arts`在此指源石技艺，不是首页所说的艺术；`Operator`在干员语境不译为网站操作员。
- `Phantom`、`Silence`、`Emperor`是代号时保护身份，不能自动变成普通名词“幻影”“沉默”“皇帝”。剧目标题中的法语或德语也不因处在English来源列而改写。

## 证据等级不是翻译批准等级

| 标记                  | 含义                                             | 不能据此声称                                 |
| --------------------- | ------------------------------------------------ | -------------------------------------------- |
| `official_direct`     | 发行方页面直接出现该形式；实际读取方式另看access | 已阅读全文、适用于所有时代、已经获得项目批准 |
| `official_reproduced` | 社区页面明确转录游戏正文中的形式                 | 社区运营方就是官方、页面全部内容均为游戏正文 |
| `community_reference` | 社区整理的译名栏、说明或索引                     | 已亲自与客户端逐字核对                       |
| `project_approved`    | 已有人工确认的项目来源形式                       | 新增官方授权，或所有国家版本均已批准         |
| `candidate`           | 本研究提出的非官方候选                           | 官方译名、母语审校通过或可直接发布           |

`source_type`回答发布主体与材料性质，`access`回答本轮实际读到了什么。官方网页只能取得搜索摘要时，两者分别为`official_site`与`search_excerpt`，不可合并成“官方全文已核”。全文打不开但搜索有目标词，可以记录所见词；不能据此确认没有出现其他写法。

多个社区页面不一定是独立来源，尤其Fandom与wiki.gg迁站前后可能同源。交叉审计应尽量对照发行方公告或明确逐字游戏文本；没有第二条独立证据的项目继续标为单源，不以票数决定事实。

## 翻译候选的决策顺序

1. 已有同语言官方形式：原样保留大小写、长音、撇号等，另记时代与媒介。官方新旧版本冲突时保留分歧，不覆盖历史。
2. 无已核同语言官方形式：先判断是否是保护名称、可译普通概念、机构名称中的通名或需要转写的人名。
3. 专名可暂保留有来源的拉丁形式；这只是非官方保护原名策略，不表示完成了本地化。用户界面可另附本地化类别说明，不将说明写进专名本体。
4. 通名可提出语义译法；公司品牌核心和“基金会／贸易／物流”等组织通名分别处理。不能从现实国家、现实公司或词源直接推导世界观身份。
5. 缺少语境就留空。不得为了九语言矩阵全满而生造片假名、将日文汉字当中文、把英语单词复制后标为正式译文。

转写不是翻译，也不保证可逆；字形相近不能证明同源或同一实体。[Unicode转写指南](https://cldr.unicode.org/index/cldr-spec/transliteration-guidelines)区分字符系统转换与意义转换；本资料因此保留原形式和候选方法，不用转写结果反推官方名称。

## 五种语言的具体处理

下列是候选编写约束，而非完整风格指南；`translation-candidates.json`只提供词头或固定名称，不包含完整句法范式。

| 语言     | 候选处理                                                               | 必须另行检查的上下文                                                                         |
| -------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 俄语     | 普通概念按名词性、数和语义翻译；未知品牌可保留拉丁原名并附俄文组织通名 | 地点在前置词后、人物姓名在宾格／属格、感染者的单复数；不能把主格直接插入句子                 |
| 意大利语 | 通名通常小写，专名保留；明确名称内介词关系                             | 冠词省略、di/del/della等缩合、单复数及修饰语性数；避免仅因Siracusa看似意语就采用现实城市事实 |
| 希腊语   | 保留重音；术语与句中冠词区分；未知品牌可先保留拉丁拼写                 | 格、性、数和拉丁混排；全大写标题的重音处理与实际字体覆盖，需要独立版式审查                   |
| 德语     | 名词大写；组合术语检查中心词与连字符；官方德语式名称优先保留原形       | 冠词格变化、长复合词换行；英语来源中的Zwillingstürme不应退化为无变音符号拼写                 |
| 波兰语   | 保留变音符号；词头按语义确定性数；品牌是否变格不能批量猜测             | 地名、人名和机构名称的属格／处所格；复数人群与普通物体语法类别不同                           |

`Oripathy`在五语候选中暂保护原名，是避免假造医学新词的保守选择，不是已找到五语官方病名。`Originium`同理。病因描述可本地化，疾病名称的正式创造需另行认可。科幻疾病研究不提供现实医疗建议。

## 句子、名字和版式

完整句子应作为翻译单元；参数有命名、有语义上下文，不通过若干独立译词拼成句子。[W3C复合消息指南](https://www.w3.org/International/articles/composite-messages/)说明词序、语法一致与复用片段可能发生冲突。城市词头正确，不等于“在某城市演出”的句子正确。

[Unicode人名规范](https://www.unicode.org/reports/tr35/tr35-personNames.html)处理姓名组成、顺序与格式，但不提供所有语言的自动变格。本项目不能借用姓名格式器“证明”Lucian与Tragodia是同一人物，也不能自动把虚构单名拆出姓氏。

[CLDR语言显示名说明](https://cldr.unicode.org/translation/displaynames/languagelocale-names)区分语言、书写系统和地域。本研究`en`来源可供`en-GB`和`en-US`候选引用，但不替代两个版本各自的正式批准；泰拉国家与现实locale也不是地理等同关系。

后续接入的版式验收建议：使用真实最长名称而不是统一占位词，至少检查320px及桌面；希腊语重音、俄文宽度、德语长词、日语长音不可因裁剪或字距被破坏。导航的可点击区域和栏位不能随语言漂移。研究阶段没有修改网页，因而不把文档检查写成浏览器验收。

## 安全接入顺序

来源形式与语义身份核对 → 人工选择显示词头及别名 → 完整句子与语言审校 → 建立唯一受控运行时数据 → 搜索／卡片／详情／票面一致性 → 窄屏、键盘和发布资格验收。

候选不直接读取进页面，不自动刷新翻译摘要或批准摘要。每次改名都保留稳定ID；查找别名可以容纳旧译，但不应让用户可见正文同时混用多个时代名。精确实施建议见[维护建议草稿](../../drafts/recommendations/terminology-maintenance.md)。
