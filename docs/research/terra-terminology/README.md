# 泰拉术语矩阵与后续内容扩充研究

研究日期：2026-09-15。范围：当前网站常用地点、猩红剧团身份链、公司机构、通用世界观概念及未来扩充所需的种族／地域。本研究是可追索的资料底座，不是全泰拉百科，也不是新增官方设定或已采纳的运行时翻译。

结论：应优先修复“同一概念的身份与来源管理”，而不只是补齐所有语言的字符串。中英日有可核形式时先保存原形；官方未核的部分显式保留缺失或社区级证据；其他语言只提交有语义理由的候选。术语表能帮助避免错名，不能证明某年代某地允许演出。

## 阅读矩阵

`en-GB`和`en-US`共用本轮找到的`en`来源形式，但各自标注`not-edition-approved`，不因同为英语自动获得两版批准。其余列与当前九个国家版本对应；这实际是八种语言，不能称为“游戏官方九语译名表”。

单元格中的`official_direct`、`official_reproduced`、`community_reference`说明证据级别；方括号内的`form_id`可定位具体来源。`candidate`始终是非官方；`protected_name`表示暂保留外语专名，并不表示翻译工作已完成。`[not_verified]`是没有可登记形式，不代表禁止使用该概念，也不证明全网不存在该语言译名。

同格`||`表示存在多条已见证据或异写，不是显示时应拼接的文本。要看原始来源、notes、人物身份及时代限制，再决定哪些用于显示、哪些只是检索别名、哪些应排除。矩阵故意不选出一个自动获批的“最佳值”。

## 核心发现：先消除错误等同

### 1. 旧团长、卢西恩和新任酒神

本名`Lucian`、干员代号`Phantom`与后继名称`Tragodia`相互关联，但旧团长是另一人物。资料用`alias_of`表示代号对应人物，用`successor_of`记录继承关系，并显式保留`distinct_from`。继承描述不扩张为对人格、意识或心理的额外诊断。[人物社区对照](https://arknights.wiki.gg/wiki/Phantom/Story)、[旧团长条目](https://arknights.wiki.gg/wiki/Tragodia_%28NPC%29)、[干员档案转载](https://prts.wiki/w/トラゴーディア)

日服发行方公告写`トラゴーディア`，社区干员语言栏有缺少长音的`トラゴディア`；保留双方实际写法，不能让多数重复的社区结果压过直接官方形式。旧团长日文称号又不能直接套用新任干员名。[日服公告](https://arknights.jp/news/1953)、[社区干员页](https://arknights.wiki.gg/wiki/Tragodia)

`Miss.Christine`的句点后不因排版习惯擅加空格；她与`Kristen Wright`也不是同一人物。`Dionysus`可作为现实词源讨论，不取代游戏英文`Tragodia`。游戏活动上线日只证明现实本地化发布，不提供旧团垮塌或新团营业的泰拉确日。[国际服公告](https://www.arknights.global/news/1955)

### 2. 城市身份与名称版本

沃尔西尼与新沃尔西尼分概念记录，不能用`alias_of`合并；1100年的周年筹备场景最多支持约1099的建城推断，不把场景日、庆典日或周年话语当精确行政成立日。[PV-ST-1转载](https://arknights.wiki.gg/wiki/PV-ST-1)、[PV-7转载](https://arknights.wiki.gg/wiki/PV-7/Story)

克莱布拉松的`Calais-Blason`、`Celaiblason`等拼写差异属于来源版本核对，不自动构成泰拉世界内的地名更改事件。没有证据支持本轮讨论时出现过的`Celaiblaison`或“克莱布尔松”作为标准形式。`Wrankwood`对应蓝卡坞，不把习惯写法“兰卡坞”直接升级为官方中文。[泰拉词库](https://prts.wiki/w/泰拉词库)、[克莱布拉松条目](https://arknights.wiki.gg/wiki/Calais-Blason)、[蓝卡坞条目](https://arknights.wiki.gg/wiki/Wrankwood)

`Vedunien`与崔林特尔梅涉及历史名称、重建及政治象征。游戏残存记录直接描述1092首日重建完成及作品命名；它不单独证明城市行政更名也恰在1092。不能因此判定1084必然用错名，也不能反向保证当前名字当时可用。这个风险已进入维护建议，等待明确原文而非自动更改排期。[游戏残存记录](https://arknights.wiki.gg/wiki/Zwillingst%C3%BCrme_im_Herbst/Herzenfolgen/Remnant_Records)

### 3. 翻译优先核对词形，不猜读音

本轮日文高价值核对项包括`ウォルシーニ`、`ヴィセハイム`、`セライブラソン`、`ツヴィリングトゥルム`和`プロペラパラダイス`。各自证据级别不同：游戏旅游文字／勋章转载与社区语言栏不可混为一谈；`ヌオバ・ウォルシーニ`仍需更直接的日服原文。具体逐词定位见attestations.json的`place-*`记录。

机构尤其容易被字面翻译误改：`Rhine Lab`不是`Rhine Life`；`Blacksteel Worldwide`不应按“国际”机械改成`International`；`Raythean`不是现实公司`Raytheon`；`Karlan Trade`不能与国家`Kjerag`合并。五语候选多数对此暂保护原名，再把语境说明本地化，而不是新造品牌。[国际服制作人问答](https://www.arknights.global/news/443?list=true)、[雷神重工社区条目](https://arknights.wiki.gg/wiki/Raythean_Industries)、[喀兰贸易条目](https://arknights.wiki.gg/wiki/Karlan_Trade)

### 4. 世界观词汇会改变事务含义

“源石病”不能直接登记为官方病名；正式中文已见形式为矿石病，英语为`Oripathy`，日语为`鉱石病`。源石／疾病／感染者三者分别建模，感染者不是某个组织的同义词。源石技艺的`Arts`也不能全局替换剧院日常“艺术”。[中文官方介绍](https://ak.hypergryph.com/protocol/application)、[日服问答](https://www.arknights.jp/news/147)、[游戏贴士转载](https://prts.wiki/w/Tip)

监控装置、抑制剂、浓缩抑制剂与病理指标不是同一类资料。某款道具的效果不能推广为该世界所有治疗手段，更不能写成现实医疗建议；词条只给基础识别，不生成患者信息或治疗承诺。

种族记录与国家／国籍分离。阿戈尔、杜林和乌萨斯的同名情况尤其需要上下文；海嗣也不能与阿戈尔族群合并。社区对`Aegir/Ægir`和`Seaborn/Seaborns`有字形或编辑规范说明，记录已见形式并保留限制，不能用社区规范修正原文引语。[阿戈尔种族](https://arknights.wiki.gg/wiki/Aegir_%28race%29)、[海嗣条目](https://arknights.wiki.gg/wiki/Seaborn)

## 时间敏感度：名称存在不等于可演出

本包所有概念都带研究语境限制。没有有效起止字段表示尚未建立可用窗口，绝不是“自古至今有效”。`located_in`只表示引证阶段的归属，`member_of`只表示相应故事阶段成员关系；均不能当作1084或1102仍成立的数据库真值。

以后新增一次排期，应分开回答：国家与城市当时是否存在、是否能抵达、场地是否可用、剧团是否具备人员与剧目、机构是否可能获知相关信息。灾害可以使场地失效，却不当然封锁整个国家；名称译对也不证明剧院存在。旧城实体、新城、改名、修复、撤离和庆典不能只用一个年份字段混写。

建议的编辑顺序是：先在年鉴记录观察与竞争日期主张，再确定项目采用的保守窗口，最后编排场次和事务措辞。事实证据与项目排期选择分别保留；不把“未记载阻碍”当作“已证明安全开放”。[既有时间审核指南](../../guides/temporal-content-review.md)和[年鉴日期主张](../terra-chronology/date-claims.csv)继续承担该责任。

对螺旋桨天堂，未来改动仍需重新检查“事故分支→场地失效→剧团获知→取消通知→原定演出”的链条。1102-01-04是项目原定演出日，不是官方事故或公告日。现存其他浮空设施不证明原场地仍可演出；改表站观察时钟还会改变当季／历史、搜索和票务语义。精确当前代码锚点只保存在[维护建议草稿](../../drafts/recommendations/terminology-maintenance.md)，不在这里建立第二份排期表。

## 校验与复用

从仓库根目录运行：

```sh
node docs/research/terra-terminology/check.mjs
```

检查唯一ID、概念／词形／来源／候选引用、证据与发布主体兼容性、关系目标、语言范围、候选未批准状态，以及CSV与JSON和原活页来源的一致性。它不能证明翻译自然、文本真伪、所有来源独立或演出时间可行；结构通过不是考据结论。

`node docs/research/terra-terminology/check.mjs --matrix`只向标准输出生成CSV，不写入仓库。修改权威JSON或原活页来源后，用仓库正常文件编辑流程更新matrix.csv，再运行检查；不要直接改单元格。已有形式ID不因重排数组重建，保留证据定位。

目前候选140条，覆盖28个概念的五语形式：60条语义译法、5条机构混合译法、75条保护原名。全部保持`unreviewed`，表示未获正式人工／母语审批，虽然经过独立智能体的定向语言风险检查。特别保留“干员”在俄语／希腊语可能偏警务或情报的联想、以及虚构医疗术语修饰关系的待审风险；本轮没有将“不足以判错”写成“译法已正确”。

## 审计边界与剩余缺口

三个子代理按地理、人物机构、世界观独立提取，随后交换审查对象；主智能体复读高风险来源、合并并校验。发现并处理了官方词形备注误写“社区整理”、阿戈尔已见字形遗漏、旧Fandom证据可由当前条目替代、以及重建日期过度解释等问题。主审还将无法独立核对原文的英语源石引擎形式降为社区参考，没有为全表整齐而提高证据等级。

本研究尚未穷尽官方本地化，也没有为每条社区语言栏找到客户端原文。日文仍有明确空缺，见检查器输出；五种其他语言的官方译名没有得到可登记的逐条证据，不能宣称“官方不存在”。大部分扩展名词仍为社区级参考；正式接入应优先补来源，而非一次性全量批准。

研究资料不提供官方地图距离、固定交通周期、精确历法置闰、所有机构成立日、所有种族的公认分类或全人物生平。也没有进行母语人士审校或网页视觉验收；本轮没有修改网页。具体网页缺陷与正式采纳选择留在维护建议草稿，未经批准不改active蓝图和发布范围。
