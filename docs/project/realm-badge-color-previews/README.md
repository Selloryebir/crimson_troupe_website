# 国家版本徽章上色预览

本目录保存九枚国家版本徽章的非运行时上色候选，用于人工并排比较国家语义、徽章辨识度与同屏协调性。来源与权利边界见[国家版本徽章来源记录](../../sources/realm-badge-provenance.md)，具体制作约束见[国家版本徽章制作与复核指南](../../guides/realm-badge-authoring.md)。

- 每个文件与同名运行时单色母版共用 `510 × 510` 透明画布和几何轮廓，只改变形内色层；
- 候选色不是官方国色，不代表已批准的国家版本主题；
- 源码、CSS、组件和构建入口不得导入本目录文件；
- 未来任何上色版本进入运行时，都必须经过新的人工授权、正式蓝图变更及双时间层对比度验收。
