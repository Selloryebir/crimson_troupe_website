# 双站时间敏感内容的作者前提

本文件保存已采纳的项目原创因果与内容边界，不参与构建，不是官方年鉴或第二份排期表。运行时场次与逐字译文只由 `src/data/` 拥有，内容仍须通过预览与正式资格门禁。

## 旧团时代与地点

1084背景参考罗德岛舰船出土并接受卡兹戴尔资助修复的年鉴条目；该事实不证明全球交通能力或剧团转场时长，也不等同后来罗德岛组织成立。维多利亚、莱塔尼亚优先与较疏排期是项目保守编排，不是官方路线。沃尔西尼保留历史城身份，剧场暂用可替换占位；不虚构分团或驻地替演补足交通论证。

## 馆藏存续

1098副本先被捕获并保存在伦蒂尼姆档案节点，此后服务器在当年战事中受损；目录部分存续，材料不足以恢复完整正文。捕获与受损的具体月日未知，网络恢复不等于档案恢复，不补街区、武器或责任人。1089与1093损坏原因未知，不能连带归因于战事。

1084据另行保存的独立副本呈现，不依赖受损节点；不据此断言1098也有完整异地备份。不补保存地点、介质或迁移日期。保存解释属于后来的馆藏层，不进入1084同期正文，也不解释污染或邀请作者。跨时机制暂不直接揭示，不新增自动弹窗；原作各类请柬与网站邀请在作者理解层分开。

损坏说明采用中性馆藏口吻：未知原因仅说明正文部分不可读、索引不足以归因；1098明确节点战损、恢复不足及月日未核实；1084仅说明独立保存。相关来源定位见年鉴的伦蒂尼姆事件，以及社区转载的GO-8、GO-1；约7至10月的冲突背景不等于每天持续战斗，也不证明剧团服务器是官方事实。

## 螺旋桨天堂取消案例

项目采用1101年末事故分支，年鉴P003及D10—D12、D15的1102春等竞争主张原样保留，不把项目选择提升为唯一官方定年。剧情背景依据UR-ST-1、UR-7、UR-8、UR-ST-3的来源索引；考据中的政治与破坏行动不自动成为剧团公开知识。

因果顺序为事故前筹演、场地坠毁、剧团获知无法使用、原演出日前取消、表站当前时点保留已取消历史记录。已选原演出日暂定1102-01-04；它不是事故日或公告日，其他先后节点不补确日。开发可用19:30、《猩红宴》及“螺旋桨天堂临时剧场 · 主厅”作可替换占位。邻场允许重编以减少无依据转场，最终取消不免除原计划的合理性审查。

场地位于哥伦比亚麦克斯特区外缘，不借用特里蒙身份。莱茵浮空设施仍存不等于原演出场地可用，不安排未经证实的转场或复开。展会筹备、园区运作与剧团筹演是不同计时对象，不能由“半年”反推本团签约。

取消记录保留原日期、使用场地条件原因、不可售，历史不等于已完成。公告以该场次日期生成，说明原浮空场地坠毁、无法依原计划演出、原排期仅供查阅；不公开未经核实的责任归属，不虚构已售票、退款、补偿或替代演出。地方事故不扩大成全国停演或新增损坏快照。若事故分支变化，重新审查整条因果链。
