# 项目作者资料

`docs/project/` 保存已经由项目负责人提供或确认、但不直接参与构建的作者资料与比较样张。它回答“项目创作时可以从哪些内部材料出发”，不同于外部来源、研究分析、正式行为蓝图和运行时内容。

## 当前记录

- [`performance-location-catalog.md`](performance-location-catalog.md)：非排他的演出地点候选、跨语言显示形式与内部创作备注；
- [`realm-badge-color-previews/`](realm-badge-color-previews/)：九枚国家版本徽章的非运行时上色比较样张。

## 维护规则

- 作者资料不得被页面、构建器或验证器直接读取；实际采用内容进入 `src/data/`，运行时素材进入 `src/assets/`；
- 候选目录不等于运行时白名单、发布清单、官方设定或 active 蓝图；需要形成长期行为约束时进入 `docs/blueprint/`；
- 资料中的外部事实只有在 `docs/sources/` 有可核验记录时才能被称为官方；内部备注和项目推导必须保持项目身份；
- 未经采纳的故事、交互和艺术方向仍属于 `docs/drafts/`，不能用本目录绕过草稿与人工门禁；
- 比较样张进入运行时前必须完成素材权利、正式蓝图、内容资格与对应体验验收。
